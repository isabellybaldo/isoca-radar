# S2c · scanner (live detection, capture, replay, resilience) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** `bins/scanner`, a long-running, read-only process. It keeps an event-affine websocket view of Polymarket's NegRisk universe, detects YES/NO basket arbitrage per frame with `arb-core`, records episodes, re-checks and integrity events in Postgres (`store`), captures raw frames for replay, and survives restarts without crash loops. It ships with `replay`, `census`, `migrate` and `breaker reset` commands and a compose `core` profile.

**Architecture:** One pure, synchronous `Engine` owns every book and the episode tracker. It has no IO and no clock: time arrives on its inputs, so live and replay produce identical rows. Tokio tasks around it:
- a shard supervisor: event-affine shards, global connect budget, backoff, parking;
- a universe refresher (5 min, warm start from Postgres);
- REST checkers: re-checks, resnapshots, drift sampler, L1 mirror sampler, `/ok`;
- a batching store writer;
- a capture thread (zstd JSONL, disk guard, retention);
- a per-minute health task.

A crash-loop breaker on the `runs` table turns ≥ 5 starts in 10 min into a safe-mode exit 0.

**Tech Stack:** Rust 1.98.1, tokio, `pm-api` (the only network crate), `store` (the only SQL crate), `arb-core`, serde/serde_json, toml, clap, anyhow, zstd, sha2, fs4. Docker: cargo-chef builder → distroless `cc` nonroot runtime.

**Spec:** `docs/superpowers/specs/2026-09-22-arb-scanner-design.md` (§5.5 statistics, §7 capture, §8.1–§8.2 architecture, §8.1.2 resilience, §9 code structure, §10 storage, §15 tests, §16 enforcement). Phase 0 answers: `spikes/probe/RESULTS.md`. Depends on the S2b plan `docs/superpowers/plans/2026-09-25-s2b-store.md` being complete.

## Global Constraints

- PAPER TRADING ONLY. No order placement, no wallet, no keys, no signing. The scanner reaches the network only through `pm-api` (deny.toml already forbids reqwest/tokio-tungstenite elsewhere) and Postgres only through `store` (sqlx is `store`-only). The process refuses to start if exchange/wallet credential env vars are present (§16 #1).
- Money and prices are never f32/f64 (workspace clippy denies `float_arithmetic`). Integer ms/µs for time; `Decimal` for amounts.
- **Phase 0 limits are binding.** At most **40** websocket connections (the measured cap is ≥ 40; above that is untested). At most **1,000** tokens per connection (5,000/conn failed with a p99 lag of 15.7 s; 500 was clean; ~1,200 was healthy). Hot shards get ≤ 500 tokens. Connection attempts: ≤ **2/s and ≤ 20/min** globally. Backoff runs 1 s → 60 s and resets only after a session lived > 30 s.
- A group (NegRisk event) or a canary pair is **never split** across connections (§7).
- **Evaluation is per frame** (§5.5): all of a frame's events are applied first, then each touched group is evaluated once.
- **Zero is a measurement:** unmeasured → `None`/NULL, measured zero → `Some(0)`.
- External input never panics: no `unwrap`/`expect` outside tests. A malformed frame becomes a `parse_error` integrity event.
- Raw frames never go into Postgres (≈ 123 GB/day): they go to capture files, with a retention window.
- Episode ids are deterministic: `"{source}-{run_id}-{tracker_id:08}"`. This is a deliberate deviation from §10's ULID: replay must reproduce ids byte for byte, and `(source, run_id)` is already unique.
- Deferred (not in this plan, recorded so reviewers don't flag them):
  - D3 implication pairs (need the `pairs` table from Phase 6);
  - duplicate hot connections (§7 "optionally");
  - `days_to_end` / `annualized_return` / `post_end` (NULL = not measured; the analyzer computes them from `legs.end_date`);
  - `clock_offset_ms` in health (NULL; Phase 0 bounded the offset at ≈ 100 ms);
  - the paper trader (S3);
  - re-measuring the connection cap above 40;
  - `cargo fuzz` targets for the frame parsers (spec §15; they belong in `pm-api` and get their own small plan).
  - The L1 sampler also covers canary pairs, but a canary mismatch only raises an integrity event: canaries have no episodes to flag.
- Commit messages are plain, with no co-author or attribution trailer. Stage only files you touch (never `PROJECT.md` / `README.md`).
- Bash prefix for every command: `cd /c/Users/Isabelly/PycharmProjects/cute-trading && export PATH="$HOME/.cargo/bin:$PATH" &&`

## Review Focus

1. **A shard reconnect in the middle of an open episode** must close it right-censored, and the next positive state after the reconnect must open a *left*-censored episode, never an invented continuous duration. Pinned in Task 4 (disconnect) and Task 6 (replay reproduces it from `ctl: down` lines).
2. **A quiet book on a live connection** must not be mistaken for a feed gap. Frames and PONGs advance the gap clock of open episodes on that connection (Task 5 `alive` test).
3. **The same episode written twice within one 100 ms flush** (open, then peak) must reach Postgres as its last version. The writer's `Pending` dedupes (Task 7), and `store::write_batch` dedupes again (S2b).
4. **A resnapshot or drift REST book that is older than our websocket state** must never regress the book (Task 5).
5. **A universe refresh that moves an event to another shard** must apply the new token → group mapping in the engine *before* the new shard's snapshot frames can arrive. The refresher waits for the engine's ack before telling the supervisor (Task 10).

```rust
impl Config {
    /// Parse and validate; returns the config and its hash (hex sha256 of the exact text).
    pub fn parse(text: &str) -> anyhow::Result<(Config, String)> {
        let cfg: Config = toml::from_str(text).context("parse scanner config")?;
        cfg.validate()?;
        let mut hash = String::with_capacity(64);
        for b in Sha256::digest(text.as_bytes()) {
            let _ = write!(hash, "{b:02x}");
        }
        Ok((cfg, hash))
    }

    pub fn load(path: &Path) -> anyhow::Result<(Config, String)> {
        let text = std::fs::read_to_string(path).with_context(|| format!("read {}", path.display()))?;
        Self::parse(&text)
    }

    fn validate(&self) -> anyhow::Result<()> {
        let s = &self.shards;
        anyhow::ensure!(
            (1..=40).contains(&s.max_connections),
            "shards.max_connections must be 1..=40 (Phase 0 measured the cap only up to 40)"
        );
        anyhow::ensure!(
            s.cold_shard_tokens >= 1 && s.cold_shard_tokens <= 1000,
            "shards.cold_shard_tokens must be 1..=1000 (Phase 0: 5,000/conn fails)"
        );
        anyhow::ensure!(
            s.hot_shard_tokens >= 1 && s.hot_shard_tokens <= s.cold_shard_tokens,
            "shards.hot_shard_tokens must be 1..=cold_shard_tokens"
        );
        anyhow::ensure!(s.per_shard_capacity >= 1, "shards.per_shard_capacity must be ≥ 1");
        anyhow::ensure!(s.retier_every_refreshes >= 1, "shards.retier_every_refreshes must be ≥ 1");
        let c = &self.connect;
        anyhow::ensure!((1..=2).contains(&c.per_sec), "connect.per_sec must be 1..=2 (spec §8.1.2)");
        anyhow::ensure!(c.per_min >= c.per_sec && c.per_min <= 20, "connect.per_min must be per_sec..=20");
        anyhow::ensure!(c.backoff_base_ms >= 1000 && c.backoff_cap_ms >= c.backoff_base_ms, "connect backoff 1 s → cap");
        anyhow::ensure!(c.park_after_failures >= 1, "connect.park_after_failures must be ≥ 1");
        anyhow::ensure!(
            !self.recheck.offsets_ms.is_empty() && self.recheck.offsets_ms.iter().all(|&o| o > 0),
            "recheck.offsets_ms must be non-empty and positive"
        );
        anyhow::ensure!(self.recheck.rest_per_sec >= 1, "recheck.rest_per_sec must be ≥ 1");
        anyhow::ensure!(
            self.capture.resume_above_gb > self.capture.pause_below_gb,
            "capture.resume_above_gb must exceed pause_below_gb"

        anyhow::ensure!(self.capture.retention_hours >= 1, "capture.retention_hours must be ≥ 1");

    }
```

```rust
//! Spec §16 #1: refuse to start if any exchange or wallet credential is present in the environment.
//! Database role passwords (POSTGRES_*, PG*, *_DB_PASSWORD) are expected and allowed. Only NAMES are
//! ever reported, never values.

const CONTAINS: [&str; 5] = ["PRIVATE_KEY", "MNEMONIC", "SEED_PHRASE", "API_SECRET", "PASSPHRASE"];
const PREFIXES: [&str; 2] = ["POLY_", "CLOB_"];

pub fn forbidden<I, S>(names: I) -> Vec<String>
where
    I: IntoIterator<Item = S>,
    S: AsRef<str>,
{
    let mut bad: Vec<String> = names
        .into_iter()
        .map(|n| n.as_ref().to_string())
        .filter(|n| {
            let u = n.to_ascii_uppercase();
            CONTAINS.iter().any(|c| u.contains(c)) || PREFIXES.iter().any(|p| u.starts_with(p))
        })
        .collect();
    bad.sort();
    bad
}

pub fn check_env() -> anyhow::Result<()> {
    let bad = forbidden(std::env::vars_os().filter_map(|(k, _)| k.into_string().ok()));
    anyhow::ensure!(
        bad.is_empty(),
        "refusing to start: exchange/wallet credential variables are set: {} (paper-only project, spec §16)",
        bad.join(", ")
    );
    Ok(())
}
```

```rust
//! The scanner's universe (spec §7): NegRisk groups with EVERY outcome (tradeable or not, so
//! completeness stays honest) plus a daily canary sample of binary markets (both tokens).
use arb_core::book::Book;
use arb_core::detect::{Group, GroupLeg, LegStatus};
use arb_core::fee::FeeSchedule;
use pm_api::gamma::{GammaEvent, GammaMarket, fee_schedule, leg_status, token_ids};
use rust_decimal::Decimal;
use rust_decimal::prelude::ToPrimitive;
use serde::{Deserialize, Serialize};
use serde_json::Value;
use sha2::{Digest, Sha256};
use std::collections::{BTreeMap, HashMap};
use store::{EventRow, LegRow};

#[derive(Debug, Clone, Copy, PartialEq, Eq, Serialize, Deserialize)]
#[serde(rename_all = "snake_case")]
pub enum Status {
    Live,
    Placeholder,
    Other,
    ClosedNo,
    ClosedYes,
    Halted,
}

impl Status {
    pub fn from_core(s: LegStatus) -> Self {
        match s {
            LegStatus::Live => Status::Live,
            LegStatus::Placeholder => Status::Placeholder,
            LegStatus::Other => Status::Other,
            LegStatus::ClosedNo => Status::ClosedNo,
            LegStatus::ClosedYes => Status::ClosedYes,
            LegStatus::Halted => Status::Halted,
        }
    }

    pub fn to_core(self) -> LegStatus {
        match self {
            Status::Live => LegStatus::Live,
            Status::Placeholder => LegStatus::Placeholder,
            Status::Other => LegStatus::Other,
            Status::ClosedNo => LegStatus::ClosedNo,
            Status::ClosedYes => LegStatus::ClosedYes,
            Status::Halted => LegStatus::Halted,
        }
    }

    pub fn as_str(self) -> &'static str {
        match self {
            Status::Live => "live",
            Status::Placeholder => "placeholder",
            Status::Other => "other",
            Status::ClosedNo => "closed_no",
            Status::ClosedYes => "closed_yes",
            Status::Halted => "halted",
        }
    }
}

#[derive(Debug, Clone, PartialEq, Eq, Serialize, Deserialize)]
pub struct LegMeta {
    pub market_id: String,
    pub yes_token: String,
    pub no_token: String,
    pub status: Status,
    pub fee_rate: Decimal,
    pub fee_exponent: u8,
    pub tick: Option<Decimal>,
    pub min_size: Option<Decimal>,
    pub seconds_delay: Option<i32>,
    pub end_date: Option<String>,
}

impl LegMeta {
    /// Built from a schedule `FeeSchedule::new` already accepted, so the fallback is unreachable in practice.
    pub fn fee(&self) -> FeeSchedule {
        FeeSchedule::new(self.fee_rate, self.fee_exponent).unwrap_or(FeeSchedule::ZERO)
    }
}

#[derive(Debug, Clone, PartialEq, Eq, Serialize, Deserialize)]
pub struct GroupMeta {
    pub event_id: String,
    pub slug: Option<String>,
    pub title: Option<String>,
    pub neg_risk_market_id: Option<String>,
    pub augmented: bool,
    pub legs: Vec<LegMeta>,
}

impl GroupMeta {
    /// Tokens we subscribe for this group: YES of every live leg (NO is derived by L1).
    pub fn live_yes_tokens(&self) -> Vec<String> {
        self.legs
            .iter()
            .filter(|l| l.status == Status::Live && !l.yes_token.is_empty())
            .map(|l| l.yes_token.clone())
            .collect()
    }
}

#[derive(Debug, Clone, PartialEq, Eq, Serialize, Deserialize)]
pub struct CanaryPair {
    pub market_id: String,
    pub event_id: String,
    pub yes_token: String,
    pub no_token: String,
}

#[derive(Debug, Clone, PartialEq, Eq, Serialize, Deserialize)]
pub struct Universe {
    pub taken_ms: i64,
    pub groups: Vec<GroupMeta>,
    pub canary: Vec<CanaryPair>,
}

fn dec(v: &Option<Value>) -> Option<Decimal> {
    match v {
        Some(Value::String(s)) => Decimal::from_str_exact(s.trim()).ok(),
        Some(Value::Number(n)) => Decimal::from_str_exact(&n.to_string()).ok(),
        _ => None,
    }
}

fn leg_meta(m: &GammaMarket, augmented: bool) -> LegMeta {
    let mut status = Status::from_core(leg_status(m, augmented));
    let (yes_token, no_token) = match token_ids(m) {
        Ok(Some((y, n))) => (y, n),
        _ => {
            if status == Status::Live {
                status = Status::Halted; // can't subscribe → never treat as a tradeable leg
            }
            (String::new(), String::new())
        }
    };
    let (fee_rate, fee_exponent) = match fee_schedule(m) {
        Ok(f) => (f.rate(), f.exponent()),
        Err(_) => {
            if status == Status::Live {
                status = Status::Halted; // unknown fees → can't compute a net edge
            }
            (Decimal::ZERO, 1)
        }
    };
    LegMeta {
        market_id: m.id.clone(),
        yes_token,
        no_token,
        status,
        fee_rate,
        fee_exponent,
        tick: dec(&m.order_price_min_tick_size),
        min_size: dec(&m.order_min_size),
        seconds_delay: dec(&m.seconds_delay).and_then(|d| d.to_i32()),
        end_date: m.end_date.clone(),
    }
}

fn canary_rank(market_id: &str, day: i64) -> u64 {
    let d = Sha256::digest(format!("{market_id}:{day}").as_bytes());
    let mut b = [0u8; 8];
    b.copy_from_slice(&d[..8]);
    u64::from_be_bytes(b)
}

impl Universe {
    pub fn build(events: &[GammaEvent], taken_ms: i64, canary_n: usize) -> Universe {
        let mut groups = Vec::new();
        let mut candidates = Vec::new();
        for e in events {
            if e.is_neg_risk() {
                let augmented = e.is_augmented();
                let legs: Vec<LegMeta> = e.markets().iter().map(|m| leg_meta(m, augmented)).collect();
                if legs.is_empty() {
                    continue;
                }
                groups.push(GroupMeta {
                    event_id: e.id.clone(),
                    slug: e.slug.clone(),
                    title: e.title.clone(),
                    neg_risk_market_id: e.neg_risk_market_id.clone(),
                    augmented,
                    legs,
                });
            } else {
                for m in e.markets() {
                    let l = leg_meta(m, false);
                    if l.status == Status::Live && !l.yes_token.is_empty() {
                        candidates.push(CanaryPair {
                            market_id: l.market_id,
                            event_id: e.id.clone(),
                            yes_token: l.yes_token,
                            no_token: l.no_token,
                        });
                    }
                }
            }
        }
        let day = taken_ms.div_euclid(86_400_000);
        candidates.sort_by_key(|c| (canary_rank(&c.market_id, day), c.market_id.clone()));
        candidates.truncate(canary_n);
        groups.sort_by(|a, b| a.event_id.cmp(&b.event_id));
        Universe {
            taken_ms,
            groups,
            canary: candidates,
        }
    }

    pub fn to_json(&self) -> anyhow::Result<String> {
        Ok(serde_json::to_string(self)?)
    }

    pub fn from_json(s: &str) -> anyhow::Result<Universe> {
        Ok(serde_json::from_str(s)?)
    }

    /// NegRisk groups only (canaries are an integrity sample, not persisted as events).
    pub fn store_rows(&self) -> (Vec<EventRow>, Vec<LegRow>) {
        let mut events = Vec::with_capacity(self.groups.len());
        let mut legs = Vec::new();
        for g in &self.groups {
            events.push(EventRow {
                event_id: g.event_id.clone(),
                slug: g.slug.clone(),
                title: g.title.clone(),
                neg_risk_market_id: g.neg_risk_market_id.clone(),
                augmented: g.augmented,
                n_legs: i32::try_from(g.legs.len()).unwrap_or(i32::MAX),
            });
            for l in &g.legs {
                legs.push(LegRow {
                    market_id: l.market_id.clone(),
                    event_id: g.event_id.clone(),
                    yes_token: l.yes_token.clone(),
                    no_token: l.no_token.clone(),
                    status: l.status.as_str().to_string(),
                    fee_rate: l.fee_rate,
                    fee_exponent: i16::from(l.fee_exponent),
                    tick: l.tick,
                    min_size: l.min_size,
                    seconds_delay: l.seconds_delay,
                    end_date: l.end_date.clone(),
                });
            }
        }
        (events, legs)
    }

    pub fn subscribed_tokens(&self) -> usize {
        self.groups.iter().map(|g| g.live_yes_tokens().len()).sum::<usize>() + 2 * self.canary.len()
    }

    pub fn group_by_event(&self, event_id: &str) -> Option<&GroupMeta> {
        self.groups
            .binary_search_by(|g| g.event_id.as_str().cmp(event_id))
            .ok()
            .map(|i| &self.groups[i])
    }
}

/// An arb-core `Group` for `meta` with the given YES books (keyed by YES token).
pub fn group_with_books(meta: &GroupMeta, books: &HashMap<String, Book>) -> Group {
    Group {
        legs: meta
            .legs
            .iter()
            .map(|l| GroupLeg {
                status: l.status.to_core(),
                book: books.get(&l.yes_token).cloned().unwrap_or_default(),
                fee: l.fee(),
            })
            .collect(),
        augmented: meta.augmented,
    }
}
```

```rust
//! Event-affine shard planning (spec §7, Phase 0 Q7e). A unit (NegRisk group or canary pair) is
//! never split. Hot units (top `hot_events` by message rate) share shards of ≤ hot_shard_tokens,
//! the rest ≤ cold_shard_tokens. At most max_connections shards: once the budget is used, the
//! lowest-priority units are dropped and reported (health.dropped_groups).
use crate::config::ShardsCfg;
use crate::universe::Universe;
use std::collections::{HashMap, HashSet};

#[derive(Debug, Clone, PartialEq, Eq)]
pub struct Unit {
    pub key: String,
    pub tokens: Vec<String>,
    pub rate: u64,
    pub canary: bool,
}

#[derive(Debug, Clone, PartialEq, Eq)]
pub struct Shard {
    pub hot: bool,
    pub units: Vec<String>,
    pub tokens: Vec<String>,
}

#[derive(Debug, Clone, Default, PartialEq, Eq)]
pub struct Plan {
    pub shards: Vec<Shard>,
    pub dropped: Vec<String>,
    pub dropped_tokens: usize,
}

impl Plan {
    pub fn conn_of(&self) -> HashMap<String, usize> {
        let mut m = HashMap::new();
        for (i, s) in self.shards.iter().enumerate() {
            for u in &s.units {
                m.insert(u.clone(), i);
            }
        }
        m
    }

    pub fn tokens(&self) -> usize {
        self.shards.iter().map(|s| s.tokens.len()).sum()
    }
}

pub fn canary_key(market_id: &str) -> String {
    format!("canary:{market_id}")
}

pub fn units(u: &Universe, rates: &HashMap<String, u64>) -> Vec<Unit> {
    let mut out = Vec::new();
    for g in &u.groups {
        let tokens = g.live_yes_tokens();
        if tokens.is_empty() {
            continue;
        }
        out.push(Unit {
            key: g.event_id.clone(),
            tokens,
            rate: rates.get(&g.event_id).copied().unwrap_or(0),
            canary: false,
        });
    }
    for c in &u.canary {
        let key = canary_key(&c.market_id);
        out.push(Unit {
            rate: rates.get(&key).copied().unwrap_or(0),
            key,
            tokens: vec![c.yes_token.clone(), c.no_token.clone()],
            canary: true,
        });
    }
    out
}

pub fn plan(mut units: Vec<Unit>, cfg: &ShardsCfg) -> Plan {
    // Priority: canaries (integrity) → message rate → size (bigger groups carry more baskets) → key.
    units.sort_by(|a, b| {
        b.canary
            .cmp(&a.canary)
            .then(b.rate.cmp(&a.rate))
            .then(b.tokens.len().cmp(&a.tokens.len()))
            .then(a.key.cmp(&b.key))
    });
    let hot: HashSet<String> = units
        .iter()
        .filter(|u| !u.canary && u.rate > 0)
        .take(cfg.hot_events)
        .map(|u| u.key.clone())
        .collect();
    let mut p = Plan::default();
    for u in units {
        let is_hot = hot.contains(&u.key);
        let cap = if is_hot { cfg.hot_shard_tokens } else { cfg.cold_shard_tokens };
        let slot = p
            .shards
            .iter()
            .position(|s| s.hot == is_hot && s.tokens.len() + u.tokens.len() <= cap);
        let idx = match slot {
            Some(i) => i,
            None if p.shards.len() < cfg.max_connections => {
                p.shards.push(Shard { hot: is_hot, units: Vec::new(), tokens: Vec::new() });
                p.shards.len() - 1
            }
            None => {
```

Row semantics (documented here once; reviewers check against this list):
- `kind`: `yes_basket` | `yes_basket_incomplete` | `no_basket`. `realization`: `settlement` | `not_arbitrage` | `converter`.
- `n_outcomes` = all legs; `n_legs` = legs used; `legs_dropped` = live legs not used; `uncovered_legs` = legs neither live nor closed_no; `incomplete_set` = kind is yes_basket_incomplete.

- Peak money: `peak_*` come from the peak state's net quote (conservative fees). `pnl_net_budget100_usd` = the same walk capped at $100 cost. `peak_profit_per_dollar` = pnl / cost (None if cost is 0).
- Bottleneck: the used leg with the smallest walked notional, with that notional.
- Flags: `below_min_size` = q_max < the largest `min_size` among used legs (None if no leg has one); `max_seconds_delay` = max over used legs; `engine_suspect` = the group was under a suspect window (top mismatch, crossed book, drift, or L1 mismatch) at open or at any peak.
- Legs rows: only legs used, `in_s = true`. Token and action: YES token + `buy_yes` for YES baskets, NO token + `buy_no` for NO baskets. `best_price` and `size_at_best` are the first level walked. `vwap` = notional / filled. `fees` = conservative fees recomputed per level for that leg (can differ from the basket's per-segment rounding by ≤ 0.00001 per segment).

```rust
/// Conservative fee of buying `filled` shares on `leg`, rounded up per level (Q3).
fn leg_fee(leg: &BuyLeg, filled: Decimal) -> Decimal {
    let mut left = filled;
    let mut fee = Decimal::ZERO;
    for &(p, q) in &leg.levels {
        if left <= Decimal::ZERO {
            break;
        }
        let take = left.min(q.get());
        fee += leg.fee.fee_conservative(p, take);
        left -= take;
    }
    fee
}

    pub fn apply_universe(&mut self, u: Arc<Universe>, conn_of: &HashMap<String, usize>, ts_ms: i64) -> Vec<Out> {
        let mut out = Vec::new();
        // 1. episodes of events that left the universe: right-censor them (rows built from the OLD universe)
        let keep: HashSet<&str> = u.groups.iter().map(|g| g.event_id.as_str()).collect();
        let mut gone: Vec<(u64, String)> = self
            .open
            .iter()
            .filter(|(_, ep)| !keep.contains(self.universe.groups[ep.group].event_id.as_str()))
            .map(|(id, ep)| (*id, ep.key.clone()))
            .collect();
        gone.sort();
        for (_, key) in gone {
            for e in self.tracker.on_disconnect(&key, ts_ms) {
                self.close_episode(e, &mut out);
            }
        }
        // 2. carry books (by token), suspect windows and open episodes (by event id)
        let mut old_books: HashMap<String, Book> = HashMap::new();
        for (g, meta) in self.universe.groups.iter().enumerate() {
            for (l, leg) in meta.legs.iter().enumerate() {
                if !leg.yes_token.is_empty() {
                    old_books.insert(leg.yes_token.clone(), std::mem::take(&mut self.groups[g].legs[l].book));
                }
            }
        }
        let old_suspect: HashMap<String, i64> = self
            .universe
            .groups
            .iter()
            .zip(&self.suspect_until)
            .map(|(m, &t)| (m.event_id.clone(), t))
            .collect();
        let open_events: Vec<(u64, String)> = self
            .open
            .iter()
            .map(|(id, ep)| (*id, self.universe.groups[ep.group].event_id.clone()))
            .collect();

        let mut index: HashMap<String, usize> = HashMap::new();
        self.groups = Vec::with_capacity(u.groups.len());
        self.token_ix.clear();
        for (g, meta) in u.groups.iter().enumerate() {
            index.insert(meta.event_id.clone(), g);
            let legs = meta
                .legs
                .iter()
                .enumerate()
                .map(|(l, leg)| {
                    if leg.status == Status::Live && !leg.yes_token.is_empty() {
                        self.token_ix.insert(leg.yes_token.clone(), (g, l));
                    }
                    GroupLeg {
                        status: leg.status.to_core(),
                        book: old_books.remove(&leg.yes_token).unwrap_or_default(),
                        fee: leg.fee(),
                    }
                })
                .collect();
            self.groups.push(Group { legs, augmented: meta.augmented });
        }
        let mut canary = HashMap::new();
        for c in &u.canary {
            for t in [&c.yes_token, &c.no_token] {
                let b = self.canary.remove(t).unwrap_or_default();
                canary.insert(t.clone(), b);
            }
        }
        self.canary = canary;
        self.group_conn = u.groups.iter().map(|m| conn_of.get(&m.event_id).copied()).collect();
        self.suspect_until = u
            .groups
            .iter()
            .map(|m| old_suspect.get(&m.event_id).copied().unwrap_or(i64::MIN))
            .collect();
        for (id, ev) in open_events {
            if let (Some(&g), Some(ep)) = (index.get(&ev), self.open.get_mut(&id)) {
                ep.group = g;
            }
        }
        self.universe = u;
        out
    }

    pub fn on_frame(&mut self, conn: usize, recv_ms: i64, events: &[MarketEvent]) -> Vec<Out> {
        let mut out = Vec::new();
        let mut touched: BTreeSet<usize> = BTreeSet::new();
        let mut frame_ts: Option<i64> = None;
        for ev in events {
            match ev {
                MarketEvent::Snapshot { token, server_ts_ms, bids, asks, .. } => {
                    bump(&mut frame_ts, *server_ts_ms);
                    let ts = *server_ts_ms;
                    self.on_book(conn, token, ts, &mut touched, &mut out, |b| {
                        b.apply_snapshot(bids, asks, ts);
                        None
                    });
                }
                MarketEvent::Delta { token, server_ts_ms, side, price, size, best_bid, best_ask } => {
                    bump(&mut frame_ts, *server_ts_ms);
                    let (ts, bb, ba) = (*server_ts_ms, *best_bid, *best_ask);
                    let (side, price, size) = (*side, *price, *size);
                    self.on_book(conn, token, ts, &mut touched, &mut out, |b| {
                        let _ = b.apply_delta(side, price, size, ts);
                        let top = b.top();
                        let ours_bid = top.best_bid.map(|(p, _)| p);
                        let ours_ask = top.best_ask.map(|(p, _)| p);
                        let bad = (bb.is_some() && bb != ours_bid) || (ba.is_some() && ba != ours_ask);
                        bad.then(|| format!("server bid {bb:?} ask {ba:?}; ours bid {ours_bid:?} ask {ours_ask:?}"))
                    });
                }
                MarketEvent::LastTrade { server_ts_ms, .. } | MarketEvent::TickSize { server_ts_ms, .. } => {
                    bump(&mut frame_ts, *server_ts_ms);
                }
                MarketEvent::Resolved { .. } | MarketEvent::NewMarket { .. } => out.push(Out::UniverseChanged),
                MarketEvent::Other { .. } => {}
            }
        }
        let Some(ts) = frame_ts else {
            return out;
        };
        out.push(Out::Lag(recv_ms - ts));
        for g in touched {
            self.evaluate(g, ts, recv_ms, &mut out);
        }
        out
    }

    fn on_book<F>(&mut self, conn: usize, token: &str, ts: i64, touched: &mut BTreeSet<usize>, out: &mut Vec<Out>, f: F)
    where
        F: FnOnce(&mut Book) -> Option<String>,
    {
        let (mismatch, crossed, group) = if let Some(&(g, l)) = self.token_ix.get(token) {
            let b = &mut self.groups[g].legs[l].book;
            let m = f(b);
            let crossed = b.is_crossed();
            touched.insert(g);
            *self.msgs.entry(self.universe.groups[g].event_id.clone()).or_insert(0) += 1;
            (m, crossed, Some(g))
        } else if let Some(b) = self.canary.get_mut(token) {
            let m = f(b);
            (m, b.is_crossed(), None)
        } else {
            return;
        };
        let event_id = group.map(|g| self.universe.groups[g].event_id.clone());
        if let Some(detail) = mismatch {
            out.push(self.integrity(
                ts,
                Issue { kind: "top_mismatch", shard: Some(conn), token: Some(token.to_string()), event_id: event_id.clone(), detail: Some(detail) },
            ));
            out.push(Out::Resnapshot { token: token.to_string() });
            if let Some(g) = group {
                self.suspect(g, ts + self.ctx.suspect_window_ms);
            }
        }
        if crossed {
            out.push(self.integrity(
                ts,
                Issue { kind: "crossed_book", shard: Some(conn), token: Some(token.to_string()), event_id, detail: None },
            ));
            if let Some(g) = group {
                self.suspect(g, ts + self.ctx.suspect_window_ms);
            }
        }
    }

    pub(crate) fn evaluate(&mut self, g: usize, ts: i64, recv_ms: i64, out: &mut Vec<Out>) {
        for det in [Det::Yes, Det::No] {
            let sig = match det {
                Det::Yes => detect_yes_basket(&self.groups[g]),
                Det::No => detect_no_basket(&self.groups[g]),
            };
            let key = Self::key(&self.universe.groups[g], det);
            let pnl = sig.as_ref().filter(|s| s.net_positive()).map(|s| s.quote.pnl);
            let at = At { g, det, ts, recv_ms };
            let mut opened = false;
            for e in self.tracker.on_state(&key, ts, pnl) {
                match e {
                    EpisodeEvent::Open { id, .. } => {
                        if let Some(s) = &sig {
                            self.open_episode(id, &key, at, s, out);
                            opened = true;
                        }
                    }
                    EpisodeEvent::Peak { id, .. } => {
                        if let Some(s) = &sig {
                            self.peak_episode(id, at, s, out);
                        }
                    }
                    close @ EpisodeEvent::Close { .. } => self.close_episode(close, out),
                }
            }
            if pnl.is_some() && !opened {
                if let Some(ep) = self.open_by_key.get(&key).and_then(|id| self.open.get_mut(id)) {
                    ep.n_updates += 1;
                }
            }
        }
    }

    fn snap(&self, at: At, s: &Signal) -> Snap {
        let legs: Vec<BuyLeg> = s
            .legs_used
            .iter()
            .map(|&i| {
                let leg = &self.groups[at.g].legs[i];
                BuyLeg {
                    levels: match at.det {
                        Det::Yes => leg.book.asks_best_first(),
                        Det::No => leg.book.no_asks_best_first(),
                    },
                    fee: leg.fee,
                }
            })
            .collect();
        let rule = match at.det {
            Det::Yes => BasketRule::AllLegs { payoff: Decimal::ONE },
            Det::No => BasketRule::NestedNo,
        };
        let budget100 = walk(&legs, rule, Some(Decimal::from(100))).pnl;
        let best = legs
            .iter()
            .map(|l| l.levels.first().map_or((None, None), |&(p, q)| (Some(p), Some(q))))
            .collect();
        let leg_fees = legs.iter().zip(&s.quote.legs).map(|(l, f)| leg_fee(l, f.filled)).collect();
        Snap { signal: s.clone(), budget100, best, leg_fees, ts_ms: at.ts }
    }

    fn open_episode(&mut self, id: u64, key: &str, at: At, s: &Signal, out: &mut Vec<Out>) {
        let lag = at.recv_ms - at.ts;
        let ep = OpenEp {
            episode_id: format!("{}-{}-{:08}", self.ctx.source, self.ctx.run_id, id),
            key: key.to_string(),
            group: at.g,
            det: at.det,
            opened_ms: at.ts,
            open_lag_ms: lag,
            stale: lag > self.ctx.stale_lag_ms,
            suspect: self.suspect_until[at.g] > at.ts,
            n_updates: 1,
            peak: self.snap(at, s),
        };
        out.push(Out::Episode(self.row(&ep, None)));
        out.push(Out::Recheck(RecheckReq {
            episode_id: ep.episode_id.clone(),
            event_id: self.universe.groups[at.g].event_id.clone(),
            det: at.det,
            opened_ms: at.ts,
            q_max: s.quote.q_max,
        }));
        self.open_by_key.insert(key.to_string(), id);
        self.open.insert(id, ep);
    }

    fn peak_episode(&mut self, id: u64, at: At, s: &Signal, out: &mut Vec<Out>) {
        let snap = self.snap(at, s);
        let suspect_now = self.suspect_until[at.g] > at.ts;
        if let Some(ep) = self.open.get_mut(&id) {
            ep.peak = snap;
            ep.suspect |= suspect_now;
        }
        if let Some(ep) = self.open.get(&id) {
            out.push(Out::Episode(self.row(ep, None)));
        }
    }

    pub(crate) fn close_episode(&mut self, e: EpisodeEvent, out: &mut Vec<Out>) {
        if let EpisodeEvent::Close { id, ts_ms, duration_ms, censor, .. } = e {
            if let Some(ep) = self.open.remove(&id) {
                self.open_by_key.remove(&ep.key);
                out.push(Out::Episode(self.row(&ep, Some((ts_ms, duration_ms, censor)))));
            }
        }
    }

    fn row(&self, ep: &OpenEp, closed: Option<(i64, i64, Censor)>) -> EpisodeWrite {
        let meta = &self.universe.groups[ep.group];
        let s = &ep.peak.signal;
        let q = &s.quote;
        let used = &s.legs_used;
        let live = meta.legs.iter().filter(|l| l.status == Status::Live).count();
        let uncovered = meta
            .legs
            .iter()
            .filter(|l| !matches!(l.status, Status::Live | Status::ClosedNo))

        let bottleneck = q
            .legs
            .iter()
            .enumerate()
            .min_by(|a, b| a.1.notional.cmp(&b.1.notional))
            .map(|(k, f)| (used.get(k).copied().unwrap_or(k), f.notional));
        let min_size = used.iter().filter_map(|&i| meta.legs[i].min_size).max();
        let censor = closed.map(|c| c.2).unwrap_or_default();
        let row = EpisodeRow {
            episode_id: ep.episode_id.clone(),
            run_id: self.ctx.run_id,
            source: self.ctx.source.clone(),
            kind: kind_str(s.kind).to_string(),
            realization: realization_str(s.realization).to_string(),
            event_id: meta.event_id.clone(),
            event_slug: meta.slug.clone(),
            event_title: meta.title.clone(),
            neg_risk_market_id: meta.neg_risk_market_id.clone(),
            pair_id: None,
            category: None,
            n_outcomes: to_i32(meta.legs.len()),
            n_legs: to_i32(used.len()),
            legs_dropped: to_i32(live.saturating_sub(used.len())),
            augmented: meta.augmented,
            incomplete_set: s.kind == Kind::YesBasketIncomplete,

            opened_server_ms: ep.opened_ms,
            closed_server_ms: closed.map(|c| c.0),
            duration_ms: closed.map(|c| c.1),
            censor_left: censor.left,
            censor_right: censor.right,
            censor_gap: censor.gap,
            detect_lag_ms: Some(ep.open_lag_ms),
            n_updates: ep.n_updates,
            peak_server_ms: ep.peak.ts_ms,
            peak_edge_top: q.top_edge,

            peak_max_size: q.q_max,
            peak_cost_usd: q.cost,

            peak_pnl_net_usd: q.pnl,

            pnl_net_budget100_usd: Some(ep.peak.budget100),
            bottleneck_leg_idx: bottleneck.map(|b| to_i32(b.0)),
            bottleneck_notional_usd: bottleneck.map(|b| b.1),
            below_min_size: min_size.map(|m| q.q_max < m),
            max_seconds_delay: used.iter().filter_map(|&i| meta.legs[i].seconds_delay).max(),
            days_to_end: None,
            annualized_return: None,
            post_end: None,
            engine_suspect: ep.suspect,
            stale_transport: ep.stale,

            oracle_downgraded: None,

            config_hash: self.ctx.config_hash.clone(),
        };
        let legs = used
            .iter()
            .enumerate()
            .map(|(k, &i)| {
                let lm = &meta.legs[i];

                let (best_price, size_at_best) = ep.peak.best.get(k).copied().unwrap_or((None, None));

                    fee_exponent: i16::from(lm.fee_exponent),

            .collect();
        EpisodeWrite { row, legs }
    }

    pub fn disconnect(&mut self, conn: usize, ts_ms: i64) -> Vec<Out> {
        let mut out = vec![self.integrity(ts_ms, Issue { kind: "reconnect_gap", shard: Some(conn), ..Issue::default() })];
        for g in 0..self.groups.len() {
            if self.group_conn[g] != Some(conn) {
                continue;
            }
            for det in [Det::Yes, Det::No] {
                let key = Self::key(&self.universe.groups[g], det);
                for e in self.tracker.on_disconnect(&key, ts_ms) {
                    self.close_episode(e, &mut out);
                }
            }
        }
        out
    }

    pub fn close_all(&mut self, ts_ms: i64) -> Vec<Out> {
        let mut out = Vec::new();
        for e in self.tracker.close_all(ts_ms) {
            self.close_episode(e, &mut out);
        }
        out
    }
```

```rust
            .filter(|ep| self.group_conn.get(ep.group).copied().flatten() == Some(conn))

    pub fn book_of(&self, token: &str) -> Option<&Book> {
        match self.token_ix.get(token) {
            Some(&(g, l)) => Some(&self.groups[g].legs[l].book),
            None => self.canary.get(token),
        }
    }

    pub fn rest_snapshot(&mut self, token: &str, book: Book) -> Vec<Out> {
        let mut out = Vec::new();
        let ts = book.server_ts_ms();
        if let Some(&(g, l)) = self.token_ix.get(token) {
            if ts < self.groups[g].legs[l].book.server_ts_ms() {
                return out;
            }
            self.groups[g].legs[l].book = book;
            self.evaluate(g, ts, ts, &mut out);
        } else if let Some(b) = self.canary.get_mut(token) {
            if ts >= b.server_ts_ms() {
                *b = book;
            }
        }
        out
    }

    pub fn drift_check(&mut self, token: &str, rest: Book, now_ms: i64) {
        self.pending_drift.push(PendingDrift {
            token: token.to_string(),
            rest,
            due_ms: now_ms + self.ctx.drift_settle_ms,
        });
    }

    pub fn tick(&mut self, now_ms: i64) -> Vec<Out> {
        let mut out = Vec::new();
        let (due, later): (Vec<PendingDrift>, Vec<PendingDrift>) =
            std::mem::take(&mut self.pending_drift).into_iter().partition(|p| p.due_ms <= now_ms);
        self.pending_drift = later;
        for p in due {
            let Some(ours) = self.book_of(&p.token) else { continue };
            if ours.server_ts_ms() > p.rest.server_ts_ms() {
                continue; // we moved on after the REST snapshot: inconclusive
            }
            if ours.asks_best_first() == p.rest.asks_best_first() && ours.bids_best_first() == p.rest.bids_best_first() {
                continue;
            }
            let event_id = self
                .token_ix
                .get(&p.token)
                .map(|&(g, _)| self.universe.groups[g].event_id.clone());
            out.push(Out::Drift {
                token: p.token.clone(),
                event_id,
                detail: format!(
                    "ws asks {} bids {} vs rest asks {} bids {} (ws ts {} rest ts {})",
                    ours.asks_best_first().len(),
                    ours.bids_best_first().len(),
                    p.rest.asks_best_first().len(),
                    p.rest.bids_best_first().len(),
                    ours.server_ts_ms(),
                    p.rest.server_ts_ms()
                ),
            });
        }
        out
    }
```

```rust
        }

/// UTC (year, month, day, hour) of a millisecond timestamp (Howard Hinnant's civil_from_days).
pub fn civil(ms: i64) -> (i64, u32, u32, u32) {
    let secs = ms.div_euclid(1000);
    let days = secs.div_euclid(86_400);
    let hour = u32::try_from(secs.rem_euclid(86_400) / 3600).unwrap_or(0);
    let z = days + 719_468;
    let era = z.div_euclid(146_097);
    let doe = z - era * 146_097;
    let yoe = (doe - doe / 1460 + doe / 36_524 - doe / 146_096) / 365;
    let doy = doe - (365 * yoe + yoe / 4 - yoe / 100);
    let mp = (5 * doy + 2) / 153;
    let d = u32::try_from(doy - (153 * mp + 2) / 5 + 1).unwrap_or(1);
    let m = u32::try_from(if mp < 10 { mp + 3 } else { mp - 9 }).unwrap_or(1);
    let y = yoe + era * 400 + i64::from(m <= 2);
    (y, m, d, hour)
}

fn day_dir(dir: &Path, ms: i64) -> PathBuf {
    let (y, m, d, _) = civil(ms);
    dir.join(format!("{y:04}-{m:02}-{d:02}"))
}

pub fn hour_path(dir: &Path, ms: i64) -> PathBuf {

}

pub fn book_ctl(token: &str, book: &Book) -> Ctl {
    let lv = |v: Vec<(Price, Shares)>| -> Vec<(String, String)> {
        v.into_iter().map(|(p, s)| (p.get().to_string(), s.get().to_string())).collect()
    };
    Ctl::RestSnapshot {
        token: token.to_string(),
        server_ts_ms: book.server_ts_ms(),
        bids: lv(book.bids_best_first()),
        asks: lv(book.asks_best_first()),
    }
}

pub fn ctl_book(bids: &[(String, String)], asks: &[(String, String)], ts: i64) -> anyhow::Result<Book> {
    let parse = |v: &[(String, String)]| -> anyhow::Result<Vec<(Price, Shares)>> {
        v.iter()
            .map(|(p, s)| -> anyhow::Result<(Price, Shares)> { Ok((Price::parse(p)?, Shares::parse(s)?)) })
            .collect()
    };
    let mut b = Book::default();
    b.apply_snapshot(&parse(bids)?, &parse(asks)?, ts);
    Ok(b)
}

pub struct Writer {
    dir: PathBuf,
    cur: Option<(PathBuf, zstd::stream::AutoFinishEncoder<'static, File>)>,
}

impl Writer {
    pub fn new(dir: PathBuf) -> Writer {
        Writer { dir, cur: None }
    }

    pub fn write(&mut self, msg: &CaptureMsg) -> std::io::Result<()> {
        match msg {
            CaptureMsg::Universe(rec) => {
                let p = universe_path(&self.dir, rec.universe.taken_ms);
                if let Some(parent) = p.parent() {
                    std::fs::create_dir_all(parent)?;
                }
                std::fs::write(&p, serde_json::to_vec(rec.as_ref())?)
            }
            CaptureMsg::Line(line) => {
                let path = hour_path(&self.dir, line.recv_ts_us.div_euclid(1000));
                if self.cur.as_ref().map(|(p, _)| p != &path).unwrap_or(true) {
                    self.cur = None; // finishes the previous hour's zstd frame
                    if let Some(parent) = path.parent() {
                        std::fs::create_dir_all(parent)?;
                    }
                    // Appending after a restart adds a new zstd frame; multi-frame files decode fine.
                    let f = OpenOptions::new().create(true).append(true).open(&path)?;
                    let enc = zstd::Encoder::new(f, 3)?.auto_finish();
                    self.cur = Some((path, enc));
                }
                if let Some((_, enc)) = self.cur.as_mut() {
                    serde_json::to_writer(&mut *enc, line)?;
                    enc.write_all(b"\n")?;
                }
                Ok(())
            }
        }
    }

    pub fn finish(&mut self) {
        self.cur = None;
    }
}

#[derive(Debug, Clone)]
pub struct DiskGuard {
    pause_below: u64,
    resume_above: u64,
    paused: bool,
}

impl DiskGuard {
    pub fn new(pause_below_gb: u64, resume_above_gb: u64) -> DiskGuard {
        let gb = 1_000_000_000_u64;
        DiskGuard {
            pause_below: pause_below_gb.saturating_mul(gb),
            resume_above: resume_above_gb.saturating_mul(gb),
            paused: false,
        }
    }

    pub fn update(&mut self, free_bytes: u64) -> bool {
        if self.paused {
            if free_bytes >= self.resume_above {
                self.paused = false;
            }
        } else if free_bytes < self.pause_below {
            self.paused = true;
        }
        self.paused
    }
}

/// Parse "<dir>/YYYY-MM-DD/HH.jsonl.zst" back to the hour's start in ms.
fn hour_start_ms(day: &str, file: &str) -> Option<i64> {
    let hh: i64 = file.strip_suffix(".jsonl.zst")?.parse().ok()?;
    let mut it = day.split('-');
    let (y, m, d): (i64, i64, i64) = (it.next()?.parse().ok()?, it.next()?.parse().ok()?, it.next()?.parse().ok()?);
    // days_from_civil (inverse of civil)
    let y2 = if m <= 2 { y - 1 } else { y };
    let era = y2.div_euclid(400);
    let yoe = y2 - era * 400;
    let mp = if m > 2 { m - 3 } else { m + 9 };
    let doy = (153 * mp + 2) / 5 + d - 1;
    let doe = yoe * 365 + yoe / 4 - yoe / 100 + doy;
    let days = era * 146_097 + doe - 719_468;
    Some((days * 86_400 + hh * 3600) * 1000)
}

pub fn expired_hours(dir: &Path, now_ms: i64, retention_hours: i64) -> Vec<PathBuf> {
    let cutoff = now_ms - retention_hours * 3_600_000;
    let mut out = Vec::new();
    let Ok(days) = std::fs::read_dir(dir) else { return out };
    for day in days.flatten() {
        let day_name = day.file_name().to_string_lossy().to_string();
        let Ok(files) = std::fs::read_dir(day.path()) else { continue };
        for f in files.flatten() {
            let name = f.file_name().to_string_lossy().to_string();
            if let Some(start) = hour_start_ms(&day_name, &name) {
                if start + 3_600_000 <= cutoff {
                    out.push(f.path());
                }
            }
        }
    }
    out.sort();
    out
}

/// The capture thread: never panics, never blocks the engine (the engine uses try_send).
pub fn spawn(cfg: CaptureCfg, mut rx: tokio::sync::mpsc::Receiver<CaptureMsg>, metrics: Arc<Metrics>) -> std::thread::JoinHandle<()> {
    std::thread::spawn(move || {
        let dir = PathBuf::from(&cfg.dir);
        let mut writer = Writer::new(dir.clone());
        let mut guard = DiskGuard::new(cfg.pause_below_gb, cfg.resume_above_gb);
        let mut last_check = i64::MIN;
        while let Some(msg) = rx.blocking_recv() {
            let now = crate::now_ms();
            if now - last_check >= 30_000 {
                last_check = now;
                if let Ok(free) = fs4::available_space(&dir) {
                    let paused = guard.update(free);
                    if paused {
                        writer.finish();
                    }
                    metrics.capture_paused.store(paused, Ordering::Relaxed);
                }
                for p in expired_hours(&dir, now, cfg.retention_hours) {
                    let _ = std::fs::remove_file(p);
                }
            }
            if metrics.capture_paused.load(Ordering::Relaxed) {
                metrics.capture_drops.fetch_add(1, Ordering::Relaxed);
                continue;
            }
            if let Err(e) = writer.write(&msg) {
                metrics.capture_drops.fetch_add(1, Ordering::Relaxed);
                eprintln!("capture: write failed: {e}");
            }
        }
        writer.finish();
    })
}
```

```rust
//! Replay a capture directory through the engine (spec §8.3). Same engine, same inputs, same outputs.
use crate::capture::{Ctl, Line, UniverseRecord, ctl_book};
use crate::engine::{Engine, EngineCtx, Out};
use anyhow::Context;
use pm_api::ws::parse_frame;
use std::collections::HashMap;
use std::io::{BufRead, BufReader};
use std::path::{Path, PathBuf};
use std::sync::Arc;

#[derive(Debug)]
pub struct ReplayOut {
    pub outs: Vec<Out>,
    pub frames: u64,
    pub parse_errors: u64,
}

fn walk(dir: &Path, hours: &mut Vec<PathBuf>, universes: &mut Vec<PathBuf>) -> anyhow::Result<()> {
    for entry in std::fs::read_dir(dir).with_context(|| format!("read {}", dir.display()))? {
        let p = entry?.path();
        if p.is_dir() {
            walk(&p, hours, universes)?;
        } else {
            let name = p.file_name().map(|n| n.to_string_lossy().to_string()).unwrap_or_default();
            if name.ends_with(".jsonl.zst") {
                hours.push(p);
            } else if name.starts_with("universe-") && name.ends_with(".json") {
                universes.push(p);
            }
        }
    }
    Ok(())
}

pub fn replay_dir(dir: &Path, ctx: EngineCtx) -> anyhow::Result<ReplayOut> {
    let (mut hours, mut ufiles) = (Vec::new(), Vec::new());
    walk(dir, &mut hours, &mut ufiles)?;
    hours.sort();
    let mut universes: HashMap<i64, UniverseRecord> = HashMap::new();
    for f in ufiles {
        let rec: UniverseRecord = serde_json::from_slice(&std::fs::read(&f)?).with_context(|| format!("parse {}", f.display()))?;
        universes.insert(rec.universe.taken_ms, rec);
    }
    let mut engine = Engine::new(ctx);
    let mut out = ReplayOut { outs: Vec::new(), frames: 0, parse_errors: 0 };
    let mut last_ms = 0_i64;
    let mut shut_down = false;
    for h in hours {
        let reader = BufReader::new(zstd::Decoder::new(std::fs::File::open(&h)?)?);
        for text in reader.lines() {
            let text = text?;
            if text.trim().is_empty() {
                continue;
            }
            let line: Line = serde_json::from_str(&text).with_context(|| format!("bad capture line in {}", h.display()))?;
            let ms = line.recv_ts_us.div_euclid(1000);
            last_ms = last_ms.max(ms);
            if let Some(raw) = &line.raw {
                out.frames += 1;
                match parse_frame(raw) {
                    Ok(evs) => {
                        out.outs.extend(engine.on_frame(line.shard, ms, &evs));
                        engine.alive(line.shard, ms);
                    }
                    Err(_) => out.parse_errors += 1,
                }
            }
            match line.ctl {
                None => {}
                Some(Ctl::Down) => out.outs.extend(engine.disconnect(line.shard, ms)),
                Some(Ctl::Universe { taken_ms }) => {
                    let rec = universes.get(&taken_ms).with_context(|| format!("missing universe-{taken_ms}.json"))?;
                    let conn: HashMap<String, usize> = rec.conn_of.iter().map(|(k, v)| (k.clone(), *v)).collect();
                    out.outs.extend(engine.apply_universe(Arc::new(rec.universe.clone()), &conn, ms));
                }
                Some(Ctl::RestSnapshot { token, server_ts_ms, bids, asks }) => {
                    let b = ctl_book(&bids, &asks, server_ts_ms)?;
                    out.outs.extend(engine.rest_snapshot(&token, b));
                }
                Some(Ctl::Suspect { event_id, until_ms }) => engine.mark_suspect(&event_id, until_ms),
                Some(Ctl::Shutdown) => {
                    out.outs.extend(engine.close_all(ms));
                    shut_down = true;
                }
            }
        }
```

```rust
//! Batching store writer (spec §8.2/§10): one transaction per flush interval. A transiently failed
//! write keeps the batch and retries with backoff; receiving never stops, so the engine never blocks
//! on Postgres. A batch Postgres rejects for its DATA (`StoreError::is_data_error`, SQLSTATE 22/23)
//! is quarantined row by row so one poison row can't stall every later flush. Above `max_rows`, the
//! oldest health, then integrity, then observation rows are dropped and counted (episodes never are,
//! except a single episode row Postgres itself rejects).
use std::collections::HashMap;
use std::time::Duration;
use store::{Batch, EpisodeWrite, HealthRow, IntegrityRow, ObservationRow, Store};
use tokio::sync::{mpsc, oneshot};

#[derive(Debug)]
pub enum WriterMsg {
    Episode(EpisodeWrite),
    Observation(ObservationRow),
    Integrity(IntegrityRow),
    Health(HealthRow),
    Flush(oneshot::Sender<()>),
}

#[derive(Debug, Default)]
pub struct Pending {
    batch: Batch,
    ep_index: HashMap<String, usize>,
    max_rows: usize,
    pub dropped: u64,
}

impl Pending {
    pub fn new(max_rows: usize) -> Pending {
        Pending { max_rows, ..Pending::default() }
    }

    pub fn rows(&self) -> usize {
        self.batch.episodes.len() + self.batch.observations.len() + self.batch.integrity.len() + self.batch.health.len()
    }

    fn upsert_episode(&mut self, w: EpisodeWrite, overwrite: bool) {
        match self.ep_index.get(&w.row.episode_id) {
            Some(&i) => {
                if overwrite {
                    self.batch.episodes[i] = w;
                }
            }
            None => {
                self.ep_index.insert(w.row.episode_id.clone(), self.batch.episodes.len());
                self.batch.episodes.push(w);
            }
        }
    }

    pub fn push(&mut self, m: WriterMsg) {
        match m {
            WriterMsg::Episode(w) => self.upsert_episode(w, true),
            WriterMsg::Observation(o) => self.batch.observations.push(o),
            WriterMsg::Integrity(i) => self.batch.integrity.push(i),
            WriterMsg::Health(h) => self.batch.health.push(h),
            WriterMsg::Flush(_) => {}
        }
        self.enforce_cap();
    }

    fn enforce_cap(&mut self) {
        while self.rows() > self.max_rows {
            if !self.batch.health.is_empty() {
                self.batch.health.remove(0);
            } else if !self.batch.integrity.is_empty() {
                self.batch.integrity.remove(0);
            } else if !self.batch.observations.is_empty() {
                self.batch.observations.remove(0);
            } else {
                break; // only episodes left: never dropped
            }
            self.dropped += 1;
        }
    }

    pub fn take(&mut self) -> Batch {
        self.ep_index.clear();
        std::mem::take(&mut self.batch)
    }

    /// Put back a batch whose write failed. It is OLDER than anything pushed since, so newer
    /// episode versions already here win, and its other rows go first.
    pub fn restore(&mut self, older: Batch) {
        let newer = self.take();
        for w in older.episodes {
            self.upsert_episode(w, false);
        }
        for w in newer.episodes {
            self.upsert_episode(w, true);
        }
        // fix ordering: older episode versions were inserted first, newer overwrote them in place
        self.batch.observations = older.observations.into_iter().chain(newer.observations).collect();
        self.batch.integrity = older.integrity.into_iter().chain(newer.integrity).collect();
        self.batch.health = older.health.into_iter().chain(newer.health).collect();
        self.enforce_cap();
    }
}

pub async fn run_writer(store: Store, mut rx: mpsc::Receiver<WriterMsg>, flush_ms: u64, max_rows: usize) {
    let mut pending = Pending::new(max_rows);
    let mut tick = tokio::time::interval(Duration::from_millis(flush_ms.max(10)));
    tick.set_missed_tick_behavior(tokio::time::MissedTickBehavior::Delay);
    let mut fails: u32 = 0;
    let mut retry_at = tokio::time::Instant::now();
    loop {
        tokio::select! {
            m = rx.recv() => match m {
                Some(WriterMsg::Flush(done)) => {
                    flush(&store, &mut pending, &mut fails).await;
                    let _ = done.send(());
                }
                Some(other) => pending.push(other),
                None => {
                    for _ in 0..3 {
                        if flush(&store, &mut pending, &mut fails).await {
                            break;
                        }
                        tokio::time::sleep(Duration::from_secs(1)).await;
                    }
                    return;
                }
            },
            _ = tick.tick() => {
                if pending.rows() > 0 && tokio::time::Instant::now() >= retry_at && !flush(&store, &mut pending, &mut fails).await {
                    let backoff = Duration::from_millis((100_u64 << fails.min(8)).min(30_000));
                    retry_at = tokio::time::Instant::now() + backoff;
                }
            }
        }
    }
}

/// Write each row of a data-rejected batch on its own; returns how many rows still failed (dropped).
/// Episodes go first so observations referencing them can still land.
async fn quarantine(store: &Store, b: Batch) -> u64 {
    let mut dropped = 0;
    let one = |batch: Batch| async move { store.write_batch(&batch).await };
    for w in b.episodes {
        let id = w.row.episode_id.clone();
        if let Err(e) = one(Batch { episodes: vec![w], ..Batch::default() }).await {
            eprintln!("writer: dropped episode {id}: {e}");
            dropped += 1;
        }
    }
    for o in b.observations {
        if one(Batch { observations: vec![o], ..Batch::default() }).await.is_err() {
            dropped += 1;
        }
    }
    for i in b.integrity {
        if one(Batch { integrity: vec![i], ..Batch::default() }).await.is_err() {
            dropped += 1;
        }
    }
    for h in b.health {
        if one(Batch { health: vec![h], ..Batch::default() }).await.is_err() {
            dropped += 1;
        }
    }
    dropped
}

/// Write the pending batch once. Transient failure → restore it for a retry; data error →
/// quarantine it row by row. Returns true when nothing is left to retry.
async fn flush(store: &Store, pending: &mut Pending, fails: &mut u32) -> bool {
    if pending.rows() == 0 {
        return true;
    }
    let b = pending.take();
    match tokio::time::timeout(Duration::from_secs(10), store.write_batch(&b)).await {
        Ok(Ok(())) => {
            *fails = 0;
            true
        }
        Ok(Err(e)) if e.is_data_error() => {
            // Postgres rejected the DATA (SQLSTATE 22/23): retrying the same batch can never succeed.
            // Quarantine: write row by row, drop (and log) only the rows that still fail.
            let dropped = quarantine(store, b).await;
            pending.dropped += dropped;
            eprintln!("writer: data error ({e}); quarantined batch, dropped {dropped} rows");
            *fails = 0;
            true
        }
        Ok(Err(e)) => {
            eprintln!("writer: batch failed ({} rows): {e}", b.episodes.len() + b.observations.len() + b.integrity.len() + b.health.len());
            pending.restore(b);
            *fails += 1;
            false
        }
        Err(_) => {
            eprintln!("writer: batch timed out");
            pending.restore(b);
            *fails += 1;
            false
        }
    }
}
```

```rust
//! Websocket shards (spec §7, §8.1.2). Each shard reconnects on its own with backoff + jitter
//! (1 s → 60 s, reset only after a session > 30 s). ONE global budget gates every connection
//! attempt across shards (≤ 2/s, ≤ 20/min). K failures in W minutes park the shard until the next
//! universe refresh.
use crate::config::ConnectCfg;
use crate::metrics::Metrics;
use crate::now_ms;
use crate::shards::Plan;
use pm_api::backoff::{Backoff, ConnectBudget};
use pm_api::ws::{Frame, run_connection};
use std::collections::VecDeque;
use std::sync::atomic::Ordering;
use std::sync::{Arc, Mutex};
use std::time::Duration;
use tokio::sync::mpsc;
use tokio::task::JoinHandle;

#[derive(Debug)]
pub enum FeedMsg {
    Frame(Frame),
    Up { conn: usize },
    Down { conn: usize, reason: String },
    Parked { conn: usize },
}

#[derive(Debug, Clone)]
pub struct Parking {
    max: usize,
    window_ms: i64,
    fails: VecDeque<i64>,
}

impl Parking {
    pub fn new(max_failures: usize, window_ms: i64) -> Parking {
        Parking { max: max_failures.max(1), window_ms, fails: VecDeque::new() }
    }

    pub fn record(&mut self, now_ms: i64) -> bool {
        self.fails.push_back(now_ms);
        while self.fails.front().is_some_and(|&t| now_ms - t > self.window_ms) {
            self.fails.pop_front();
        }
        self.fails.len() >= self.max
    }
}

/// 80–120 % of `delay_ms`, from a cheap deterministic hash of (conn, attempt).
pub fn jittered(delay_ms: u64, conn: usize, attempt: u32) -> u64 {
    let mut h: u64 = 0xcbf2_9ce4_8422_2325;
    for b in (conn as u64).to_le_bytes().into_iter().chain(attempt.to_le_bytes()) {
        h ^= u64::from(b);
        h = h.wrapping_mul(0x0100_0000_01b3);
    }
    let pct = 80 + h % 41; // 80..=120
    delay_ms.saturating_mul(pct) / 100
}

pub fn needs_restart(old: Option<&[String]>, finished: bool, new: &[String]) -> bool {
    match old {
        None => true,
        Some(t) => finished || t != new,
    }
}

fn take_budget(budget: &Mutex<ConnectBudget>) -> bool {
    budget.lock().unwrap_or_else(|p| p.into_inner()).try_take(now_ms())
}

pub fn spawn_shard(
    conn: usize,
    tokens: Vec<String>,
    shared: mpsc::Sender<FeedMsg>,
    budget: Arc<Mutex<ConnectBudget>>,
    cfg: ConnectCfg,
    capacity: usize,
    metrics: Arc<Metrics>,
) -> JoinHandle<()> {
    tokio::spawn(async move {
        let mut backoff = Backoff::new(cfg.backoff_base_ms, cfg.backoff_cap_ms, cfg.healthy_session_ms);
        let mut parking = Parking::new(cfg.park_after_failures, cfg.park_window_secs * 1000);
        let mut attempt: u32 = 0;
        loop {
            while !take_budget(&budget) {
                tokio::time::sleep(Duration::from_millis(250)).await;
            }
            let started = now_ms();
            backoff.on_connected(started);
            if shared.send(FeedMsg::Up { conn }).await.is_err() {
                return;
            }
            let (ftx, mut frx) = mpsc::channel::<Frame>(capacity.max(1));
            let fwd_shared = shared.clone();
            let fwd = tokio::spawn(async move {
                while let Some(f) = frx.recv().await {
                    if fwd_shared.send(FeedMsg::Frame(f)).await.is_err() {
                        break;
                    }
                }
            });
            let result = run_connection(conn, tokens.clone(), ftx).await;
            let _ = fwd.await; // all of this session's frames are in `shared` before Down
            let ended = now_ms();
            if matches!(result, Err(pm_api::ApiError::Dropped { .. })) {
                metrics.drops.fetch_add(1, Ordering::Relaxed);
            }
            metrics.reconnects.fetch_add(1, Ordering::Relaxed);
            let reason = match &result {
                Ok(()) => "closed".to_string(),
                Err(e) => e.to_string(),
            };
            if shared.send(FeedMsg::Down { conn, reason }).await.is_err() {
                return;
            }
            let failed = result.is_err() || ended - started < cfg.healthy_session_ms;
            if failed && parking.record(ended) {
                metrics.parked.fetch_add(1, Ordering::Relaxed);
                let _ = shared.send(FeedMsg::Parked { conn }).await;
                return;
            }
            let delay = backoff.on_disconnected(ended);
            attempt = attempt.saturating_add(1);
            tokio::time::sleep(Duration::from_millis(jittered(delay, conn, attempt))).await;
        }
    })
}

pub struct Supervisor {
    handles: Vec<(Vec<String>, JoinHandle<()>)>,
    shared: mpsc::Sender<FeedMsg>,
    budget: Arc<Mutex<ConnectBudget>>,
    cfg: ConnectCfg,
    capacity: usize,
    metrics: Arc<Metrics>,
}

impl Supervisor {
    pub fn new(shared: mpsc::Sender<FeedMsg>, budget: Arc<Mutex<ConnectBudget>>, cfg: ConnectCfg, capacity: usize, metrics: Arc<Metrics>) -> Supervisor {
        Supervisor { handles: Vec::new(), shared, budget, cfg, capacity, metrics }
    }

    pub async fn apply(&mut self, plan: &Plan) {
        while self.handles.len() > plan.shards.len() {
            if let Some((_, h)) = self.handles.pop() {
                let running = !h.is_finished();
                h.abort();
                if running {
                    let conn = self.handles.len();
                    let _ = self.shared.send(FeedMsg::Down { conn, reason: "shard removed".into() }).await;
                }
            }
        }
        let parked_before = self.handles.iter().filter(|(_, h)| h.is_finished()).count() as u64;
        for (i, s) in plan.shards.iter().enumerate() {
            let (old, finished) = match self.handles.get(i) {
                Some((t, h)) => (Some(t.as_slice()), h.is_finished()),
                None => (None, false),
            };
            if !needs_restart(old, finished, &s.tokens) {
                continue;
            }
            if let Some((_, h)) = self.handles.get(i) {
                if !h.is_finished() {
                    h.abort();
                    let _ = self.shared.send(FeedMsg::Down { conn: i, reason: "resharded".into() }).await;
                }
            }
            let h = spawn_shard(i, s.tokens.clone(), self.shared.clone(), self.budget.clone(), self.cfg.clone(), self.capacity, self.metrics.clone());
            if i < self.handles.len() {
                self.handles[i] = (s.tokens.clone(), h);
            } else {
                self.handles.push((s.tokens.clone(), h));
            }
        }
        let _ = self.metrics.parked.fetch_update(Ordering::Relaxed, Ordering::Relaxed, |p| Some(p.saturating_sub(parked_before)));
        self.metrics.shards.store(plan.shards.len() as u64, Ordering::Relaxed);
        self.metrics.tokens.store(plan.tokens() as u64, Ordering::Relaxed);
        self.metrics.dropped_groups.store(plan.dropped.len() as u64, Ordering::Relaxed);
    }

    pub fn abort_all(&mut self) {
        for (_, h) in self.handles.drain(..) {
            h.abort();
        }
    }
}
```

```rust
pub async fn fetch_books(clob: &ClobClient, limiter: &Limiter, tokens: &[String]) -> Result<HashMap<String, Book>, String> {

pub fn observe(req: &RecheckReq, offset_ms: i64, meta: Option<&GroupMeta>, books: Result<HashMap<String, Book>, String>) -> ObservationRow {
    let base = ObservationRow {
        episode_id: req.episode_id.clone(),
        offset_ms: i32::try_from(offset_ms).unwrap_or(i32::MAX),
        source: "rest".into(),
        observed_ms: None,
        skipped: true,
        skip_reason: None,
        edge: None,
        q_max: None,
        pnl: None,
        still_profitable: None,
        fill_at_original_size: None,
    };
    let Some(meta) = meta else {
        return ObservationRow { skip_reason: Some("event left the universe".into()), ..base };
    };
    let books = match books {
        Ok(b) => b,
        Err(e) => return ObservationRow { skip_reason: Some(e), ..base },
    };
    let missing = meta.live_yes_tokens().iter().filter(|t| !books.contains_key(*t)).count();
    if missing > 0 {
        return ObservationRow { skip_reason: Some(format!("{missing} books missing")), ..base };
    }
    let observed_ms = books.values().map(|b| b.server_ts_ms()).max();
    let g = group_with_books(meta, &books);
    let sig = match req.det {
        Det::Yes => detect_yes_basket(&g),
        Det::No => detect_no_basket(&g),
    };
    match sig {
        Some(s) => ObservationRow {
            observed_ms,
            skipped: false,
            edge: Some(s.quote.top_edge),
            q_max: Some(s.quote.q_max),
            pnl: Some(s.quote.pnl),
            still_profitable: Some(s.net_positive()),
            fill_at_original_size: Some(s.quote.q_max >= req.q_max),
            ..base
        },
        // no gross-positive basket at all: the walk takes nothing, a measured zero
        None => ObservationRow {
            observed_ms,
            skipped: false,
            q_max: Some(Decimal::ZERO),
            pnl: Some(Decimal::ZERO),
            still_profitable: Some(false),
            fill_at_original_size: Some(false),
            ..base
        },
    }
}

pub fn mirror_ok(yes: &Book, no: &Book) -> bool {
    yes.no_asks_best_first() == no.asks_best_first() && yes.no_bids_best_first() == no.bids_best_first()
}

pub fn next_batch(len: usize, cursor: usize, n: usize) -> (Vec<usize>, usize) {
    if len == 0 {
        return (Vec::new(), 0);
    }
    let take = n.min(len);
    let start = cursor % len;
    let idx: Vec<usize> = (0..take).map(|k| (start + k) % len).collect();
    (idx, (start + take) % len)
}

pub async fn run_rechecks(
    mut rx: mpsc::Receiver<RecheckReq>,
    universe: watch::Receiver<Arc<Universe>>,
    clob: Arc<ClobClient>,
    limiter: Arc<Limiter>,
    offsets: Vec<i64>,
    writer: mpsc::Sender<WriterMsg>,
) {
    while let Some(req) = rx.recv().await {
        let (universe, clob, limiter, writer) = (universe.clone(), clob.clone(), limiter.clone(), writer.clone());
        let mut offs = offsets.clone();
        let received = now_ms();
        tokio::spawn(async move {
            // spec §8.2: also re-check at +Δd (max secondsDelay over the group's legs) when > 0
            let delay_ms = universe
                .borrow()
                .group_by_event(&req.event_id)
                .and_then(|m| m.legs.iter().filter_map(|l| l.seconds_delay).max())
                .map(|s| i64::from(s) * 1000)
                .unwrap_or(0);
            if delay_ms > 0 {
                offs.push(delay_ms);
            }
            offs.sort_unstable();
            offs.dedup();
            for off in offs {
                let wait = (received + off - now_ms()).max(0);
                tokio::time::sleep(Duration::from_millis(u64::try_from(wait).unwrap_or(0))).await;
                let meta = universe.borrow().group_by_event(&req.event_id).cloned();
                let books = match &meta {
                    Some(m) => fetch_books(&clob, &limiter, &m.live_yes_tokens()).await,
                    None => Ok(HashMap::new()),
                };
                let row = observe(&req, off, meta.as_ref(), books);
                if writer.send(WriterMsg::Observation(row)).await.is_err() {
                    return;
                }
            }
        });
    }
}

pub async fn run_resnapshots(mut rx: mpsc::Receiver<String>, clob: Arc<ClobClient>, limiter: Arc<Limiter>, cmd: mpsc::Sender<CheckCmd>) {

                if let Some(book) = books.remove(&token) {

                        return;
                    }
                }
            }
            Err(e) => eprintln!("resnapshot {token}: {e}"),
        }
    }
}

pub async fn run_samplers(
    universe: watch::Receiver<Arc<Universe>>,
    clob: Arc<ClobClient>,
    limiter: Arc<Limiter>,
    cfg: RecheckCfg,
    cmd: mpsc::Sender<CheckCmd>,
    metrics: Arc<Metrics>,
) {
    let mut minute = tokio::time::interval(Duration::from_secs(60));
    let mut ok_tick = tokio::time::interval(Duration::from_secs(5));
    minute.set_missed_tick_behavior(tokio::time::MissedTickBehavior::Delay);
    ok_tick.set_missed_tick_behavior(tokio::time::MissedTickBehavior::Delay);
    let (mut drift_cursor, mut l1_cursor) = (0usize, 0usize);
    loop {
        tokio::select! {
            _ = ok_tick.tick() => {
                limiter.wait().await;
                let t = now_ms();
                let ok = clob.ok().await.unwrap_or(false);
                metrics.push_rest(now_ms() - t);
                metrics.set_ok(ok);
            }
            _ = minute.tick() => {
                let u = universe.borrow().clone();
                // drift: rotate through every subscribed token
                let tokens: Vec<String> = u
                    .groups
                    .iter()
                    .flat_map(|g| g.live_yes_tokens())
                    .chain(u.canary.iter().flat_map(|c| [c.yes_token.clone(), c.no_token.clone()]))
                    .collect();
                let (idx, next) = next_batch(tokens.len(), drift_cursor, cfg.drift_tokens_per_min);
                drift_cursor = next;
                let pick: Vec<String> = idx.into_iter().map(|i| tokens[i].clone()).collect();
                if let Ok(books) = fetch_books(&clob, &limiter, &pick).await {
                    for (token, book) in books {
                        if cmd.send(CheckCmd::Drift { token, book }).await.is_err() {
                            return;
                        }
                    }
                }
                // L1: rotate through live NegRisk legs, YES and NO books from REST
                let legs: Vec<(String, String, String)> = u
                    .groups
                    .iter()
                    .flat_map(|g| {
                        g.legs
                            .iter()
                            .filter(|l| l.status == Status::Live && !l.yes_token.is_empty() && !l.no_token.is_empty())
                            .map(|l| (g.event_id.clone(), l.yes_token.clone(), l.no_token.clone()))
                            .collect::<Vec<_>>()
                    })
                    .chain(u.canary.iter().map(|c| (c.event_id.clone(), c.yes_token.clone(), c.no_token.clone())))
                    .collect();
                let (idx, next) = next_batch(legs.len(), l1_cursor, cfg.l1_legs_per_min);
                l1_cursor = next;
                let pick: Vec<&(String, String, String)> = idx.iter().map(|&i| &legs[i]).collect();
                let toks: Vec<String> = pick.iter().flat_map(|(_, y, n)| [y.clone(), n.clone()]).collect();
                if let Ok(books) = fetch_books(&clob, &limiter, &toks).await {
                    for (event_id, y, n) in pick {
                        if let (Some(yb), Some(nb)) = (books.get(y), books.get(n)) {
                            if !mirror_ok(yb, nb) {
                                let detail = format!("L1 mirror mismatch yes={y} no={n}");
                                if cmd.send(CheckCmd::L1Mismatch { event_id: event_id.clone(), detail }).await.is_err() {
                                    return;
                                }
                            }
                        }
                    }
                }
            }
        }
    }
}
```

```rust
async fn shutdown_signal() {
    #[cfg(unix)]
    {
        use tokio::signal::unix::{SignalKind, signal};
        match signal(SignalKind::terminate()) {
            Ok(mut term) => {
                tokio::select! {
                    _ = tokio::signal::ctrl_c() => {}
                    _ = term.recv() => {}
                }
            }
            Err(_) => {
                let _ = tokio::signal::ctrl_c().await;
            }
        }
    }
    #[cfg(not(unix))]
    {
        let _ = tokio::signal::ctrl_c().await;
    }
}

pub async fn run(cfg: Config, cfg_hash: String) -> anyhow::Result<()> {
    let url = std::env::var("DATABASE_URL").context("DATABASE_URL (role scanner_rw) is not set")?;
    let store = Store::connect(&url, 5).await?;
    let starts = store.starts_since("scanner", now_ms() - cfg.breaker.window_secs * 1000).await?;
    if breaker_trips(starts, cfg.breaker.max_starts) {
        let id = store.start_run(&new_run(&cfg_hash, "safe")).await?;
        let reason = format!(
            "safe mode: {starts} starts in the last {} s (crash-loop breaker); no connections made. \
             Fix the cause, then `scanner breaker reset`",
            cfg.breaker.window_secs
        );
        store.end_run(id, now_ms(), &reason).await?;
        eprintln!("scanner: {reason}");
        return Ok(()); // exit 0: compose `on-failure` does not restart a clean exit
    }
    let run_id = store.start_run(&new_run(&cfg_hash, "live")).await?;
    let result = run_live(&cfg, &cfg_hash, &store, run_id).await;
    let reason = match &result {
        Ok(()) => "shutdown".to_string(),
        Err(e) => format!("error: {e:#}"),
    };
    let _ = store.end_run(run_id, now_ms(), &reason).await;
    result
}

struct Io {
    writer: mpsc::Sender<WriterMsg>,
    capture: mpsc::Sender<CaptureMsg>,
    recheck: mpsc::Sender<RecheckReq>,
    resnap: mpsc::Sender<String>,
    refresh: Arc<tokio::sync::Notify>,
    metrics: Arc<Metrics>,
    run_id: i64,
    l1_window_ms: i64,
    suspect_window_ms: i64,
}

impl Io {
    fn capture(&self, line: Line) {
        if self.capture.try_send(CaptureMsg::Line(line)).is_err() {
            self.metrics.capture_drops.fetch_add(1, Ordering::Relaxed);
        }
    }

    /// Capture a control input stamped `t_ms`, the SAME instant the engine is given for it,
    /// so replay reproduces closes and censoring to the millisecond.
    fn ctl(&self, shard: usize, ctl: Ctl, t_ms: i64) {
        self.capture(Line { recv_ts_us: t_ms * 1000, shard, raw: None, ctl: Some(ctl) });
    }

    fn integrity(&self, kind: &str, token: Option<String>, event_id: Option<String>, detail: String) -> IntegrityRow {
        IntegrityRow { run_id: self.run_id, ts_ms: now_ms(), kind: kind.into(), shard: None, token, event_id, detail: Some(detail) }
    }

    async fn route(&self, engine: &mut Engine, outs: Vec<Out>) -> anyhow::Result<()> {
        for o in outs {
            match o {
                Out::Episode(w) => self.writer.send(WriterMsg::Episode(w)).await.context("writer gone")?,
                Out::Integrity(i) => self.writer.send(WriterMsg::Integrity(i)).await.context("writer gone")?,
                Out::Recheck(r) => {
                    let _ = self.recheck.try_send(r);
                }
                Out::Resnapshot { token } => {
                    let _ = self.resnap.try_send(token);
                }
                Out::UniverseChanged => self.refresh.notify_one(),
                Out::Lag(ms) => self.metrics.push_lag(ms),
                Out::Drift { token, event_id, detail } => {
                    self.writer
                        .send(WriterMsg::Integrity(self.integrity("drift", Some(token.clone()), event_id.clone(), detail)))
                        .await
                        .context("writer gone")?;
                    let _ = self.resnap.try_send(token);
                    if let Some(ev) = event_id {
                        let t = now_ms();
                        let until = t + self.suspect_window_ms;
                        engine.mark_suspect(&ev, until);
                        self.ctl(0, Ctl::Suspect { event_id: ev, until_ms: until }, t);
                    }
                }
            }
        }
        Ok(())
    }
}

async fn run_live(cfg: &Config, cfg_hash: &str, store: &Store, run_id: i64) -> anyhow::Result<()> {
    let metrics = Arc::new(Metrics::default());
    std::fs::create_dir_all(&cfg.capture.dir).with_context(|| format!("create {}", cfg.capture.dir))?;

    // Universe: warm start or fresh (spec §8.1.2)
    let now = now_ms();
    let warm = match store.latest_universe().await? {
        Some(s) if warm_start_usable(s.taken_ms, now, i64::try_from(cfg.universe.warm_start_max_age_secs).unwrap_or(0) * 1000) => {
            Universe::from_json(&s.body).ok()
        }
        _ => None,
    };
    let universe = match warm {
        Some(u) => u,
        None => {
            let u = fetch_universe(cfg).await?;
            persist_universe(store, &u).await?;
            u
        }
    };
    let universe = Arc::new(universe);
    let plan = shards::plan(shards::units(&universe, &HashMap::new()), &cfg.shards);

    // Channels
    let (feed_tx, mut feed_rx) = mpsc::channel::<FeedMsg>(cfg.engine.channel_capacity);
    let (cmd_tx, mut cmd_rx) = mpsc::channel::<EngineCmd>(1024);
    let (check_tx, mut check_rx) = mpsc::channel::<CheckCmd>(4096);
    let (writer_tx, writer_rx) = mpsc::channel::<WriterMsg>(65_536);
    let (capture_tx, capture_rx) = mpsc::channel::<CaptureMsg>(65_536);
    let (recheck_tx, recheck_rx) = mpsc::channel::<RecheckReq>(4096);
    let (resnap_tx, resnap_rx) = mpsc::channel::<String>(4096);
    let (plan_tx, mut plan_rx) = mpsc::channel::<Plan>(8);
    let (u_tx, u_rx) = watch::channel(universe.clone());
    let refresh = Arc::new(tokio::sync::Notify::new());

    // Tasks
    let writer_task = tokio::spawn(writer::run_writer(store.clone(), writer_rx, cfg.store.flush_ms, cfg.store.max_pending_rows));
    let capture_thread = capture::spawn(cfg.capture.clone(), capture_rx, metrics.clone());
    let clob = Arc::new(ClobClient::new()?);
    let limiter = Arc::new(Limiter::new(cfg.recheck.rest_per_sec));
    tokio::spawn(checks::run_rechecks(recheck_rx, u_rx.clone(), clob.clone(), limiter.clone(), cfg.recheck.offsets_ms.clone(), writer_tx.clone()));
    tokio::spawn(checks::run_resnapshots(resnap_rx, clob.clone(), limiter.clone(), check_tx.clone()));
    tokio::spawn(checks::run_samplers(u_rx.clone(), clob.clone(), limiter.clone(), cfg.recheck.clone(), check_tx.clone(), metrics.clone()));
    {
        // health: one row per minute
        let (metrics, writer_tx) = (metrics.clone(), writer_tx.clone());
        tokio::spawn(async move {
            let mut t = tokio::time::interval(Duration::from_secs(60));
            t.tick().await;
            loop {
                t.tick().await;
                let minute = now_ms().div_euclid(60_000) * 60_000;
                if writer_tx.send(WriterMsg::Health(metrics.minute_row(run_id, minute))).await.is_err() {
                    return;
                }
            }
        });
    }
    let budget = Arc::new(Mutex::new(ConnectBudget::new(cfg.connect.per_sec, cfg.connect.per_min)));
    let supervisor_task = {
        let mut sup = Supervisor::new(feed_tx.clone(), budget, cfg.connect.clone(), cfg.shards.per_shard_capacity, metrics.clone());
        tokio::spawn(async move {
            while let Some(p) = plan_rx.recv().await {
                sup.apply(&p).await;
            }
            sup.abort_all();
        })
    };
    {
        // refresher (spec §7: every 5 min, and on new_market / market_resolved)
        let (cfg, store, cmd_tx, plan_tx, u_tx, refresh) = (cfg.clone(), store.clone(), cmd_tx.clone(), plan_tx.clone(), u_tx.clone(), refresh.clone());
        tokio::spawn(async move {
            let mut rates: HashMap<String, u64> = HashMap::new();
            let mut n: u32 = 0;
            loop {
                tokio::select! {
                    _ = tokio::time::sleep(Duration::from_secs(cfg.universe.refresh_secs)) => {}
                    _ = refresh.notified() => {}
                }
                n = n.wrapping_add(1);
                let u = match fetch_universe(&cfg).await {
                    Ok(u) => u,
                    Err(e) => {
                        eprintln!("refresh: {e:#}");
                        continue;
                    }
                };
                if n % cfg.shards.retier_every_refreshes == 0 {
                    let (tx, rx) = oneshot::channel();
                    if cmd_tx.send(EngineCmd::Rates(tx)).await.is_err() {
                        return;
                    }
                    rates = rx.await.unwrap_or_default();
                }
                let plan = shards::plan(shards::units(&u, &rates), &cfg.shards);
                if let Err(e) = persist_universe(&store, &u).await {
                    eprintln!("refresh persist: {e:#}");
                }
                let u = Arc::new(u);
                let (ack_tx, ack_rx) = oneshot::channel();
                if cmd_tx.send(EngineCmd::Apply { universe: u.clone(), conn_of: plan.conn_of(), ack: ack_tx }).await.is_err() {
                    return;
                }
                let _ = ack_rx.await; // mapping applied BEFORE any new shard can deliver frames
                let _ = u_tx.send(u);
                if plan_tx.send(plan).await.is_err() {
                    return;
                }
            }
        });
    }

    // Engine loop (this future)
    let io = Io {
        writer: writer_tx.clone(),
        capture: capture_tx.clone(),
        recheck: recheck_tx,
        resnap: resnap_tx,
        refresh: refresh.clone(),
        metrics: metrics.clone(),
        run_id,
        l1_window_ms: cfg.engine.l1_suspect_window_ms,
        suspect_window_ms: cfg.engine.suspect_window_ms,
    };
    let mut engine = Engine::new(engine_ctx(cfg, cfg_hash, run_id, "live"));
    let apply = |engine: &mut Engine, u: Arc<Universe>, conn_of: &HashMap<String, usize>, io: &Io| {
        let rec = UniverseRecord { universe: (*u).clone(), conn_of: conn_of.iter().map(|(k, v)| (k.clone(), *v)).collect::<ConnMap>() };
        if io.capture.try_send(CaptureMsg::Universe(Box::new(rec))).is_err() {
            io.metrics.capture_drops.fetch_add(1, Ordering::Relaxed);
        }
        let t = now_ms();
        io.ctl(0, Ctl::Universe { taken_ms: u.taken_ms }, t);
        engine.apply_universe(u, conn_of, t)
    };
    let outs = apply(&mut engine, universe.clone(), &plan.conn_of(), &io);
    io.route(&mut engine, outs).await?;
    plan_tx.send(plan).await.context("supervisor gone")?;

    let mut tick = tokio::time::interval(Duration::from_secs(1));
    tick.set_missed_tick_behavior(tokio::time::MissedTickBehavior::Delay);
    let shutdown = shutdown_signal();
    tokio::pin!(shutdown);
    let result: anyhow::Result<()> = loop {
        tokio::select! {
            _ = &mut shutdown => break Ok(()),
            m = feed_rx.recv() => {
                let Some(m) = m else { break Err(anyhow::anyhow!("feed channel closed")) };
                match m {
                    FeedMsg::Frame(f) => {
                        let ms = f.recv_us.div_euclid(1000);
                        metrics.msgs.fetch_add(1, Ordering::Relaxed);
                        metrics.bytes.fetch_add(f.text.len() as u64, Ordering::Relaxed);
                        let outs = match parse_frame(&f.text) {
                            Ok(evs) => {
                                let outs = engine.on_frame(f.conn, ms, &evs);
                                engine.alive(f.conn, ms);
                                outs
                            }
                            Err(e) => vec![Out::Integrity(IntegrityRow {
                                run_id, ts_ms: ms, kind: "parse_error".into(), shard: i32::try_from(f.conn).ok(),
                                token: None, event_id: None, detail: Some(e.to_string()),
                            })],
                        };
                        io.capture(Line { recv_ts_us: f.recv_us, shard: f.conn, raw: Some(f.text), ctl: None });
                        if let Err(e) = io.route(&mut engine, outs).await { break Err(e) }
                    }
                    FeedMsg::Up { .. } => {}
                    FeedMsg::Down { conn, reason } => {
                        let t = now_ms();
                        io.ctl(conn, Ctl::Down, t);
                        let mut outs = engine.disconnect(conn, t);
                        if let Some(Out::Integrity(i)) = outs.first_mut() {
                            i.detail = Some(reason);
                        }
                        if let Err(e) = io.route(&mut engine, outs).await { break Err(e) }
                    }
                    FeedMsg::Parked { conn } => {
                        let row = IntegrityRow { run_id, ts_ms: now_ms(), kind: "shard_parked".into(), shard: i32::try_from(conn).ok(), token: None, event_id: None, detail: None };
                        if writer_tx.send(WriterMsg::Integrity(row)).await.is_err() { break Err(anyhow::anyhow!("writer gone")) }
                    }
                }
            }
            c = cmd_rx.recv() => {
                let Some(c) = c else { break Err(anyhow::anyhow!("command channel closed")) };
                match c {
                    EngineCmd::Apply { universe, conn_of, ack } => {
                        let outs = apply(&mut engine, universe, &conn_of, &io);
                        let _ = ack.send(());
                        if let Err(e) = io.route(&mut engine, outs).await { break Err(e) }
                    }
                    EngineCmd::Rates(tx) => { let _ = tx.send(engine.rates()); }
                }
            }
            Some(k) = check_rx.recv() => {
                let outs = match k {
                    CheckCmd::RestSnapshot { token, book } => {
                        io.ctl(0, book_ctl(&token, &book), now_ms());
                        engine.rest_snapshot(&token, book)
                    }
                    CheckCmd::Drift { token, book } => { engine.drift_check(&token, book, now_ms()); Vec::new() }
                    CheckCmd::L1Mismatch { event_id, detail } => {
                        let t = now_ms();
                        let until = t + io.l1_window_ms;
                        engine.mark_suspect(&event_id, until);
                        io.ctl(0, Ctl::Suspect { event_id: event_id.clone(), until_ms: until }, t);
                        vec![Out::Integrity(io.integrity("mirror_mismatch", None, Some(event_id), detail))]
                    }
                };
                if let Err(e) = io.route(&mut engine, outs).await { break Err(e) }
            }
            _ = tick.tick() => {
                let outs = engine.tick(now_ms());
                if let Err(e) = io.route(&mut engine, outs).await { break Err(e) }
            }
        }
    };

    // Shutdown: stop shards, close episodes, flush, finish capture
    drop(plan_tx);
    supervisor_task.abort();
    let t = now_ms();
    io.ctl(0, Ctl::Shutdown, t);
    let outs = engine.close_all(t);
    let _ = io.route(&mut engine, outs).await;
    let (done_tx, done_rx) = oneshot::channel();
    if writer_tx.send(WriterMsg::Flush(done_tx)).await.is_ok() {
        let _ = tokio::time::timeout(Duration::from_secs(10), done_rx).await;
    }
    drop(io);
    drop(capture_tx);
    drop(writer_tx);
    let _ = tokio::time::timeout(Duration::from_secs(15), writer_task).await;
    let _ = tokio::task::spawn_blocking(move || capture_thread.join()).await;
    result
}
```

```rust
#![allow(clippy::unwrap_used, clippy::expect_used)]
use std::collections::{HashMap, HashSet};

fn deps() -> HashMap<String, HashSet<String>> {
    let cargo = std::env::var("CARGO").unwrap_or_else(|_| "cargo".into());
    let out = std::process::Command::new(cargo)
        .args(["metadata", "--format-version", "1", "--no-deps"])
        .output()
        .expect("cargo metadata");
    let v: serde_json::Value = serde_json::from_slice(&out.stdout).expect("json");
    let mut m = HashMap::new();
    for p in v["packages"].as_array().unwrap() {
        let name = p["name"].as_str().unwrap().to_string();
        let ds: HashSet<String> = p["dependencies"]
            .as_array()
            .unwrap()
            .iter()
            .filter(|d| d["kind"].is_null()) // normal deps only
            .map(|d| d["name"].as_str().unwrap().to_string())
            .collect();
        m.insert(name, ds);
    }
    m
}

#[test]
fn crate_graph_matches_spec_9_2() {
    let d = deps();
    let io = ["tokio", "reqwest", "tokio-tungstenite", "sqlx", "pm-api", "store"];
    for pure in ["arb-core"] {
        for bad in io {
            assert!(!d[pure].contains(bad), "{pure} must stay pure (no {bad})");
        }
    }
    assert!(!d["store"].contains("pm-api") && !d["store"].contains("reqwest"), "store has no network");
    assert!(!d["pm-api"].contains("store") && !d["pm-api"].contains("sqlx"), "pm-api has no database");
    for bad in ["reqwest", "tokio-tungstenite", "sqlx"] {
        assert!(!d["scanner"].contains(bad), "scanner reaches the network/db only via pm-api/store ({bad})");
    }
}
```
