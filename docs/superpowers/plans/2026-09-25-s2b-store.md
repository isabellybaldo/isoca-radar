# S2b · store (Postgres 17 + `store` crate) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A Postgres 17 container with roles, a versioned schema for everything the scanner (S2c) writes, and a `store` crate that is the only code in the workspace allowed to talk SQL.

**Architecture:** `compose.yml` gets its first service, `postgres` (pinned digest, named volume, init script creating the login roles). `crates/store` wraps sqlx 0.8: embedded migrations (`sqlx::migrate!`), a `Store` handle, and typed repositories for runs (the crash-loop breaker's source of truth), the warm-start universe cache, events/legs, and one batched write transaction for episodes, episode legs, observations, integrity events and health rows. An `AFTER INSERT OR UPDATE` trigger on `episodes` sends `NOTIFY episode`. Integration tests create a throwaway database per test inside a real Postgres (local compose, or a CI service container).

**Tech Stack:** Rust 1.98.1, sqlx 0.8 (`postgres`, `runtime-tokio`, `rust_decimal`, `migrate`, `macros`, `derive`; no TLS: internal network only), rust_decimal, thiserror, tokio. Postgres 17 (official image, pinned by digest). Docker Desktop (WSL2).

**Spec:** `docs/superpowers/specs/2026-09-22-arb-scanner-design.md` (§8.1, §8.1.2 runs/breaker, §9.3 "store owns the schema", §10 Storage, §15 Store tests, §16). Phase 0 results: `spikes/probe/RESULTS.md` (raw feed ≈ 123 GB/day: raw frames never go into Postgres).

## Global Constraints

- PAPER TRADING ONLY. Nothing in this plan touches Polymarket. No credentials of any exchange or wallet anywhere; database role passwords are the only secrets and live in a git-ignored `.env`.
- Zero GitHub secrets: CI uses an ephemeral Postgres service container with literal throwaway passwords.
- Money is never f32/f64. Every money/price column maps to `rust_decimal::Decimal`. Prices use `NUMERIC(8,6)`. **Derived amounts (costs, fees, P&L, VWAP, sizes) use unconstrained `NUMERIC`**, because a price (6 dp) × a size (up to 6 dp) has up to 12 dp and `NUMERIC(20,6)` would round silently on insert. This is a deliberate deviation from §10's `NUMERIC(20,6)`, taken to keep values exact.
- **Zero is a measurement:** `NULL` = not measured, `0` = measured zero. Rust uses `Option<_>` for anything that may be unmeasured.
- Timestamps are `BIGINT` ms (server or wall clock as named), plus generated `timestamptz` columns for humans where useful.
- `store` owns the schema. deny.toml gains `{ name = "sqlx", wrappers = ["store"] }`: no other crate may depend on sqlx.
- Queries are runtime-checked (`sqlx::query`/`QueryBuilder`), not the `query!` macros, and verified by integration tests against a real Postgres 17. This is a deliberate deviation from §15's "compile-time checks in offline mode": the same safety net (every query executes in CI) without the `sqlx-cli prepare` workflow and a committed `.sqlx/` that drifts.
- No `unwrap`/`expect` in `crates/store/src` (workspace clippy denies them). Tests may `#![allow(clippy::unwrap_used, clippy::expect_used)]`.
- Commit messages are plain, with no co-author or attribution trailer. Stage only files you touch (never `PROJECT.md` / `README.md`, which are untracked on purpose).
- Bash prefix for every command: `cd /c/Users/Isabelly/PycharmProjects/cute-trading && export PATH="$HOME/.cargo/bin:$PATH" &&`

## Review Focus

1. **A test run without Postgres** (the owner's `cargo test --workspace` on Windows, no container up) must still pass, printing `SKIPPED`, while **CI must never skip**: `STORE_TESTS_REQUIRED=1` turns a missing `TEST_DATABASE_URL` into a failure (pinned in Task 2's harness and CI job).
2. **Two episodes with swapped same-typed fields** (e.g. `peak_cost_usd` ↔ `peak_payout_usd`) would still insert without error. The round-trip test uses a distinct value in every column, so a misordered bind fails (pinned in Task 4).
3. **Re-running migrations** on an already-migrated database must be a no-op, not an error (pinned in Task 2).
4. **A breaker reset** must make old starts stop counting, even inside the 10-minute window, and a reset row itself must never count as a start (pinned in Task 3).
5. **The analyze role writing, or the scanner role dropping or deleting episodes**, must fail with a permission error (pinned in Task 5).

-- Login roles scanner_rw / analyze_ro are created by docker/postgres/init/01-roles.sh.

ALTER DEFAULT PRIVILEGES IN SCHEMA public GRANT SELECT, INSERT, UPDATE ON TABLES TO scanner_rw;
ALTER DEFAULT PRIVILEGES IN SCHEMA public GRANT USAGE, SELECT ON SEQUENCES TO scanner_rw;

CREATE TABLE runs (

CREATE TRIGGER episodes_notify AFTER INSERT OR UPDATE ON episodes
    FOR EACH ROW EXECUTE FUNCTION notify_episode();

```rust
//! store: the ONLY crate that talks to Postgres (spec §9.3: "store owns the schema, and nothing
//! else writes SQL"; deny.toml enforces that no other crate depends on sqlx).
#![forbid(unsafe_code)]

mod batch;
pub mod error;
pub mod rows;
mod runs;
mod universe;

pub use error::StoreError;
pub use rows::*;
pub use sqlx::postgres::PgConnectOptions;

use sqlx::postgres::{PgPool, PgPoolOptions};
use std::str::FromStr;
use std::time::Duration;

/// Migrations embedded at compile time from `crates/store/migrations`.
pub static MIGRATOR: sqlx::migrate::Migrator = sqlx::migrate!("./migrations");

#[derive(Clone, Debug)]
pub struct Store {
    pool: PgPool,
}

impl Store {
    pub fn options(url: &str) -> Result<PgConnectOptions, StoreError> {
        Ok(PgConnectOptions::from_str(url)?)
    }

    pub async fn connect(url: &str, max_conns: u32) -> Result<Self, StoreError> {
        Self::connect_with(Self::options(url)?, max_conns).await
    }

    pub async fn connect_with(opts: PgConnectOptions, max_conns: u32) -> Result<Self, StoreError> {
        let pool = PgPoolOptions::new()
            .max_connections(max_conns)
            .acquire_timeout(Duration::from_secs(10))
            .connect_with(opts)
            .await?;
        Ok(Self { pool })
    }

    /// Apply pending migrations. Must run as the owner role; the scanner role cannot create tables.
    pub async fn migrate(&self) -> Result<(), StoreError> {
        MIGRATOR.run(&self.pool).await?;
        Ok(())
    }

    pub fn pool(&self) -> &PgPool {
        &self.pool
    }

    pub async fn close(&self) {
        self.pool.close().await;
    }
}
```

    pub async fn connect_with_role(opts: PgConnectOptions, max_conns: u32, role: &str) -> Result<Self, StoreError> {

                format!("invalid role name {role:?}").into(),

            .max_connections(max_conns)
            .acquire_timeout(Duration::from_secs(10))
            .after_connect(move |conn, _meta| {
                let sql = set_role.clone();
                Box::pin(async move {
                    sqlx::raw_sql(&sql).execute(conn).await?;
                    Ok(())
                })
            })
            .connect_with(opts)
            .await?;
        Ok(Self { pool })
    }

    pub async fn raw_exec(&self, sql: &str) -> Result<(), StoreError> {
        sqlx::raw_sql(sql).execute(&self.pool).await?;

    pub async fn start_run(&self, r: &NewRun) -> Result<i64, StoreError> {
        Ok(sqlx::query_scalar(
            "INSERT INTO runs (service, started_ms, version, config_hash, mode) \
             VALUES ($1, $2, $3, $4, $5) RETURNING run_id",
        )
        .bind(&r.service)
        .bind(r.started_ms)
        .bind(&r.version)
        .bind(&r.config_hash)
        .bind(&r.mode)
        .fetch_one(self.pool())
        .await?)

    pub async fn end_run(&self, run_id: i64, ended_ms: i64, reason: &str) -> Result<(), StoreError> {
        sqlx::query("UPDATE runs SET ended_ms = $2, exit_reason = $3 WHERE run_id = $1")
            .bind(run_id)
            .bind(ended_ms)
            .bind(reason)
            .execute(self.pool())
            .await?;
        Ok(())

    /// Live and safe-mode starts of `service` since `since_ms`, not counting anything before the
    /// latest breaker reset of that service.
    pub async fn starts_since(&self, service: &str, since_ms: i64) -> Result<i64, StoreError> {
        Ok(sqlx::query_scalar(
            "SELECT count(*) FROM runs \
             WHERE service = $1 AND mode IN ('live', 'safe') \
               AND started_ms >= GREATEST($2, COALESCE( \
                   (SELECT max(started_ms) + 1 FROM runs WHERE service = $1 AND mode = 'breaker_reset'), $2))",
        )
        .bind(service)
        .bind(since_ms)
        .fetch_one(self.pool())
        .await?)
    }

    pub async fn record_breaker_reset(&self, service: &str, now_ms: i64) -> Result<(), StoreError> {
        sqlx::query(
            "INSERT INTO runs (service, started_ms, ended_ms, version, config_hash, mode, exit_reason) \
             VALUES ($1, $2, $2, '', '', 'breaker_reset', 'manual reset')",
        )
        .bind(service)
        .bind(now_ms)
        .execute(self.pool())
        .await?;
        Ok(())
    }

    /// (ended_ms, exit_reason) of one run.
    pub async fn run_exit(&self, run_id: i64) -> Result<(Option<i64>, Option<String>), StoreError> {
        Ok(sqlx::query_as("SELECT ended_ms, exit_reason FROM runs WHERE run_id = $1")
            .bind(run_id)

//! Universe cache (warm start, §8.1.2) and the current events/legs tables (§10).
use crate::{EventRow, LegRow, Store, StoreError, UniverseSnapshot};
use sqlx::{Postgres, QueryBuilder};

const CHUNK: usize = 1000;

impl Store {
    pub async fn save_universe(&self, taken_ms: i64, n_events: i32, body: &str) -> Result<(), StoreError> {
        let mut tx = self.pool().begin().await?;
        sqlx::query("INSERT INTO universe_snapshots (taken_ms, n_events, body) VALUES ($1, $2, $3)")
            .bind(taken_ms)
            .bind(n_events)
            .bind(body)
            .execute(&mut *tx)
            .await?;
        sqlx::query(
            "DELETE FROM universe_snapshots WHERE id NOT IN \
             (SELECT id FROM universe_snapshots ORDER BY taken_ms DESC, id DESC LIMIT 3)",
        )
        .execute(&mut *tx)
        .await?;
        tx.commit().await?;
        Ok(())
    }

    pub async fn latest_universe(&self) -> Result<Option<UniverseSnapshot>, StoreError> {
        Ok(sqlx::query_as(
            "SELECT taken_ms, n_events, body FROM universe_snapshots ORDER BY taken_ms DESC, id DESC LIMIT 1",
        )
        .fetch_optional(self.pool())
        .await?)
    }

    pub async fn count_universe_snapshots(&self) -> Result<i64, StoreError> {
        Ok(sqlx::query_scalar("SELECT count(*) FROM universe_snapshots")
            .fetch_one(self.pool())
            .await?)
    }

    /// Upsert one complete universe scan. Events first (legs reference them), one transaction.
    pub async fn upsert_universe(&self, events: &[EventRow], legs: &[LegRow], seen_ms: i64) -> Result<(), StoreError> {
        let mut tx = self.pool().begin().await?;
        for chunk in events.chunks(CHUNK) {
            let mut qb = QueryBuilder::<Postgres>::new(
                "INSERT INTO events (event_id, slug, title, neg_risk_market_id, augmented, n_legs, first_seen_ms, last_seen_ms) ",
            );
            qb.push_values(chunk, |mut b, e| {
                b.push_bind(e.event_id.clone())
                    .push_bind(e.slug.clone())
                    .push_bind(e.title.clone())
                    .push_bind(e.neg_risk_market_id.clone())
                    .push_bind(e.augmented)
                    .push_bind(e.n_legs)
                    .push_bind(seen_ms)
                    .push_bind(seen_ms);
            });
            qb.push(
                " ON CONFLICT (event_id) DO UPDATE SET slug = EXCLUDED.slug, title = EXCLUDED.title, \
                 neg_risk_market_id = EXCLUDED.neg_risk_market_id, augmented = EXCLUDED.augmented, \
                 n_legs = EXCLUDED.n_legs, last_seen_ms = EXCLUDED.last_seen_ms, gone_ms = NULL",
            );
            qb.build().execute(&mut *tx).await?;
        }
        for chunk in legs.chunks(CHUNK) {
            let mut qb = QueryBuilder::<Postgres>::new(
                "INSERT INTO legs (market_id, event_id, yes_token, no_token, status, fee_rate, fee_exponent, \
                 tick, min_size, seconds_delay, end_date, first_seen_ms, last_seen_ms) ",
            );
            qb.push_values(chunk, |mut b, l| {
                b.push_bind(l.market_id.clone())
                    .push_bind(l.event_id.clone())
                    .push_bind(l.yes_token.clone())
                    .push_bind(l.no_token.clone())
                    .push_bind(l.status.clone())
                    .push_bind(l.fee_rate)
                    .push_bind(l.fee_exponent)
                    .push_bind(l.tick)
                    .push_bind(l.min_size)
                    .push_bind(l.seconds_delay)
                    .push_bind(l.end_date.clone())
                    .push_bind(seen_ms)
                    .push_bind(seen_ms);
            });
            qb.push(
                " ON CONFLICT (market_id) DO UPDATE SET event_id = EXCLUDED.event_id, yes_token = EXCLUDED.yes_token, \
                 no_token = EXCLUDED.no_token, status = EXCLUDED.status, fee_rate = EXCLUDED.fee_rate, \
                 fee_exponent = EXCLUDED.fee_exponent, tick = EXCLUDED.tick, min_size = EXCLUDED.min_size, \
                 seconds_delay = EXCLUDED.seconds_delay, end_date = EXCLUDED.end_date, \
                 last_seen_ms = EXCLUDED.last_seen_ms, gone_ms = NULL",
            );
            qb.build().execute(&mut *tx).await?;
        }
        tx.commit().await?;
        Ok(())
    }

    /// Call only after a COMPLETE universe scan stamped `seen_ms` (spec §7: otherwise closed markets stay open forever).
    pub async fn mark_gone(&self, seen_ms: i64) -> Result<u64, StoreError> {
        let mut tx = self.pool().begin().await?;
        let events = sqlx::query("UPDATE events SET gone_ms = $1 WHERE last_seen_ms < $1 AND gone_ms IS NULL")
            .bind(seen_ms)
            .execute(&mut *tx)
            .await?
            .rows_affected();
        sqlx::query("UPDATE legs SET gone_ms = $1 WHERE last_seen_ms < $1 AND gone_ms IS NULL")
            .bind(seen_ms)
            .execute(&mut *tx)
            .await?;
        tx.commit().await?;
        Ok(events)
    }

    /// (first_seen_ms, last_seen_ms, gone_ms) of one event.
    pub async fn event_seen(&self, event_id: &str) -> Result<(i64, i64, Option<i64>), StoreError> {
        Ok(sqlx::query_as("SELECT first_seen_ms, last_seen_ms, gone_ms FROM events WHERE event_id = $1")
            .bind(event_id)
            .fetch_one(self.pool())
            .await?)
    }
}

  - `Store::count(&self, table: Table) -> Result<i64, StoreError>` with `pub enum Table { Observations, IntegrityEvents, Health, EpisodeLegs }` (no string-built SQL from callers).
  - Postgres channel `episode` receives the `episode_id` on every insert/update (trigger from Task 2).

/// Keep only the last write of each episode, in first-seen order (the scanner may upsert the same
/// episode at open and at peak within one batch).
fn dedupe_last(ws: &[EpisodeWrite]) -> Vec<&EpisodeWrite> {
    let mut idx: HashMap<&str, usize> = HashMap::new();
    let mut out: Vec<&EpisodeWrite> = Vec::new();
    for w in ws {
        match idx.get(w.row.episode_id.as_str()) {
            Some(&i) => out[i] = w,
            None => {
                idx.insert(w.row.episode_id.as_str(), out.len());
                out.push(w);
            }
        }
    }
    out
}

/// A LISTEN connection on one channel.
pub struct Listener(PgListener);

impl Listener {
    /// Wait for the next notification and return its payload.
    pub async fn recv_payload(&mut self) -> Result<String, StoreError> {
        Ok(self.0.recv().await?.payload().to_string())
    }
}

impl Store {
    pub async fn write_batch(&self, b: &Batch) -> Result<(), StoreError> {
        if b.is_empty() {
            return Ok(());
        }
        let mut tx = self.pool().begin().await?;

        let update_set = EPISODE_COLS[1..]
            .iter()
            .map(|c| format!("{c} = EXCLUDED.{c}"))
            .collect::<Vec<_>>()
            .join(", ");
        let episodes = dedupe_last(&b.episodes);
        for chunk in episodes.chunks(EP_CHUNK) {
            let mut qb = QueryBuilder::<Postgres>::new(format!("INSERT INTO episodes ({}) ", EPISODE_COLS.join(", ")));
            qb.push_values(chunk, |mut sep, w| push_episode(&mut sep, &w.row));
            qb.push(format!(" ON CONFLICT (episode_id) DO UPDATE SET {update_set}"));
            qb.build().execute(&mut *tx).await?;
        }

        if !episodes.is_empty() {
            let ids: Vec<String> = episodes.iter().map(|w| w.row.episode_id.clone()).collect();
            sqlx::query("DELETE FROM episode_legs WHERE episode_id = ANY($1)")
                .bind(ids)
                .execute(&mut *tx)
                .await?;
            let all_legs: Vec<&EpisodeLegRow> = episodes.iter().flat_map(|w| w.legs.iter()).collect();
            for chunk in all_legs.chunks(CHUNK) {
                let mut qb = QueryBuilder::<Postgres>::new(format!("INSERT INTO episode_legs ({LEG_COLS}) "));
                qb.push_values(chunk, |mut s, l| {
                    s.push_bind(l.episode_id.clone())
                        .push_bind(l.leg_idx)
                        .push_bind(l.market_id.clone())
                        .push_bind(l.token.clone())
                        .push_bind(l.action.clone())
                        .push_bind(l.best_price)
                        .push_bind(l.vwap)
                        .push_bind(l.levels)
                        .push_bind(l.size_at_best)
                        .push_bind(l.filled)
                        .push_bind(l.notional)
                        .push_bind(l.fees)
                        .push_bind(l.in_s)
                        .push_bind(l.fee_rate)
                        .push_bind(l.fee_exponent);
                });
                qb.build().execute(&mut *tx).await?;
            }
        }

        for chunk in b.observations.chunks(CHUNK) {
            let mut qb = QueryBuilder::<Postgres>::new(
                "INSERT INTO observations (episode_id, offset_ms, source, observed_ms, skipped, skip_reason, edge, \
                 q_max, pnl, still_profitable, fill_at_original_size) ",
            );
            qb.push_values(chunk, |mut s, o| {
                s.push_bind(o.episode_id.clone())
                    .push_bind(o.offset_ms)
                    .push_bind(o.source.clone())
                    .push_bind(o.observed_ms)
                    .push_bind(o.skipped)
                    .push_bind(o.skip_reason.clone())
                    .push_bind(o.edge)

    }

    }
