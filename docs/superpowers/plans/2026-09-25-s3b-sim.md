# S3b · `sim` crate (pure paper trader) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A pure, deterministic `sim` crate that paper-trades arbitrage episodes with the spec's execution model (latency, FAK fills against books minus consumed liquidity, leg-risk unwinds, NO→collateral conversion, settlement by payout vector) and the four policies P0–P3. No wiring into the scanner yet (that is S3c).

**Architecture:** `crates/sim` depends only on `arb-core`, `rust_decimal`, `serde`, `thiserror`. A `PaperTrader` owns one `Account` + `ConsumedLiquidity` per (policy × latency scenario) account from `config/policies.toml`. It is driven purely by inputs that carry their own time: `on_open` (an episode opened), `on_frame(recv_ms, books)` (called BEFORE each frame is applied, so due work sees the book as of its due time), `on_level`/`on_snapshot` (feed updates that clear consumed liquidity), `on_resolution` (payout vector). Outputs are plain row structs (`SimOut`) that S3c maps to Postgres.

**Tech Stack:** Rust 1.98.1 (pinned), `rust_decimal` (+ `maths` in arb-core for the annualized figure, + `serde` in sim), `serde`, `thiserror`; tests with `proptest`, `serde_json`, `toml`.

**Spec:** `docs/superpowers/specs/2026-09-22-arb-scanner-design.md`. §5.5 (lock-up), §5.6 (accounting), §9.1–9.3 (crate layout, contracts), §11 (policies), §15 (Sim tests), §16 (paper-only).

## Global Constraints

- PAPER ONLY. `sim` produces ledger entries only; no order placement, wallet, key or signing code; no network or database crates (spec §16 #5).
- `sim` is pure. Its only dependencies are `arb-core`, `rust_decimal`, `serde` and `thiserror`: no tokio, reqwest, sqlx, pm-api, store, clock or IO. Time arrives on inputs, so live, replay and tests agree byte for byte (spec §9.3).
- Exact decimals only. No `f32`/`f64` anywhere. The workspace clippy config denies `float_arithmetic`, `unwrap_used` and `expect_used`; test files start with `#![allow(clippy::unwrap_used, clippy::expect_used)]`.
- Money in TOML is written as strings (`"1000"`, `"0.10"`) so it deserializes exactly into `Decimal`.
- Venue rules: min order 5 shares (Q6). A FAK buy needs `price × size` with ≤ 2 decimals and size ≤ 2 dp, so sizes are rounded DOWN. Buy/sell fees are in USDC, `fee_conservative` per level fill (Q2, Q3).
- Paper defaults (Q16): $1,000 virtual per account, $100 per trade; scenarios colocated-idle / SP-idle / SP-burst (+ Q1 delay-0 and Q4 feeBips sensitivities).
- Build and test commands start with `cd /c/Users/Isabelly/PycharmProjects/cute-trading && export PATH="$HOME/.cargo/bin:$PATH" &&`. Debug builds only (`cargo test -p sim`): no `--release`, no docker builds. The project's disk budget is 30 GB.
- Commits have NO `Co-Authored-By` or other attribution trailer.

## Review Focus

1. **A leg's book is missing at `t_x`** (its token was dropped by a universe refresh): that leg fills 0, the other legs' fills become leg risk and are unwound; no panic. Test: Task 8 `missing_book_at_execution_unwinds_the_other_legs`.
2. **Two accounts trade the same episode**: each has its own consumed-liquidity ledger, so one account's paper fill never depletes another's. Test: Task 8 `accounts_do_not_share_consumed_liquidity`.
3. **Concurrent intents exceed cash**: an intent reserves its worst-case cost at decision time, so the next decision sees only the free cash; the reservation is released at execution. Test: Task 8 `pending_reservation_limits_the_next_intent`.
4. **A long input gap** (hours between frames, e.g. across a restart in replay) must not emit thousands of marks: one mark at the new aligned time. Test: Task 9 `a_long_gap_emits_one_mark`.
5. **Non-binary resolutions (Q19)**: a 50-50 payout vector settles each side at its actual payout, never an assumed {0,1}. Test: Task 6 `non_binary_payout_settles_at_the_vector` and Task 9 `resolution_settles_every_account`.

const MS_PER_DAY: i64 = 86_400_000;

/// Unix ms from an RFC 3339 timestamp as Gamma sends `endDate` ("2026-10-01T12:00:00Z", optional
/// fractional seconds, optional ±hh:mm offset), or a bare date (= midnight UTC). None otherwise.
pub fn parse_rfc3339_ms(s: &str) -> Option<i64> {
    let s = s.trim();
    let date = s.get(..10)?;
    let rest = s.get(10..)?;
    let mut it = date.split('-');
    let y: i64 = it.next()?.parse().ok()?;
    let m: i64 = it.next()?.parse().ok()?;
    let d: i64 = it.next()?.parse().ok()?;
    if it.next().is_some() || !(1..=12).contains(&m) || !(1..=31).contains(&d) {
        return None;
    }
    let mut ms = days_from_civil(y, m, d) * MS_PER_DAY;
    if rest.is_empty() {
        return Some(ms);
    }
    let rest = rest.strip_prefix('T').or_else(|| rest.strip_prefix(' '))?;
    let hms = rest.get(..8)?;
    let mut tz = rest.get(8..)?;
    let mut t = hms.split(':');
    let hh: i64 = t.next()?.parse().ok()?;
    let mi: i64 = t.next()?.parse().ok()?;
    let ss: i64 = t.next()?.parse().ok()?;
    if t.next().is_some() || hh > 23 || mi > 59 || ss > 60 {
        return None;
    }
    ms += (hh * 3600 + mi * 60 + ss) * 1000;
    if let Some(frac) = tz.strip_prefix('.') {
        let n = frac.find(|c: char| !c.is_ascii_digit()).unwrap_or(frac.len());
        if n == 0 {
            return None;
        }
        let first3: String = frac.get(..n)?.chars().chain("000".chars()).take(3).collect();
        ms += first3.parse::<i64>().ok()?;
        tz = frac.get(n..)?;
    }
    match tz {
        "" | "Z" | "z" => Some(ms),
        _ => {
            let sign = match tz.as_bytes().first()? {
                b'+' => 1,
                b'-' => -1,
                _ => return None,
            };
            let off = tz.get(1..)?;
            let (oh, om) = match off.split_once(':') {
                Some(x) => x,
                None => (off.get(..2)?, off.get(2..)?),
            };
            let oh: i64 = oh.parse().ok()?;
            let om: i64 = om.parse().ok()?;
            if oh > 23 || om > 59 {
                return None;
            }
            Some(ms - sign * (oh * 60 + om) * 60_000)
        }
    }
}

/// Days since 1970-01-01 for a proleptic Gregorian date (Howard Hinnant's `days_from_civil`).
fn days_from_civil(y: i64, m: i64, d: i64) -> i64 {
    let y = if m <= 2 { y - 1 } else { y };
    let era = y.div_euclid(400);
    let yoe = y - era * 400;
    let mp = (m + 9) % 12;
    let doy = (153 * mp + 2) / 5 + d - 1;
    let doe = yoe * 365 + yoe / 4 - yoe / 100 + doy;
    era * 146_097 + doe - 719_468
}

/// Days from `t_ms` until `end_ms`: an estimate (events can resolve before or after `endDate`),
/// negative once past it.
pub fn days_to_end(end_ms: i64, t_ms: i64) -> Decimal {
    Decimal::from(end_ms - t_ms) / Decimal::from(MS_PER_DAY)
}

/// Secondary lock-up figure (spec §5.5): (1 + r)^(365 / max(days, 7)) − 1. Days are floored at 7
/// so tiny horizons don't explode. None if 1 + r ≤ 0 or the power overflows.
pub fn annualized(simple_return: Decimal, days: Decimal) -> Option<Decimal> {
    let base = Decimal::ONE + simple_return;
    if base <= Decimal::ZERO {
        return None;
    }
    let exp = Decimal::from(365) / days.max(Decimal::from(7));
    base.checked_powd(exp).map(|x| x - Decimal::ONE)
}
```

//! Identifiers shared by the sim modules.
use arb_core::book::Side;
use serde::{Deserialize, Serialize};

/// The token a position or order is on. We subscribe YES books only; NO is the mirror (L1).
#[derive(Debug, Clone, Copy, PartialEq, Eq, Hash, PartialOrd, Ord, Serialize, Deserialize)]
#[serde(rename_all = "snake_case")]
pub enum Outcome {
    Yes,
    No,
}

impl Outcome {
    pub fn as_str(self) -> &'static str {
        match self {
            Outcome::Yes => "yes",
            Outcome::No => "no",
        }
    }
}

/// One tradeable token: a market's YES or NO. Books are looked up by `yes_token`.
#[derive(Debug, Clone, PartialEq, Eq, Hash, PartialOrd, Ord, Serialize, Deserialize)]
pub struct LegKey {
    pub market_id: String,
    pub yes_token: String,
    pub outcome: Outcome,
}

/// A side of the YES book. Consumed liquidity is tracked in YES-book coordinates.
#[derive(Debug, Clone, Copy, PartialEq, Eq, Hash, PartialOrd, Ord, Serialize, Deserialize)]
#[serde(rename_all = "snake_case")]
pub enum BookSide {
    Bid,
    Ask,
}

impl BookSide {
    pub fn from_core(s: Side) -> Self {
        match s {
            Side::Bid => BookSide::Bid,
            Side::Ask => BookSide::Ask,
        }
    }
}

/// Serde helper: a `BTreeMap` as a list of pairs (JSON object keys must be strings; ours are structs).
pub mod vecmap {
    use serde::{Deserialize, Deserializer, Serialize, Serializer};
    use std::collections::BTreeMap;

    pub fn serialize<S: Serializer, K: Serialize, V: Serialize>(
        m: &BTreeMap<K, V>,
        s: S,
    ) -> Result<S::Ok, S::Error> {
        s.collect_seq(m.iter())
    }

    pub fn deserialize<'de, D: Deserializer<'de>, K: Deserialize<'de> + Ord, V: Deserialize<'de>>(
        d: D,
    ) -> Result<BTreeMap<K, V>, D::Error> {
        Ok(Vec::<(K, V)>::deserialize(d)?.into_iter().collect())
    }
}

    SimError::Config(msg.into())

impl SimConfig {
    pub fn scenario(&self, name: &str) -> Option<&Scenario> {
        self.scenarios.iter().find(|s| s.name == name)
    }

    pub fn validate(&self) -> Result<(), SimError> {
        if self.settle_delay_ms < 0 || self.mark_every_ms <= 0 || self.burst_window_ms <= 0 {
            return Err(bad("settle_delay_ms ≥ 0, mark_every_ms > 0, burst_window_ms > 0"));
        }
        if self.min_order_shares <= Decimal::ZERO {
            return Err(bad("min_order_shares must be > 0"));
        }
        if self.markout_offsets_ms.iter().any(|&o| o <= 0)
            || self.markout_offsets_ms.windows(2).any(|w| w[0] >= w[1])
        {
            return Err(bad("markout_offsets_ms must be positive and strictly increasing"));
        }
        let mut names = HashSet::new();
        for s in &self.scenarios {
            if !names.insert(s.name.as_str()) {
                return Err(bad(format!("duplicate scenario {}", s.name)));
            }
            if s.proc_ms < 0 || s.net_ms < 0 || s.match_ms < 0 {
                return Err(bad(format!("scenario {}: latencies must be ≥ 0", s.name)));
            }
            if s.burst.iter().any(|b| b.multiplier < 1)
                || s.burst.windows(2).any(|w| w[0].frames_per_s_above >= w[1].frames_per_s_above)
            {
                return Err(bad(format!("scenario {}: burst steps need multiplier ≥ 1 and increasing thresholds", s.name)));
            }
        }
        let mut ids = HashSet::new();
        for a in &self.accounts {
            if self.scenario(&a.scenario).is_none() {
                return Err(bad(format!("account {}: unknown scenario", a.id())));
            }
            if a.bankroll <= Decimal::ZERO || a.per_trade <= Decimal::ZERO {
                return Err(bad(format!("account {}: bankroll and per_trade must be > 0", a.id())));
            }
            if a.fee_bips < Decimal::ZERO || a.fee_bips > Decimal::from(10_000) {
                return Err(bad(format!("account {}: fee_bips must be in [0, 10000]", a.id())));
            }
            if !ids.insert(a.id()) {
                return Err(bad(format!("duplicate account {}", a.id())));
            }
        }
        if self.accounts.is_empty() {
            return Err(bad("no accounts"));
        }
        Ok(())
    }
}

//! Execution latency (spec §5.6): everything is anchored on OUR receive time of the opening frame.
use crate::config::Scenario;
use std::collections::VecDeque;

/// Frames received in the trailing window, from input times only (so replay reproduces it).
#[derive(Debug, Clone, Default)]
pub struct FrameRate {
    window_ms: i64,
    times: VecDeque<i64>,
}

impl FrameRate {
    pub fn new(window_ms: i64) -> Self {
        Self { window_ms: window_ms.max(1), times: VecDeque::new() }
    }

    pub fn push(&mut self, t_ms: i64) {
        self.times.push_back(t_ms);
        while let Some(&front) = self.times.front() {
            if front <= t_ms - self.window_ms {
                self.times.pop_front();
            } else {
                break;
            }
        }
    }

    pub fn per_second(&self) -> u64 {
        let n = u64::try_from(self.times.len()).unwrap_or(u64::MAX);
        let w = u64::try_from(self.window_ms).unwrap_or(1).max(1);
        n.saturating_mul(1000) / w
    }
}

/// Matching-time multiplier: the highest step whose threshold the current rate exceeds.
pub fn burst_multiplier(sc: &Scenario, frames_per_s: u64) -> i64 {
    sc.burst
        .iter()
        .filter(|b| frames_per_s > b.frames_per_s_above)
        .map(|b| b.multiplier)
        .max()
        .unwrap_or(1)
}

/// Receive time → matchable: proc + net + match × burst + secondsDelay (if the scenario honors it).
pub fn exec_delay_ms(sc: &Scenario, seconds_delay: Option<i32>, frames_per_s: u64) -> i64 {
    let delay = if sc.honor_seconds_delay {
        i64::from(seconds_delay.unwrap_or(0).max(0)) * 1000
    } else {
        0
    };
    sc.proc_ms + sc.net_ms + sc.match_ms * burst_multiplier(sc, frames_per_s) + delay
}

//! Consumed liquidity (spec §5.6). Our fills aren't real, so the orders we "took" are still in the
//! feed. Each account keeps what it consumed per YES-book level; the amount only clears once the
//! feed shows that level shrink by at least that amount (someone else plausibly took it) or vanish.
//! Otherwise every flicker of the same episode could "fill" the same resting orders again.
use crate::types::{BookSide, vecmap};
use arb_core::book::Book;
use rust_decimal::Decimal;
use serde::{Deserialize, Serialize};
use std::collections::BTreeMap;

#[derive(Debug, Clone, PartialEq, Eq, PartialOrd, Ord, Hash, Serialize, Deserialize)]
pub struct LevelKey {
    pub yes_token: String,
    pub side: BookSide,
    pub price: Decimal,
}

#[derive(Debug, Clone, Copy, PartialEq, Eq, Serialize, Deserialize)]
pub struct Consumed {
    pub amount: Decimal,
    /// The feed's aggregate size at the level when we last consumed from it.
    pub ref_size: Decimal,
}

#[derive(Debug, Clone, Default, PartialEq, Eq, Serialize, Deserialize)]
pub struct ConsumedLiquidity {
    #[serde(with = "vecmap")]
    levels: BTreeMap<LevelKey, Consumed>,
}

impl ConsumedLiquidity {
    pub fn available(&self, key: &LevelKey, feed_size: Decimal) -> Decimal {
        let used = self.levels.get(key).map_or(Decimal::ZERO, |c| c.amount);
        (feed_size - used).max(Decimal::ZERO)
    }

    pub fn consume(&mut self, key: LevelKey, feed_size: Decimal, qty: Decimal) {
        if qty <= Decimal::ZERO {
            return;
        }
        let e = self.levels.entry(key).or_insert(Consumed {
            amount: Decimal::ZERO,
            ref_size: feed_size,
        });
        e.amount += qty;
        e.ref_size = feed_size;
    }

    /// The feed's new aggregate size at one level (0 = the level was removed).
    pub fn on_level(&mut self, key: &LevelKey, new_size: Decimal) {
        let clear = self
            .levels
            .get(key)
            .is_some_and(|c| new_size <= Decimal::ZERO || new_size <= c.ref_size - c.amount);
        if clear {
            self.levels.remove(key);
        }
    }

    /// A full book for `yes_token` arrived: re-check every consumed level of that token.
    pub fn on_snapshot(&mut self, yes_token: &str, book: &Book) {
        let side_map = |v: Vec<(arb_core::money::Price, arb_core::money::Shares)>| -> BTreeMap<Decimal, Decimal> {
            v.into_iter().map(|(p, s)| (p.get(), s.get())).collect()
        };
        let bids = side_map(book.bids_best_first());
        let asks = side_map(book.asks_best_first());
        let keys: Vec<LevelKey> = self
            .levels
            .keys()
            .filter(|k| k.yes_token == yes_token)
            .cloned()
            .collect();
        for k in keys {
            let side = match k.side {
                BookSide::Bid => &bids,
                BookSide::Ask => &asks,
            };
            let size = side.get(&k.price).copied().unwrap_or(Decimal::ZERO);
            self.on_level(&k, size);
        }
    }

    pub fn len(&self) -> usize {
        self.levels.len()
    }

    pub fn is_empty(&self) -> bool {
        self.levels.is_empty()
    }
}

//! The venue as the sim sees it (spec §5.6): FAK orders walked against the feed's book minus the
//! liquidity this account already consumed. Buy and sell fees are USDC, rounded up per level fill.
use crate::consumed::{ConsumedLiquidity, LevelKey};
use crate::types::{BookSide, LegKey, Outcome};
use arb_core::book::Book;
use arb_core::fee::FeeSchedule;
use arb_core::money::{Price, Shares};
use rust_decimal::{Decimal, RoundingStrategy};
use serde::{Deserialize, Serialize};

#[derive(Debug, Clone, Default, PartialEq, Eq, Serialize, Deserialize)]
pub struct OrderFill {
    pub filled: Decimal,
    pub notional: Decimal,
    pub fees: Decimal,
    pub levels_used: u32,
}

impl OrderFill {
    pub fn vwap(&self) -> Option<Decimal> {
        if self.filled > Decimal::ZERO {
            self.notional.checked_div(self.filled)
        } else {
            None
        }
    }
}

/// The traded outcome's levels, best first: what we'd buy (asks) or sell into (bids). NO is L1.
pub fn outcome_levels(book: &Book, outcome: Outcome, buying: bool) -> Vec<(Price, Shares)> {
    match (outcome, buying) {
        (Outcome::Yes, true) => book.asks_best_first(),
        (Outcome::Yes, false) => book.bids_best_first(),
        (Outcome::No, true) => book.no_asks_best_first(),
        (Outcome::No, false) => book.no_bids_best_first(),
    }
}

/// The levels we would buy along, best first (used by policies and by S3c's engine hook).
pub fn bought_levels(book: &Book, outcome: Outcome) -> Vec<(Price, Shares)> {
    outcome_levels(book, outcome, true)
}

/// The YES-book level a trade at `price` of `leg.outcome` consumes (L1 mirror for NO).
pub fn yes_level(leg: &LegKey, buying: bool, price: Price) -> LevelKey {
    let (side, p) = match (leg.outcome, buying) {
        (Outcome::Yes, true) => (BookSide::Ask, price),
        (Outcome::Yes, false) => (BookSide::Bid, price),
        (Outcome::No, true) => (BookSide::Bid, price.complement()),
        (Outcome::No, false) => (BookSide::Ask, price.complement()),
    };
    LevelKey { yes_token: leg.yes_token.clone(), side, price: p.get() }
}

fn take(
    book: &Book,
    leg: &LegKey,
    fee: FeeSchedule,
    limit: Option<Price>,
    qty: Decimal,
    consumed: &mut ConsumedLiquidity,
    buying: bool,
) -> OrderFill {
    let mut out = OrderFill::default();
    let mut left = qty;
    for (p, s) in outcome_levels(book, leg.outcome, buying) {
        if left <= Decimal::ZERO {
            break;
        }
        if let Some(l) = limit
            && ((buying && p > l) || (!buying && p < l))
        {
            break;
        }
        let key = yes_level(leg, buying, p);
        let q = consumed.available(&key, s.get()).min(left);
        if q <= Decimal::ZERO {
            continue;
        }
        consumed.consume(key, s.get(), q);
        out.filled += q;
        out.notional += p.get() * q;
        out.fees += fee.fee_conservative(p, q);
        out.levels_used += 1;
        left -= q;
    }
    out
}

/// FAK buy: take up to `qty` at prices ≤ `limit`; whatever isn't there is not filled.
pub fn fak_buy(
    book: &Book,
    leg: &LegKey,
    fee: FeeSchedule,
    limit: Price,
    qty: Decimal,
    consumed: &mut ConsumedLiquidity,
) -> OrderFill {
    take(book, leg, fee, Some(limit), qty, consumed, true)
}

/// FAK sell into the bids with no floor (the leg-risk unwind, spec §5.6).
pub fn fak_sell(
    book: &Book,
    leg: &LegKey,
    fee: FeeSchedule,
    qty: Decimal,
    consumed: &mut ConsumedLiquidity,
) -> OrderFill {
    take(book, leg, fee, None, qty, consumed, false)
}

/// Largest size ≤ `q` with ≤ 2 dp such that `limit × size` has ≤ 2 dp for every limit (a FAK buy's
/// USDC amount), or 0 if that is below `min` (5 shares, Q6).
pub fn order_size(limits: &[Price], q: Decimal, min: Decimal) -> Decimal {
    let step = Decimal::new(1, 2);
    let mut s = q.round_dp_with_strategy(2, RoundingStrategy::ToZero);
    // Prices have ≤ 6 dp, so a valid size is at most 10_000 steps below any start; bounded anyway.
    for _ in 0..100_000 {
        if s < min || s <= Decimal::ZERO {
            return Decimal::ZERO;
        }
        if limits.iter().all(|l| (l.get() * s).normalize().scale() <= 2) {
            return s;
        }
        s -= step;
    }
    Decimal::ZERO
}

//! One paper account (spec §5.6): cash, positions at cost basis, an append-only ledger.
//! Identity (spec §15): cash + marks = bankroll + realized + unrealized, where
//! unrealized = marks − open basis. It holds exactly because basis leaves positions only through
//! `take_out`, whose output is the same number realized P&L subtracts.
use crate::config::AccountSpec;
use crate::types::{LegKey, Outcome, vecmap};
use crate::venue::OrderFill;
use rust_decimal::Decimal;
use serde::{Deserialize, Serialize};
use std::collections::BTreeMap;

#[serde(rename_all = "snake_case")]
pub enum EntryKind {
    Buy,
    Sell,
    Convert,
    Settle,
    Mark,
}

            EntryKind::Sell => "sell",

#[derive(Debug, Clone, Default, PartialEq, Eq, Serialize, Deserialize)]
pub struct Position {

#[derive(Debug, Clone, Copy, PartialEq, Eq)]

impl Valuation {

    }

#[derive(Debug, Clone, PartialEq, Eq, Serialize, Deserialize)]
pub struct Account {
    pub id: String,
    pub spec: AccountSpec,
    pub cash: Decimal,
    /// Worst-case cost of intents decided but not yet executed.
    pub reserved: Decimal,
    pub realized: Decimal,
    pub fees_paid: Decimal,
    #[serde(with = "vecmap")]
    pub positions: BTreeMap<LegKey, Position>,
    /// YES returned by NO→collateral conversions: basis 0, marked at 0 until resolution (spec §5.6).
    #[serde(with = "vecmap")]
    pub returned: BTreeMap<LegKey, Decimal>,
    pub seq: u64,
    pub peak_equity: Decimal,
    pub max_drawdown: Decimal,
}

impl Account {
    pub fn new(spec: AccountSpec) -> Self {
        Self {
            id: spec.id(),
            cash: spec.bankroll,
            peak_equity: spec.bankroll,
            spec,
            reserved: Decimal::ZERO,
            realized: Decimal::ZERO,
            fees_paid: Decimal::ZERO,
            positions: BTreeMap::new(),
            returned: BTreeMap::new(),
            seq: 0,
            max_drawdown: Decimal::ZERO,
        }
    }

    pub fn free_cash(&self) -> Decimal {
        (self.cash - self.reserved).max(Decimal::ZERO)
    }

    #[allow(clippy::too_many_arguments)]
    fn entry(
        &mut self,
        t_ms: i64,
        kind: EntryKind,
        episode_id: Option<&str>,
        leg: Option<&LegKey>,
        qty: Decimal,
        price: Option<Decimal>,
        cash_delta: Decimal,
        fees: Decimal,
        realized_delta: Decimal,
    ) -> LedgerEntry {
        self.seq += 1;
        LedgerEntry {
            account: self.id.clone(),
            seq: self.seq,
            t_ms,
            kind,
            episode_id: episode_id.map(str::to_string),
            leg: leg.cloned(),
            qty,
            price,
            cash_delta,
            fees,
            realized_delta,
            cash_after: self.cash,
            equity: None,
        }
    }

    /// Remove up to `qty` from a position: (quantity removed, basis leaving with it).
    fn take_out(&mut self, leg: &LegKey, qty: Decimal) -> (Decimal, Decimal) {
        let Some(p) = self.positions.get_mut(leg) else {
            return (Decimal::ZERO, Decimal::ZERO);
        };
        let q = qty.min(p.qty);
        if q <= Decimal::ZERO {
            return (Decimal::ZERO, Decimal::ZERO);
        }
        // Rounded to 12 dp so every ledger figure keeps ≤ 12 dp: sums stay far inside Decimal's
        // 28 significant digits and the equity identity holds exactly (no silent rounding).
        let out = if q == p.qty {
            p.basis
        } else {
            (p.basis * q / p.qty).round_dp_with_strategy(12, rust_decimal::RoundingStrategy::MidpointNearestEven)
        };
        p.qty -= q;
        p.basis -= out;
        if p.qty <= Decimal::ZERO {
            self.positions.remove(leg);
        }
        (q, out)
    }

    pub fn buy(&mut self, t_ms: i64, episode_id: &str, leg: &LegKey, f: &OrderFill) -> Option<LedgerEntry> {
        if f.filled <= Decimal::ZERO {
            return None;
        }
        let cost = f.notional + f.fees;
        self.cash -= cost;
        self.fees_paid += f.fees;
        let p = self.positions.entry(leg.clone()).or_default();
        p.qty += f.filled;
        p.basis += cost;
        Some(self.entry(t_ms, EntryKind::Buy, Some(episode_id), Some(leg), f.filled, f.vwap(), -cost, f.fees, Decimal::ZERO))
    }

    pub fn sell(&mut self, t_ms: i64, episode_id: &str, leg: &LegKey, f: &OrderFill) -> Option<LedgerEntry> {
        if f.filled <= Decimal::ZERO {
            return None;
        }
        let (q, basis_out) = self.take_out(leg, f.filled);
        let proceeds = f.notional - f.fees;
        self.cash += proceeds;
        self.fees_paid += f.fees;
        let realized = proceeds - basis_out;
        self.realized += realized;
        Some(self.entry(t_ms, EntryKind::Sell, Some(episode_id), Some(leg), q, f.vwap(), proceeds, f.fees, realized))
    }

    /// NO→collateral (NegRisk adapter): |S| NO sets of size q pay (|S| − 1)·q·(1 − feeBips) and
    /// return q YES of every leg outside S (marked 0). q is capped by what every S leg still holds.
    pub fn convert(&mut self, t_ms: i64, episode_id: &str, s_legs: &[LegKey], complements: &[LegKey], q: Decimal) -> Option<LedgerEntry> {
        if s_legs.len() < 2 {
            return None;
        }
        let held = s_legs
            .iter()
            .map(|l| self.positions.get(l).map_or(Decimal::ZERO, |p| p.qty))
            .min()
            .unwrap_or(Decimal::ZERO);
        let q = q.min(held);
        if q <= Decimal::ZERO {
            return None;
        }
        let mut basis_out = Decimal::ZERO;
        for l in s_legs {
            basis_out += self.take_out(l, q).1;
        }
        let sets = Decimal::from(u64::try_from(s_legs.len()).unwrap_or(u64::MAX)) - Decimal::ONE;
        let gross = sets * q;
        let fee = gross * self.spec.fee_bips / Decimal::from(10_000);
        let cash_in = gross - fee;
        self.cash += cash_in;
        self.fees_paid += fee;
        let realized = cash_in - basis_out;
        self.realized += realized;
        for c in complements {
            *self.returned.entry(c.clone()).or_default() += q;
        }
        Some(self.entry(t_ms, EntryKind::Convert, Some(episode_id), None, q, None, cash_in, fee, realized))
    }

    /// Settle every holding in `market_id` at its payout vector (never an assumed {0,1}; Q19).
    pub fn settle(&mut self, t_ms: i64, market_id: &str, payout_yes: Decimal, payout_no: Decimal) -> Vec<LedgerEntry> {
        let pay_of = |o: Outcome| match o {
            Outcome::Yes => payout_yes,
            Outcome::No => payout_no,
        };
        let mut out = Vec::new();
        let held: Vec<LegKey> = self.positions.keys().filter(|k| k.market_id == market_id).cloned().collect();
        for leg in held {
            let (q, basis) = self.take_out(&leg, Decimal::MAX);
            let price = pay_of(leg.outcome);
            let pay = q * price;
            self.cash += pay;
            self.realized += pay - basis;
            out.push(self.entry(t_ms, EntryKind::Settle, None, Some(&leg), q, Some(price), pay, Decimal::ZERO, pay - basis));
        }
        let returned: Vec<LegKey> = self.returned.keys().filter(|k| k.market_id == market_id).cloned().collect();
        for leg in returned {
            let q = self.returned.remove(&leg).unwrap_or(Decimal::ZERO);
            let price = pay_of(leg.outcome);
            let pay = q * price;
            self.cash += pay;
            self.realized += pay;
            out.push(self.entry(t_ms, EntryKind::Settle, None, Some(&leg), q, Some(price), pay, Decimal::ZERO, pay));
        }
        out
    }

    /// Positions at the current bid (none → 0, conservative); returned YES at 0 (spec §5.6).
    pub fn valuation(&self, bid: impl Fn(&LegKey) -> Option<Decimal>) -> Valuation {
        let mut v = Valuation { marks: Decimal::ZERO, basis_open: Decimal::ZERO };
        for (leg, p) in &self.positions {
            v.marks += p.qty * bid(leg).unwrap_or(Decimal::ZERO);
            v.basis_open += p.basis;
        }
        v
    }

    pub fn mark(&mut self, t_ms: i64, bid: impl Fn(&LegKey) -> Option<Decimal>) -> LedgerEntry {
        let equity = self.cash + self.valuation(bid).marks;
        self.peak_equity = self.peak_equity.max(equity);
        self.max_drawdown = self.max_drawdown.max(self.peak_equity - equity);
        let mut e = self.entry(t_ms, EntryKind::Mark, None, None, Decimal::ZERO, None, Decimal::ZERO, Decimal::ZERO, Decimal::ZERO);
        e.equity = Some(equity);
        e
    }
}

/// The outcome bought on the `pos`-th used leg of a signal of kind `k`.
pub fn outcome_for(k: Kind, pos: usize) -> Outcome {

        Kind::Implication if pos == 0 => Outcome::No,
        _ => Outcome::Yes,

/// Cost of buying `q` along `levels` (+ conservative fees unless `gross`) and the worst price
/// touched. None if the levels hold less than `q`.
pub fn walk_cost(levels: &[(Price, Shares)], q: Decimal, fee: FeeSchedule, gross: bool) -> Option<(Decimal, Price)> {
    let mut left = q;
    let mut cost = Decimal::ZERO;
    let mut worst = None;
    for &(p, s) in levels {
        if left <= Decimal::ZERO {
            break;
        }
        let take = s.get().min(left);
        if take <= Decimal::ZERO {
            continue;
        }
        cost += p.get() * take;
        if !gross {
            cost += fee.fee_conservative(p, take);
        }
        worst = Some(p);
        left -= take;
    }
    if left > Decimal::ZERO {
        return None;
    }
    worst.map(|w| (cost, w))
}

pub fn decide(cfg: &SimConfig, spec: &AccountSpec, free_cash: Decimal, ctx: &OpenCtx) -> Decision {
    let kind = ctx.signal.kind;
    if !takes_kind(spec.policy, kind) {
        return Decision::NotMine;
    }
    let naive = spec.policy == PolicyKind::P3Naive;
    let quote = if naive { &ctx.signal.gross } else { &ctx.signal.quote };
    let edge = if naive { quote.pnl_gross } else { quote.pnl };
    if edge <= Decimal::ZERO {
        return Decision::Skip(SkipReason::NotNetPositive);
    }
    match spec.policy {
        PolicyKind::P1Settlement => {
            let (Some(days), Some(ann)) = (ctx.days_to_end, ctx.annualized) else {
                return Decision::Skip(SkipReason::NoLockupFigures);
            };
            if days < Decimal::ZERO || days > cfg.p1.max_days_to_end {
                return Decision::Skip(SkipReason::TooLong);
            }
            if ann < cfg.p1.min_annualized {
                return Decision::Skip(SkipReason::AnnualizedTooLow);
            }
        }
        PolicyKind::P2Combo if !ctx.pair_approved => return Decision::Skip(SkipReason::PairNotApproved),
        _ => {}
    }
    let used = &ctx.signal.legs_used;
    let mut infos = Vec::with_capacity(used.len());
    for &gi in used {
        match ctx.legs.get(gi) {
            Some(l) => infos.push(l),
            None => return Decision::Skip(SkipReason::BadInput),
        }
    }
    if ctx.open_levels.len() != used.len() {
        return Decision::Skip(SkipReason::BadInput);
    }
    // One complete basket: every used leg. A NO walk drops legs as they exhaust (L11); v1 trades
    // only the full set, whose size is the smallest leg fill (conservative, see plan rulings).
    let q_open = quote.legs.iter().map(|l| l.filled).min().unwrap_or(Decimal::ZERO);
    if q_open <= Decimal::ZERO {
        return Decision::Skip(SkipReason::BelowMinSize);
    }
    let at = |q: Decimal| -> Option<(Decimal, Vec<Price>)> {
        let mut total = Decimal::ZERO;
        let mut limits = Vec::with_capacity(infos.len());
        for (levels, info) in ctx.open_levels.iter().zip(&infos) {
            let (c, w) = walk_cost(levels, q, info.fee, naive)?;
            total += c;
            limits.push(w);
        }
        Some((total, limits))
    };
    let Some((cost_open, _)) = at(q_open) else {
        return Decision::Skip(SkipReason::BadInput);
    };
    let Some(unit_cost) = cost_open.checked_div(q_open).filter(|u| *u > Decimal::ZERO) else {
        return Decision::Skip(SkipReason::BadInput);
    };
    let afford = free_cash / unit_cost;
    if afford < cfg.min_order_shares {
        return Decision::Skip(SkipReason::NoCash);
    }
    let q_want = q_open.min(spec.per_trade / unit_cost).min(afford);
    let Some((_, limits)) = at(q_want) else {
        return Decision::Skip(SkipReason::BadInput);
    };
    let q = order_size(&limits, q_want, cfg.min_order_shares);
    if q <= Decimal::ZERO {
        return Decision::Skip(SkipReason::BelowMinSize);
    }
    let legs: Vec<IntentLeg> = infos
        .iter()
        .zip(&limits)
        .enumerate()
        .map(|(pos, (info, &limit))| IntentLeg {
            key: LegKey {
                market_id: info.market_id.clone(),
                yes_token: info.yes_token.clone(),
                outcome: outcome_for(kind, pos),
            },
            limit,
            fee: info.fee,
            seconds_delay: info.seconds_delay,
        })
        .collect();
    let reserve = legs
        .iter()
        .map(|l| (l.limit.get() + l.fee.phi(l.limit)) * q)
        .sum::<Decimal>()
        + Decimal::new(1, 3);
    let hold = if kind == Kind::NoBasket {
        Hold::Convert {
            complements: ctx
                .legs
                .iter()
                .enumerate()
                .filter(|(i, _)| !used.contains(i))
                .map(|(_, l)| LegKey { market_id: l.market_id.clone(), yes_token: l.yes_token.clone(), outcome: Outcome::Yes })
                .collect(),
        }
    } else {
        Hold::ToResolution
    };
    Decision::Take(Planned { legs, q_target: q, reserve, hold, detected_pnl: edge, detected_q: q_open })
}

pub fn cfg(accounts: &[(PolicyKind, &str)]) -> SimConfig {
    SimConfig {
        settle_delay_ms: 2000,
        markout_offsets_ms: vec![1000],
        mark_every_ms: 60_000,
        burst_window_ms: 10_000,
        min_order_shares: d("5"),
        p1: P1Params { min_annualized: d("0.10"), max_days_to_end: d("30") },
        scenarios: vec![Scenario { name: "t".into(), proc_ms: 0, net_ms: 0, match_ms: 100, honor_seconds_delay: true, burst: vec![] }],
        accounts: accounts
            .iter()
            .map(|(policy, bankroll)| AccountSpec { policy: *policy, scenario: "t".into(), bankroll: d(bankroll), per_trade: d("100"), fee_bips: Decimal::ZERO })
            .collect(),
    }
}

fn books_of(g: &arb_core::detect::Group) -> HashMap<String, Book> {
    g.legs.iter().enumerate().map(|(i, l)| (format!("y{i}"), l.book.clone())).collect()
}

const NO3: [Outcome; 3] = [Outcome::No, Outcome::No, Outcome::No];

fn fills(outs: &[SimOut]) -> Vec<(String, Decimal)> {
    outs.iter()
        .filter_map(|o| match o {
            SimOut::Fill(f) => Some((f.leg.market_id.clone(), f.filled)),
            _ => None,
        })
        .collect()
}

#[test]
fn no_basket_executes_at_t_x_then_converts() {
    let g = no_group(FeeSchedule::ZERO);
    let books = books_of(&g);
    let mut t = PaperTrader::new(cfg(&[(PolicyKind::P0Converter, "1000")])).unwrap();
    let outs = t.on_open(&ctx("e1", 1000, &g, detect_no_basket(&g).unwrap(), &NO3));
    assert!(matches!(&outs[..], [SimOut::Intent(i)] if i.skip_reason.is_none() && i.exec_ms == Some(1100)));
    assert!(fills(&t.on_frame(1050, &books)).is_empty(), "not due yet");
    let outs = t.on_frame(1100, &books);
    assert_eq!(fills(&outs), vec![("m0".into(), d("51.2")), ("m1".into(), d("51.2")), ("m2".into(), d("51.2"))]);
    let exec = outs.iter().find_map(|o| if let SimOut::Exec(e) = o { Some(e.clone()) } else { None }).unwrap();
    assert_eq!((exec.q_eff, exec.leg_risk_qty, exec.hit), (d("51.2"), d("0"), true));
    let a = &t.accounts()[0];
    assert_eq!(a.cash, d("900.16")); // 1000 − 51.2 × 1.95
    assert_eq!(a.reserved, d("0"), "reservation released at execution");

    let outs = t.on_frame(3100, &books); // settle delay 2000
    assert!(outs.iter().any(|o| matches!(o, SimOut::Ledger(e) if e.kind == sim::account::EntryKind::Convert)));
    let a = &t.accounts()[0];
    assert_eq!(a.cash, d("1002.56")); // + 2 × 51.2
    assert_eq!(a.realized, d("2.56"));
    assert_eq!(a.returned.values().copied().collect::<Vec<_>>(), vec![d("51.2")]);
}

#[test]
fn a_second_episode_cannot_refill_consumed_liquidity() {
    let g = no_group(FeeSchedule::ZERO);
    let mut books = books_of(&g);
    let mut t = PaperTrader::new(cfg(&[(PolicyKind::P0Converter, "1000")])).unwrap();
    t.on_open(&ctx("e1", 1000, &g, detect_no_basket(&g).unwrap(), &NO3));
    t.on_frame(1100, &books);
    t.on_open(&ctx("e2", 1200, &g, detect_no_basket(&g).unwrap(), &NO3));
    let outs = t.on_frame(1300, &books);
    assert_eq!(fills(&outs), vec![("m0".into(), d("48.8")), ("m1".into(), d("48.8")), ("m2".into(), d("48.8"))]);
    // the feed then shows leg 0's YES bid shrink by ≥ what we took: it clears
    books.get_mut("y0").unwrap().apply_delta(Side::Bid, p("0.40"), arb_core::money::Shares::parse("0").unwrap(), 1400);
    t.on_level("y0", BookSide::Bid, d("0.40"), d("0"));
    books.get_mut("y0").unwrap().apply_delta(Side::Bid, p("0.40"), arb_core::money::Shares::parse("100").unwrap(), 1401);
    t.on_open(&ctx("e3", 1500, &g, detect_no_basket(&g).unwrap(), &NO3));
    let outs = t.on_frame(1600, &books);
    assert_eq!(fills(&outs)[0], ("m0".into(), d("51.2")));
}

#[test]
fn a_leg_that_thins_before_t_x_creates_leg_risk_which_is_unwound() {
    let g = no_group(FeeSchedule::ZERO);
    let mut books = books_of(&g);
    let mut t = PaperTrader::new(cfg(&[(PolicyKind::P0Converter, "1000")])).unwrap();
    t.on_open(&ctx("e1", 1000, &g, detect_no_basket(&g).unwrap(), &NO3));
    // between open and t_x, leg 2's YES bid (its NO ask 0.70) drops to 20
    books.get_mut("y2").unwrap().apply_delta(Side::Bid, p("0.30"), arb_core::money::Shares::parse("20").unwrap(), 1050);
    t.on_level("y2", BookSide::Bid, d("0.30"), d("20"));
    let outs = t.on_frame(1100, &books);
    assert_eq!(fills(&outs)[2], ("m2".into(), d("20")));
    let exec = outs.iter().find_map(|o| if let SimOut::Exec(e) = o { Some(e.clone()) } else { None }).unwrap();
    assert_eq!((exec.q_eff, exec.leg_risk_qty), (d("20"), d("62.4")));
    // unwinds due at t_x + 100: sell 31.2 NO on legs 0 and 1 at NO bids 0.55 / 0.60
    let outs = t.on_frame(1200, &books);
    let sells: Vec<_> = outs.iter().filter_map(|o| if let SimOut::Fill(f) = o { Some((f.side, f.filled, f.vwap)) } else { None }).collect();
    assert_eq!(sells, vec![("sell", d("31.2"), Some(d("0.55"))), ("sell", d("31.2"), Some(d("0.60")))]);
    t.on_frame(3100, &books); // conversion of the 20 complete sets
    let a = &t.accounts()[0];
    // unwinds: 31.2·(0.55 − 0.60) + 31.2·(0.60 − 0.65) = −3.12; conversion: 20·(2 − 1.95) = +1
    assert_eq!(a.realized, d("-2.12"));
    assert!(a.positions.is_empty());
}

//! The paper trader (spec §5.6, §11): one account per `policies.toml` entry, each with its own
//! consumed-liquidity ledger. Pure: time arrives on the inputs (see the call contract in the plan).
use crate::SimError;
use crate::account::Account;
use crate::config::SimConfig;
use crate::consumed::ConsumedLiquidity;
use crate::latency::{FrameRate, exec_delay_ms};
use crate::policy::{Decision, Hold, OpenCtx, Planned, decide};
use crate::rows::{AccountRow, ExecRow, FillRow, IntentRow, MarkoutRow, SimOut};

pub struct PaperTrader {
    cfg: SimConfig,
    accounts: Vec<Account>,
    scenario_ix: Vec<usize>,
    consumed: Vec<ConsumedLiquidity>,
    pending: Vec<Pending>,
    unwinds: Vec<Unwind>,
    conversions: Vec<Conversion>,
    markouts: Vec<Markout>,
    rate: FrameRate,
    next_mark_ms: Option<i64>,
}

/// Remove the items due at `now`, ordered by due time (stable: insertion order breaks ties).
fn drain_due<T>(v: &mut Vec<T>, now: i64, due: impl Fn(&T) -> i64) -> Vec<T> {
    let (mut ready, rest): (Vec<T>, Vec<T>) = std::mem::take(v).into_iter().partition(|x| due(x) <= now);
    *v = rest;
    ready.sort_by_key(|x| due(x));
    ready
}

/// The bid we could sell `leg` into now (NO bid = 1 − YES ask).
pub fn bid_of(books: &impl Books, leg: &LegKey) -> Option<Decimal> {
    let top = books.yes_book(&leg.yes_token)?.top();
    match leg.outcome {
        Outcome::Yes => top.best_bid.map(|(p, _)| p.get()),
        Outcome::No => top.best_ask.map(|(p, _)| Decimal::ONE - p.get()),
    }
}

/// Mid of `leg`'s outcome (NO mid = 1 − YES mid); None unless both YES sides exist.
pub fn mid_of(books: &impl Books, leg: &LegKey) -> Option<Decimal> {
    let top = books.yes_book(&leg.yes_token)?.top();
    let m = (top.best_bid?.0.get() + top.best_ask?.0.get()) / Decimal::TWO;
    Some(match leg.outcome {
        Outcome::Yes => m,
        Outcome::No => Decimal::ONE - m,
    })
}

impl PaperTrader {
    pub fn new(cfg: SimConfig) -> Result<Self, SimError> {
        let accounts = cfg.accounts.iter().cloned().map(Account::new).collect();
        Self::with_accounts(cfg, accounts)
    }

    fn with_accounts(cfg: SimConfig, accounts: Vec<Account>) -> Result<Self, SimError> {
        cfg.validate()?;
        let scenario_ix = accounts
            .iter()
            .map(|a| {
                cfg.scenarios
                    .iter()
                    .position(|s| s.name == a.spec.scenario)
                    .ok_or_else(|| SimError::Config(format!("account {}: unknown scenario", a.id)))
            })
            .collect::<Result<Vec<_>, _>>()?;
        let n = accounts.len();
        Ok(Self {
            rate: FrameRate::new(cfg.burst_window_ms),
            cfg,
            accounts,
            scenario_ix,
            consumed: vec![ConsumedLiquidity::default(); n],
            pending: Vec::new(),
            unwinds: Vec::new(),
            conversions: Vec::new(),
            markouts: Vec::new(),
            next_mark_ms: None,
        })
    }

    pub fn accounts(&self) -> &[Account] {
        &self.accounts
    }

    fn delay(&self, acct: usize, seconds_delay: Option<i32>) -> i64 {
        let sc = &self.cfg.scenarios[self.scenario_ix[acct]];
        exec_delay_ms(sc, seconds_delay, self.rate.per_second())
    }

    pub fn on_open(&mut self, ctx: &OpenCtx) -> Vec<SimOut> {
        let mut out = Vec::new();
        let max_delay = ctx
            .signal
            .legs_used
            .iter()
            .filter_map(|&i| ctx.legs.get(i).and_then(|l| l.seconds_delay))
            .max();
        for a in 0..self.accounts.len() {
            let t_exec = ctx.r_open_ms + self.delay(a, max_delay);
            let acct = &self.accounts[a];
            match decide(&self.cfg, &acct.spec, acct.free_cash(), ctx) {
                Decision::NotMine => {}
                Decision::Skip(r) => out.push(SimOut::Intent(IntentRow {
                    account: acct.id.clone(),
                    episode_id: ctx.episode_id.clone(),
                    decided_ms: ctx.r_open_ms,
                    exec_ms: None,
                    skip_reason: Some(r.as_str().to_string()),
                    q_target: None,
                    detected_q: None,
                    detected_pnl: None,
                    reserve: None,
                })),
                Decision::Take(planned) => {
                    out.push(SimOut::Intent(IntentRow {
                        account: acct.id.clone(),
                        episode_id: ctx.episode_id.clone(),
                        decided_ms: ctx.r_open_ms,
                        exec_ms: Some(t_exec),
                        skip_reason: None,
                        q_target: Some(planned.q_target),
                        detected_q: Some(planned.detected_q),
                        detected_pnl: Some(planned.detected_pnl),
                        reserve: Some(planned.reserve),
                    }));
                    self.accounts[a].reserved += planned.reserve;
                    self.pending.push(Pending {
                        acct: a,
                        episode_id: ctx.episode_id.clone(),
                        kind: ctx.signal.kind,
                        planned,
                        t_exec,
                    });
                }
            }
        }
        out
    }

    /// Call BEFORE applying the frame at `recv_ms`: runs everything due at or before it.
    pub fn on_frame(&mut self, recv_ms: i64, books: &impl Books) -> Vec<SimOut> {
        self.rate.push(recv_ms);
        let mut out = Vec::new();
        for p in drain_due(&mut self.pending, recv_ms, |p| p.t_exec) {
            self.execute(p, books, &mut out);
        }
        for u in drain_due(&mut self.unwinds, recv_ms, |u| u.due_ms) {
            self.unwind(u, books, &mut out);
        }
        for c in drain_due(&mut self.conversions, recv_ms, |c| c.due_ms) {
            self.convert(c, &mut out);
        }
        for m in drain_due(&mut self.markouts, recv_ms, |m| m.due_ms) {
            let mid = mid_of(books, &m.leg);
            out.push(SimOut::Markout(MarkoutRow {
                account: self.accounts[m.acct].id.clone(),
                episode_id: m.episode_id,
                leg: m.leg,
                fill_vwap: m.vwap,
                offset_ms: m.offset_ms,
                mid,
                markout: mid.map(|x| x - m.vwap),
            }));
        }
        self.marks_due(recv_ms, books, &mut out);
        out
    }

    pub fn on_level(&mut self, yes_token: &str, side: BookSide, price: Decimal, new_size: Decimal) {
        let key = crate::consumed::LevelKey { yes_token: yes_token.to_string(), side, price };
        for c in &mut self.consumed {
            c.on_level(&key, new_size);
        }
    }

    pub fn on_snapshot(&mut self, yes_token: &str, book: &Book) {
        for c in &mut self.consumed {
            c.on_snapshot(yes_token, book);
        }
    }

    /// Π of the intended basket on the current books minus this account's consumed liquidity.
    fn pnl_now(&self, p: &Pending, books: &impl Books) -> Option<Decimal> {
        let consumed = &self.consumed[p.acct];
        let mut legs = Vec::with_capacity(p.planned.legs.len());
        for l in &p.planned.legs {
            let book = books.yes_book(&l.key.yes_token)?;
            let levels = outcome_levels(book, l.key.outcome, true)
                .into_iter()
                .filter_map(|(px, s)| {
                    let avail = consumed.available(&yes_level(&l.key, true, px), s.get());
                    Shares::new(avail).ok().filter(|a| a.get() > Decimal::ZERO).map(|a| (px, a))
                })
                .collect();
            legs.push(BuyLeg { levels, fee: l.fee });
        }
        let rule = match p.kind {
            Kind::NoBasket => BasketRule::NestedNo,
            _ => BasketRule::AllLegs { payoff: Decimal::ONE },
        };
        Some(walk(&legs, rule, None).pnl)
    }

    fn execute(&mut self, p: Pending, books: &impl Books, out: &mut Vec<SimOut>) {
        let a = p.acct;
        self.accounts[a].reserved = (self.accounts[a].reserved - p.planned.reserve).max(Decimal::ZERO);
        let pnl_at_tx = self.pnl_now(&p, books);
        let mut filled = Vec::with_capacity(p.planned.legs.len());
        for leg in &p.planned.legs {
            let f = match books.yes_book(&leg.key.yes_token) {
                Some(b) => fak_buy(b, &leg.key, leg.fee, leg.limit, p.planned.q_target, &mut self.consumed[a]),
                None => OrderFill::default(),
            };
            out.push(SimOut::Fill(FillRow {
                account: self.accounts[a].id.clone(),
                episode_id: p.episode_id.clone(),
                leg: leg.key.clone(),
                t_ms: p.t_exec,
                side: "buy",
                limit: Some(leg.limit.get()),
                requested: p.planned.q_target,
                filled: f.filled,
                vwap: f.vwap(),
                fees: f.fees,
                levels_used: f.levels_used,
            }));
            if let Some(e) = self.accounts[a].buy(p.t_exec, &p.episode_id, &leg.key, &f) {
                out.push(SimOut::Ledger(e));
            }
            filled.push(f);
        }
        let q_eff = filled.iter().map(|f| f.filled).min().unwrap_or(Decimal::ZERO);
        let mut leg_risk = Decimal::ZERO;
        for (leg, f) in p.planned.legs.iter().zip(&filled) {
            let excess = f.filled - q_eff;
            if excess > Decimal::ZERO {
                leg_risk += excess;
                let due_ms = p.t_exec + self.delay(a, leg.seconds_delay);
                self.unwinds.push(Unwind {
                    acct: a,
                    episode_id: p.episode_id.clone(),
                    leg: leg.key.clone(),
                    fee: leg.fee,
                    qty: excess,
                    due_ms,
                });
            }
            if let Some(vwap) = f.vwap() {
                for &off in &self.cfg.markout_offsets_ms {
                    self.markouts.push(Markout {
                        acct: a,
                        episode_id: p.episode_id.clone(),
                        leg: leg.key.clone(),
                        vwap,
                        offset_ms: off,
                        due_ms: p.t_exec + off,
                    });
                }
            }
        }
        if q_eff > Decimal::ZERO
            && let Hold::Convert { complements } = &p.planned.hold
        {
            self.conversions.push(Conversion {
                acct: a,
                episode_id: p.episode_id.clone(),
                s_legs: p.planned.legs.iter().map(|l| l.key.clone()).collect(),
                complements: complements.clone(),
                q: q_eff,
                due_ms: p.t_exec + self.cfg.settle_delay_ms,
            });
        }
        out.push(SimOut::Exec(ExecRow {
            account: self.accounts[a].id.clone(),
            episode_id: p.episode_id,
            exec_ms: p.t_exec,
            q_eff,
            leg_risk_qty: leg_risk,
            pnl_at_tx,
            hit: pnl_at_tx.is_some_and(|x| x > Decimal::ZERO),
        }));
    }

    fn unwind(&mut self, u: Unwind, books: &impl Books, out: &mut Vec<SimOut>) {
        let qty = u.qty.round_dp_with_strategy(2, RoundingStrategy::ToZero);
        // Below the venue minimum there is no order: the inventory is held, marked at the bid.
        if qty < self.cfg.min_order_shares {
            return;
        }
        let Some(book) = books.yes_book(&u.leg.yes_token) else {
            return;
        };
        let f = fak_sell(book, &u.leg, u.fee, qty, &mut self.consumed[u.acct]);
        out.push(SimOut::Fill(FillRow {
            account: self.accounts[u.acct].id.clone(),
            episode_id: u.episode_id.clone(),
            leg: u.leg.clone(),
            t_ms: u.due_ms,
            side: "sell",
            limit: None,
            requested: qty,
            filled: f.filled,
            vwap: f.vwap(),
            fees: f.fees,
            levels_used: f.levels_used,
        }));
        if let Some(e) = self.accounts[u.acct].sell(u.due_ms, &u.episode_id, &u.leg, &f) {
            out.push(SimOut::Ledger(e));
        }
    }

    fn convert(&mut self, c: Conversion, out: &mut Vec<SimOut>) {
        if let Some(e) = self.accounts[c.acct].convert(c.due_ms, &c.episode_id, &c.s_legs, &c.complements, c.q) {
            out.push(SimOut::Ledger(e));
        }
    }

    fn account_row(&self, a: usize, t_ms: i64, books: &impl Books) -> AccountRow {
        let acct = &self.accounts[a];
        let v = acct.valuation(|l| bid_of(books, l));
        AccountRow {
            account: acct.id.clone(),
            t_ms,
            cash: acct.cash,
            equity: acct.cash + v.marks,
            realized: acct.realized,
            unrealized: v.unrealized(),
            fees_paid: acct.fees_paid,
            locked: v.basis_open,
            max_drawdown: acct.max_drawdown,
            n_positions: i64::try_from(acct.positions.len() + acct.returned.len()).unwrap_or(i64::MAX),
        }
    }

    fn mark_all(&mut self, t_ms: i64, books: &impl Books, out: &mut Vec<SimOut>) {
        for a in 0..self.accounts.len() {
            let e = self.accounts[a].mark(t_ms, |l| bid_of(books, l));
            out.push(SimOut::Ledger(e));
            out.push(SimOut::Account(self.account_row(a, t_ms, books)));
        }
    }

    fn marks_due(&mut self, now: i64, books: &impl Books, out: &mut Vec<SimOut>) {
        let every = self.cfg.mark_every_ms;
        let aligned_after = |t: i64| (t.div_euclid(every) + 1) * every;
        let Some(next) = self.next_mark_ms else {
            self.next_mark_ms = Some(aligned_after(now));
            return;
        };
        if now < next {
            return;
        }
        // One mark at the latest boundary ≤ now, however long the input gap was.
        let at = now.div_euclid(every) * every;
        self.mark_all(at, books, out);
        self.next_mark_ms = Some(aligned_after(now));
    }
}

    /// A market resolved with this payout vector: settle it in every account (spec §5.6, Q19).
    pub fn on_resolution(&mut self, t_ms: i64, market_id: &str, payout_yes: Decimal, payout_no: Decimal) -> Vec<SimOut> {
        let mut out = Vec::new();
        for a in 0..self.accounts.len() {
            let entries = self.accounts[a].settle(t_ms, market_id, payout_yes, payout_no);
            if entries.is_empty() {
                continue;
            }
            out.extend(entries.into_iter().map(SimOut::Ledger));
            // No books here: remaining positions are valued at 0 in this row (conservative);
            // the next minute mark revalues them at the bid.
            let acct = &self.accounts[a];
            let v = acct.valuation(|_| None);
            out.push(SimOut::Account(AccountRow {
                account: acct.id.clone(),
                t_ms,
                cash: acct.cash,
                equity: acct.cash + v.marks,
                realized: acct.realized,
                unrealized: v.unrealized(),
                fees_paid: acct.fees_paid,
                locked: v.basis_open,
                max_drawdown: acct.max_drawdown,
                n_positions: i64::try_from(acct.positions.len() + acct.returned.len()).unwrap_or(i64::MAX),
            }));
        }
        out
    }

    /// Shutdown at `t_ms`: complete pending conversions (the on-chain step would have happened),
    /// drop pending intents (releasing their reservations), unwinds and markouts, then mark.
    pub fn close(&mut self, t_ms: i64, books: &impl Books) -> Vec<SimOut> {
        let mut out = Vec::new();
        for mut c in std::mem::take(&mut self.conversions) {
            c.due_ms = t_ms;
            self.convert(c, &mut out);
        }
        for p in std::mem::take(&mut self.pending) {
            let a = &mut self.accounts[p.acct];
            a.reserved = (a.reserved - p.planned.reserve).max(Decimal::ZERO);
        }
        self.unwinds.clear();
        self.markouts.clear();
        self.mark_all(t_ms, books, &mut out);
        out
    }

    pub fn state(&self) -> TraderState {
        TraderState { accounts: self.accounts.clone() }
    }

    pub fn restore(cfg: SimConfig, state: TraderState) -> Result<Self, SimError> {
        let mut saved: HashMap<String, Account> = state.accounts.into_iter().map(|a| (a.id.clone(), a)).collect();
        let accounts = cfg
            .accounts
            .iter()
            .map(|spec| {
                saved.remove(&spec.id()).map_or_else(
                    || Account::new(spec.clone()),
                    |mut a| {
                        a.reserved = Decimal::ZERO;
                        a
                    },
                )
            })
            .collect();
        Self::with_accounts(cfg, accounts)
    }
```

Note: `close` sets `c.due_ms = t_ms` so the conversion's ledger entry is stamped at the shutdown time; `convert` already uses `c.due_ms` as its `t_ms`.

## Rulings recorded in this plan (owner: check)

1. **Full-set execution only for NO baskets.** Spec §5.6 says `q_eff` is taken "per nested basket, L11". v1 trades only the complete set (every used leg), sized by the walk's smallest leg fill. This is conservative: it executes less than the nested optimum. Nested execution can come later without changing the ledger.
2. **FAK limit = the worst open level needed for `q_target`.** Spec: "a FAK limit at the price level detected at open".
3. **Consumed liquidity clears in full, never partially.** A clear needs a cumulative shrink of at least the consumed amount relative to the size seen when we consumed; a partial shrink leaves the whole amount consumed. This is conservative: it gives less available depth.
4. **Unwind below 5 shares = no order.** The inventory is held and marked at the bid until resolution, since the venue minimum applies to sells too.
5. **`L_proc` is a config constant** (`proc_ms`), not measured in-process, so replay stays deterministic. The measured value belongs in the soak write-up.
6. **Burst thresholds (2000 / 6000 frames/s) are placeholders.** Recalibrate them from the soak's `health.msgs` before the first evaluation run, since the file is frozen per run.
7. **Marks are driven by input time** (every 60 s of frame time). One mark covers any longer gap.
8. **Restarts keep accounts only.** Pending intents, unwinds and markouts are dropped at shutdown; pending conversions complete at shutdown.
