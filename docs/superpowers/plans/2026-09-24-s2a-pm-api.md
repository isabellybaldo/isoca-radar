# S2a `pm-api` Implementation Plan (Phase 2, part 1 of 3)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build `pm-api`, the only crate allowed to touch the network. It holds the read-only wire types, parsers and clients for Gamma discovery, CLOB `/books` + `/ok`, and the market websocket, plus pure reconnect-backoff and connection-budget logic.

**Architecture:** A new workspace crate `crates/pm-api` depending on `arb-core`. Parsing is **pure and offline-tested** against fixtures shaped like the documented payloads. Network calls are thin `async` wrappers, tested only by `#[ignore]`d live tests. Every URL lives in `routes.rs`, and a test forbids URL literals anywhere else. Numbers never pass through `f64`: `serde_json` runs with `arbitrary_precision` and every number becomes an exact `Decimal` from its source text.

**Tech Stack:** Rust 1.98.1, tokio 1, reqwest 0.12 (rustls), tokio-tungstenite 0.26 (rustls + webpki roots), serde / serde_json (`arbitrary_precision`), futures-util, rustls 0.23 (ring provider), arb-core.

**Spec:** `docs/superpowers/specs/2026-09-22-arb-scanner-design.md` (§3 API facts, §7 capture, §8.1.2 resilience, §16 enforcement).

## Global Constraints

- PAPER TRADING ONLY. pm-api exposes exactly: `GET /events/keyset` (Gamma), `GET /book`, `POST /books`, `GET /ok` (CLOB), the market websocket, and the Sports websocket. A test asserts this route table.
- No URL literal (`http://`, `https://`, `ws://`, `wss://`) anywhere in `crates/pm-api/src` except `routes.rs` (test-enforced).
- No credentials of any kind. No auth headers, no signing, no order routes.
- Numbers from the wire are parsed to `Decimal` from their exact text: `serde_json` feature `arbitrary_precision`, never `as_f64`.
- External input never panics: no `unwrap`/`expect` in `src` (workspace clippy deny); malformed input returns `ApiError`.
- Gamma pagination uses exactly `after_cursor`; a page that brings no new ids while a cursor is still returned is an error (`ApiError::Stuck`), never a silent stop.
- Commit messages are plain, with no co-author or attribution trailer.

## Review Focus

1. **Gamma sends explicit `null`** for booleans, `markets` or `clobTokenIds`. Parsing must succeed, treating null as absent (pinned in Task 2).
2. **Numeric fields arrive as JSON numbers in some places and strings in others** (ids, fee rate, exponent, timestamps). Both must parse exactly (pinned in Tasks 2, 4, 5).
3. **`price_changes` items with `best_bid: ""`** (an empty book side) must become `None`, not an error (pinned in Task 5).
4. **The initial websocket dump arrives as a JSON array** while later events are single objects. Both must parse (pinned in Task 5).
5. **A server ignoring the cursor** (repeating page 1) must stop with `Stuck` instead of looping or truncating silently (pinned in Task 3).

```rust
use thiserror::Error;

#[derive(Debug, Error)]
pub enum ApiError {
    #[error("http: {0}")]
    Http(#[from] reqwest::Error),
    #[error("json: {0}")]
    Json(#[from] serde_json::Error),
    #[error("bad field {field}: {detail}")]
    Field { field: &'static str, detail: String },
    #[error("websocket: {0}")]
    Ws(Box<tokio_tungstenite::tungstenite::Error>),
    #[error("pagination made no progress after {0} pages (cursor ignored?)")]
    Stuck(usize),
}

impl From<tokio_tungstenite::tungstenite::Error> for ApiError {
    fn from(e: tokio_tungstenite::tungstenite::Error) -> Self {
        ApiError::Ws(Box::new(e))
    }
}

impl ApiError {
    pub fn field(field: &'static str, detail: impl Into<String>) -> Self {
        ApiError::Field { field, detail: detail.into() }
    }
}
```

```rust
//! Shared exact-parsing helpers. Numbers keep their source text (serde_json arbitrary_precision).
use crate::ApiError;
use rust_decimal::Decimal;
use serde::{Deserialize, Deserializer};
use serde_json::Value;

/// Accept a JSON string or number; numbers are rendered from their exact source text.
pub fn string_or_number<'de, D: Deserializer<'de>>(d: D) -> Result<String, D::Error> {
    match Value::deserialize(d)? {
        Value::String(s) => Ok(s),
        Value::Number(n) => Ok(n.to_string()),
        other => Err(serde::de::Error::custom(format!("expected string or number, got {other}"))),
    }
}

/// Exact Decimal from a JSON string or number.
pub fn decimal(v: &Value, field: &'static str) -> Result<Decimal, ApiError> {
    let text = match v {
        Value::String(s) => s.clone(),
        Value::Number(n) => n.to_string(),
        other => return Err(ApiError::field(field, format!("not a number: {other}"))),
    };
    Decimal::from_str_exact(text.trim()).map_err(|e| ApiError::field(field, e.to_string()))
}

/// A list of strings sent either as a real JSON array or as a JSON-encoded string ("[\"a\",\"b\"]").
/// Absent or null → empty.
pub fn string_array(v: &Option<Value>, field: &'static str) -> Result<Vec<String>, ApiError> {
    let raw = match v {
        None | Some(Value::Null) => return Ok(Vec::new()),
        Some(v) => v,
    };
    let arr = match raw {
        Value::String(s) => {
            serde_json::from_str::<Value>(s).map_err(|e| ApiError::field(field, e.to_string()))?
        }
        other => other.clone(),
    };
    match arr {
        Value::Array(items) => items
            .into_iter()
            .map(|x| match x {
                Value::String(s) => Ok(s),
                Value::Number(n) => Ok(n.to_string()),
                other => Err(ApiError::field(field, format!("unexpected element {other}"))),
            })
            .collect(),
        other => Err(ApiError::field(field, format!("not an array: {other}"))),
    }
}
```

```rust
/// (YES token, NO token), or None when Gamma has no ids yet.
pub fn token_ids(m: &GammaMarket) -> Result<Option<(String, String)>, ApiError> {
    let ids = string_array(&m.clob_token_ids, "clobTokenIds")?;
    match ids.as_slice() {
        [] => Ok(None),
        [yes, no] => Ok(Some((yes.clone(), no.clone()))),
        _ => Err(ApiError::field("clobTokenIds", format!("expected 2 ids, got {}", ids.len()))),
    }
}

/// The market's taker fee schedule; disabled or absent → zero fees.
pub fn fee_schedule(m: &GammaMarket) -> Result<FeeSchedule, ApiError> {
    if m.fees_enabled == Some(false) {
        return Ok(FeeSchedule::ZERO);
    }
    let Some(fs) = &m.fee_schedule else {
        return Ok(FeeSchedule::ZERO);
    };
    let rate = match &fs.rate {
        Some(v) => decimal(v, "feeSchedule.rate")?,
        None => Decimal::ZERO,
    };
    let exponent = match &fs.exponent {
        Some(v) => {
            let d = decimal(v, "feeSchedule.exponent")?;
            if d.fract() != Decimal::ZERO || d < Decimal::ONE || d > Decimal::from(4u8) {
                return Err(ApiError::field("feeSchedule.exponent", d.to_string()));
            }
            let mut e: u8 = 1;
            while Decimal::from(e) < d {
                e += 1;
            }
            e
        }
        None => 1,
    };
    FeeSchedule::new(rate, exponent).map_err(|e| ApiError::field("feeSchedule", e.to_string()))
}

/// Resolved outcome from outcomePrices: Some(true) = YES won, Some(false) = NO won.
fn resolved_outcome(m: &GammaMarket) -> Option<bool> {
    let p = string_array(&m.outcome_prices, "outcomePrices").ok()?;
    if p.len() != 2 {
        return None;
    }
    let y = Decimal::from_str_exact(p[0].trim()).ok()?;
    let n = Decimal::from_str_exact(p[1].trim()).ok()?;
    if y == Decimal::ONE && n == Decimal::ZERO {
        Some(true)
    } else if y == Decimal::ZERO && n == Decimal::ONE {
        Some(false)
    } else {
        None
    }
}

/// Classify a leg (spec §7 universe): Other > Closed* > Live > Placeholder (augmented) / Halted.
pub fn leg_status(m: &GammaMarket, augmented: bool) -> LegStatus {
    if m.neg_risk_other.unwrap_or(false) {
        return LegStatus::Other;
    }
    if m.closed.unwrap_or(false) {
        return match resolved_outcome(m) {
            Some(true) => LegStatus::ClosedYes,
            Some(false) => LegStatus::ClosedNo,
            None => LegStatus::Halted,
        };
    }
    let live = m.active.unwrap_or(false)
        && m.accepting_orders.unwrap_or(false)
        && m.enable_order_book.unwrap_or(false);
    if live {
        LegStatus::Live
    } else if augmented {
        LegStatus::Placeholder
    } else {
        LegStatus::Halted
    }
}
```

```rust
use crate::routes::{GAMMA_BASE, GAMMA_EVENTS_KEYSET};
use std::collections::HashSet;
use std::future::Future;

/// Page through Gamma's keyset endpoint. Stops when no cursor is returned.
/// A page that brings no new ids while a cursor is still offered, or hitting `max_pages`,
/// is an error: a silently truncated universe is worse than a failed refresh (spec §7).
pub async fn fetch_all<F, Fut>(mut fetch: F, max_pages: usize) -> Result<Vec<GammaEvent>, ApiError>
where
    F: FnMut(Option<String>) -> Fut,
    Fut: Future<Output = Result<KeysetPage, ApiError>>,
{
    let mut seen = HashSet::new();
    let mut out = Vec::new();
    let mut cursor: Option<String> = None;
    for pages in 1..=max_pages {
        let page = fetch(cursor.clone()).await?;
        let mut new_ids = 0usize;
        for e in page.events {
            if seen.insert(e.id.clone()) {
                new_ids += 1;
                out.push(e);
            }
        }
        match page.next_cursor {
            Some(c) if !c.is_empty() => {
                if new_ids == 0 {
                    return Err(ApiError::Stuck(pages));
                }
                cursor = Some(c);
            }
            _ => return Ok(out),
        }
    }
    Err(ApiError::Stuck(max_pages))
}

pub struct GammaClient {
    http: reqwest::Client,
    base: String,
}

    pub fn new(http: reqwest::Client) -> Self {
        Self { http, base: GAMMA_BASE.to_string() }
    }

    /// One page of active, open events (≤ 100). The cursor parameter is exactly `after_cursor`.
    pub async fn page(&self, cursor: Option<String>) -> Result<KeysetPage, ApiError> {
        let mut query: Vec<(&str, String)> = vec![
            ("closed", "false".to_string()),
            ("active", "true".to_string()),
            ("limit", "100".to_string()),
        ];
        if let Some(c) = cursor {
            query.push(("after_cursor", c));
        }
        let text = self
            .http
            .get(format!("{}{}", self.base, GAMMA_EVENTS_KEYSET))
            .query(&query)
            .send()
            .await?
            .error_for_status()?
            .text()
            .await?;
        parse_page(&text)
    }

    pub async fn all_active_events(&self) -> Result<Vec<GammaEvent>, ApiError> {
        fetch_all(|c| self.page(c), 1_000).await
    }
}
```

```rust
        Some(Value::String(s)) => s.clone(),
        Some(Value::Number(n)) => n.to_string(),
        _ => return Err(ApiError::field("timestamp", "missing")),
    };
    text.trim().parse::<i64>().map_err(|e| ApiError::field("timestamp", e.to_string()))
}

    pub fn server_ts_ms(&self) -> Result<i64, ApiError> {
        ts_ms(&self.timestamp)
    }

        let mut b = Book::default();
        b.apply_snapshot(&levels(&self.bids)?, &levels(&self.asks)?, self.server_ts_ms()?);

    }

    tokens.chunks(MAX_TOKENS_PER_REQUEST).map(<[String]>::to_vec).collect()

    http: reqwest::Client,
    base: String,

        let mut out = Vec::new();
        for chunk in chunk_tokens(tokens) {
            let body: Vec<Value> = chunk.iter().map(|t| json!({ "token_id": t })).collect();
            let text = self
                .http
                .post(format!("{}{}", self.base, CLOB_BOOKS))
                .json(&body)
                .send()
                .await?
                .error_for_status()?
                .text()
                .await?;
            let mut books: Vec<BookWire> = serde_json::from_str(&text)?;
            out.append(&mut books);
        }
        Ok(out)
    }

    pub async fn ok(&self) -> Result<bool, ApiError> {
        let resp = self.http.get(format!("{}{}", self.base, CLOB_OK)).send().await?;
        Ok(resp.status().is_success())
    }
```

```rust
fn text_of(v: &Value, field: &'static str) -> Result<String, ApiError> {
    match v {
        Value::String(s) => Ok(s.clone()),
        Value::Number(n) => Ok(n.to_string()),
        other => Err(ApiError::field(field, format!("unexpected {other}"))),
    }

fn str_field(v: &Value, field: &'static str) -> Result<String, ApiError> {
    v.get(field).ok_or_else(|| ApiError::field(field, "missing")).and_then(|x| text_of(x, field))

        Some(x) => Price::parse(&text_of(x, field)?)

        .collect()
}

fn parse_event(v: &Value, out: &mut Vec<MarketEvent>) -> Result<(), ApiError> {
    let et = v.get("event_type").and_then(Value::as_str).unwrap_or("");
    match et {
        "book" => out.push(MarketEvent::Snapshot {
            token: str_field(v, "asset_id")?,
            server_ts_ms: ts(v)?,
            bids: levels_of(v.get("bids"))?,
            asks: levels_of(v.get("asks"))?,
        }),
        "price_change" => {
            let t = ts(v)?;
            let changes = v
                .get("price_changes")
                .and_then(Value::as_array)
                .ok_or_else(|| ApiError::field("price_changes", "missing"))?;
            for c in changes {
                let side = match c.get("side").and_then(Value::as_str) {
                    Some("BUY") => Side::Bid,
                    Some("SELL") => Side::Ask,
                    other => return Err(ApiError::field("side", format!("{other:?}"))),
                };
                out.push(MarketEvent::Delta {
                    token: str_field(c, "asset_id")?,
                    server_ts_ms: t,
                    side,
                    price: price(c, "price")?,
                    size: Shares::parse(&str_field(c, "size")?).map_err(|e| ApiError::field("size", e.to_string()))?,
                    best_bid: opt_price(c.get("best_bid"), "best_bid")?,
                    best_ask: opt_price(c.get("best_ask"), "best_ask")?,
                });
            }
        }
        "last_trade_price" => out.push(MarketEvent::LastTrade { token: str_field(v, "asset_id")?, server_ts_ms: ts(v)? }),
        "tick_size_change" => out.push(MarketEvent::TickSize { token: str_field(v, "asset_id")?, server_ts_ms: ts(v)? }),
        "market_resolved" => out.push(MarketEvent::Resolved {
            market: str_field(v, "market").unwrap_or_default(),
            server_ts_ms: ts(v).unwrap_or(0),
        }),
        "new_market" => out.push(MarketEvent::NewMarket { server_ts_ms: ts(v).unwrap_or(0) }),
        other => out.push(MarketEvent::Other { event_type: other.to_string() }),
    }
    Ok(())
}

/// Parse one text frame. The initial dump is a JSON array; later frames are single objects.
/// `PONG` (heartbeat reply) and blank frames yield no events.
pub fn parse_frame(text: &str) -> Result<Vec<MarketEvent>, ApiError> {
    let t = text.trim();
    if t.is_empty() || t.eq_ignore_ascii_case("PONG") {
        return Ok(Vec::new());
    }
    let v: Value = serde_json::from_str(t)?;
    let items = match v {
        Value::Array(a) => a,
        other => vec![other],
    };
    let mut out = Vec::new();
    for item in &items {
        parse_event(item, &mut out)?;
    }
    Ok(out)
}

pub fn subscribe_message(tokens: &[String]) -> String {
    json!({ "assets_ids": tokens, "type": "market", "initial_dump": true }).to_string()
}

/// Wall-clock microseconds (our receive clock; compared against server ms for lag).
pub fn now_us() -> i64 {
    SystemTime::now()
        .duration_since(UNIX_EPOCH)
        .map(|d| i64::try_from(d.as_micros()).unwrap_or(i64::MAX))
        .unwrap_or(0)
}

#[derive(Debug, Clone)]
pub struct Frame {
    pub conn: usize,
    pub recv_us: i64,
    pub text: String,
}

/// One websocket session: connect, subscribe, send `PING` every 10 s, forward every text frame.
/// Returns Ok(()) when the server closes or the receiver is dropped; Err on transport errors.
pub async fn run_connection(conn: usize, tokens: Vec<String>, tx: mpsc::Sender<Frame>) -> Result<(), ApiError> {
    let (ws, _) = tokio_tungstenite::connect_async(WS_MARKET).await?;
    let (mut write, mut read) = ws.split();
    write.send(Message::text(subscribe_message(&tokens))).await?;
    let mut ping = tokio::time::interval(Duration::from_secs(10));
    ping.tick().await;
    loop {
        tokio::select! {
            _ = ping.tick() => {
                write.send(Message::text("PING")).await?;
            }
            msg = read.next() => match msg {
                Some(Ok(Message::Text(t))) => {
                    let frame = Frame { conn, recv_us: now_us(), text: t.as_str().to_owned() };
                    if tx.send(frame).await.is_err() {
                        return Ok(());
                    }
                }
                Some(Ok(Message::Close(_))) | None => return Ok(()),
                Some(Ok(_)) => {}
                Some(Err(e)) => return Err(e.into()),
            }
        }
    }
}
```

```rust
//! Reconnect pacing (spec §8.1.2). Pure: time is passed in. Jitter is added by the caller.
use std::collections::VecDeque;

#[derive(Debug, Clone)]
pub struct Backoff {
    base_ms: u64,
    cap_ms: u64,
    healthy_ms: i64,
    attempt: u32,
    connected_at: Option<i64>,
}

impl Backoff {
    pub fn new(base_ms: u64, cap_ms: u64, healthy_ms: i64) -> Self {
        Self { base_ms, cap_ms, healthy_ms, attempt: 0, connected_at: None }
    }

    pub fn on_connected(&mut self, now_ms: i64) {
        self.connected_at = Some(now_ms);
    }

    /// Delay before the next attempt. Resets to `base_ms` only if the session that just ended
    /// lived longer than `healthy_ms` (a flapping link must not pull the delay down).
    pub fn on_disconnected(&mut self, now_ms: i64) -> u64 {
        if let Some(t) = self.connected_at.take() {
            if now_ms - t > self.healthy_ms {
                self.attempt = 0;
            }
        }
        let shift = self.attempt.min(20);
        let delay = self.base_ms.saturating_mul(1u64 << shift).min(self.cap_ms);
        self.attempt = self.attempt.saturating_add(1);
        delay
    }
}

/// Global limit on connection attempts across all shards: ≤ per_sec in any 1 s, ≤ per_min in any 60 s.
#[derive(Debug, Clone)]
pub struct ConnectBudget {
    per_sec: usize,
    per_min: usize,
    recent: VecDeque<i64>,
}

impl ConnectBudget {
    pub fn new(per_sec: usize, per_min: usize) -> Self {
        Self { per_sec, per_min, recent: VecDeque::new() }
    }

    pub fn try_take(&mut self, now_ms: i64) -> bool {
        while self.recent.front().is_some_and(|&t| now_ms - t >= 60_000) {
            self.recent.pop_front();
        }
        let last_sec = self.recent.iter().filter(|&&t| now_ms - t < 1_000).count();
        if last_sec >= self.per_sec || self.recent.len() >= self.per_min {
            return false;
        }
        self.recent.push_back(now_ms);
        true
    }
}
```
