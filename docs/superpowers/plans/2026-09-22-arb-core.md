# arb-core (S1) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build `arb-core`, the pure Rust math crate: exact money types, the fee model, L2 books with the YES/NO mirror, the depth-aware basket walker (L9, L11), detectors D1–D3, the episode tracker, and survival statistics. Every lemma gets a test.

**Architecture:** A single library crate in a new Cargo workspace at the repo root. No IO, no clock, no async: time arrives as integers on the inputs, so the same code will later run live, in replay, and in WASM. Everything is exact decimal (`rust_decimal`), and a test forbids `f32`/`f64` in the source.

**Tech Stack:** Rust (edition 2024), `rust_decimal` 1.41, `thiserror` 2, `proptest` 1 (dev), GitHub Actions CI, `cargo-deny`.

**Spec:** `docs/superpowers/specs/2026-09-22-arb-scanner-design.md` (branch `refactor`). §5 (math) and §15 (testing) are the source of truth for this plan.

## Global Constraints

- PAPER TRADING ONLY: no order placement, wallets, keys, signing code or exchange credentials, anywhere, ever.
- `arb-core` has **no IO dependencies** (no tokio, reqwest, sockets, filesystem in `src/`), and **no `f32`/`f64`** in `src/`.
- Every edge is **strict**: exactly 0 is not an opportunity.
- Prices and sizes have at most **6 decimal places**; prices are in [0, 1].
- Fee per share `φ(p) = rate · (p(1−p))^exponent`. Π books `fee_conservative` (round **up** to 5 dp per level fill).
- The NO book is the mirror of the YES book: NO ask = 1 − YES bid, NO bid = 1 − YES ask (L1).
- Commit messages are plain, with **no co-author or attribution trailer** (owner preference).
- Branch: `refactor`.

```rust
//! Spec §15: arb-core must never use floating point.
#![allow(clippy::unwrap_used, clippy::expect_used)]
use std::fs;
use std::path::Path;

fn scan(dir: &Path, hits: &mut Vec<String>) {
    for entry in fs::read_dir(dir).unwrap() {
        let path = entry.unwrap().path();
        if path.is_dir() {
            scan(&path, hits);
        } else if path.extension().is_some_and(|e| e == "rs") {
            let text = fs::read_to_string(&path).unwrap();
            for (n, line) in text.lines().enumerate() {
                let bytes = line.as_bytes();
                for needle in ["f32", "f64"] {
                    let mut start = 0;
                    while let Some(pos) = line[start..].find(needle) {
                        let at = start + pos;
                        let before_ok = at == 0 || !(bytes[at - 1].is_ascii_alphanumeric() || bytes[at - 1] == b'_');
                        let end = at + needle.len();
                        let after_ok = end >= bytes.len() || !(bytes[end].is_ascii_alphanumeric() || bytes[end] == b'_');
                        if before_ok && after_ok {
                            hits.push(format!("{}:{}: {}", path.display(), n + 1, line.trim()));
                        }
                        start = end;
                    }
                }
            }
        }
    }
}
```

```rust
//! Exact money types (spec §5.1, §15). No floating point.
use rust_decimal::Decimal;
use thiserror::Error;

/// Polymarket prices and sizes never exceed 6 decimal places (pUSD has 6).
pub const MAX_DP: u32 = 6;

#[derive(Debug, Clone, PartialEq, Eq, Error)]
pub enum MoneyError {
    #[error("not a decimal: {0:?}")]
    Parse(String),
    #[error("more than {MAX_DP} decimal places: {0}")]
    TooPrecise(Decimal),
    #[error("out of range: {0}")]
    OutOfRange(Decimal),
}

fn parse_decimal(s: &str) -> Result<Decimal, MoneyError> {
    Decimal::from_str_exact(s.trim()).map_err(|_| MoneyError::Parse(s.to_string()))
}

fn normalized_within_dp(d: Decimal) -> Result<Decimal, MoneyError> {
    let n = d.normalize();
    if n.scale() > MAX_DP {
        Err(MoneyError::TooPrecise(d))
    } else {
        Ok(n)
    }
}

/// A price in [0, 1], at most 6 decimal places, stored normalized (0.50 == 0.5).
#[derive(Debug, Clone, Copy, PartialEq, Eq, PartialOrd, Ord, Hash)]
pub struct Price(Decimal);

impl Price {
    pub fn new(d: Decimal) -> Result<Self, MoneyError> {
        if d < Decimal::ZERO || d > Decimal::ONE {
            return Err(MoneyError::OutOfRange(d));
        }
        Ok(Self(normalized_within_dp(d)?))
    }

    pub fn parse(s: &str) -> Result<Self, MoneyError> {
        Self::new(parse_decimal(s)?)
    }

    pub fn get(self) -> Decimal {
        self.0
    }

    /// L1 mirror: YES price p corresponds to NO price 1 − p.
    pub fn complement(self) -> Self {
        Self((Decimal::ONE - self.0).normalize())
    }
}

/// A non-negative share quantity, at most 6 decimal places.
#[derive(Debug, Clone, Copy, PartialEq, Eq, PartialOrd, Ord, Hash)]
pub struct Shares(Decimal);

impl Shares {
    pub fn new(d: Decimal) -> Result<Self, MoneyError> {
        if d < Decimal::ZERO {
            return Err(MoneyError::OutOfRange(d));
        }
        Ok(Self(normalized_within_dp(d)?))
    }

    pub fn parse(s: &str) -> Result<Self, MoneyError> {
        Self::new(parse_decimal(s)?)
    }

    pub fn get(self) -> Decimal {
        self.0
    }
}
```

```rust
//! Taker fee model (spec §3, §5.1, L8): fee = shares × rate × (p(1−p))^exponent.
use crate::money::Price;
use rust_decimal::{Decimal, RoundingStrategy};
use thiserror::Error;

#[derive(Debug, Clone, PartialEq, Eq, Error)]
pub enum FeeError {
    #[error("fee rate must be >= 0, got {0}")]
    NegativeRate(Decimal),
    #[error("fee exponent must be 1..=4, got {0}")]
    BadExponent(u8),
}

/// A market's taker fee schedule (Gamma `feeSchedule.rate` / `.exponent`). We are always the taker.
#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub struct FeeSchedule {
    rate: Decimal,
    exponent: u8,
}

impl FeeSchedule {
    pub const ZERO: FeeSchedule = FeeSchedule { rate: Decimal::ZERO, exponent: 1 };

    pub fn new(rate: Decimal, exponent: u8) -> Result<Self, FeeError> {
        if rate < Decimal::ZERO {
            return Err(FeeError::NegativeRate(rate));
        }
        if !(1..=4).contains(&exponent) {
            return Err(FeeError::BadExponent(exponent));
        }
        Ok(Self { rate, exponent })
    }

    /// Per-share fee φ(p) = rate · (p(1−p))^exponent. Symmetric: φ(p) = φ(1−p).
    pub fn phi(&self, p: Price) -> Decimal {
        let x = p.get() * (Decimal::ONE - p.get());
        let mut acc = Decimal::ONE;
        for _ in 0..self.exponent {
            acc *= x;
        }
        self.rate * acc
    }

    /// c(p) = p + φ(p): cost of buying one share at p (L8).
    pub fn buy_cost(&self, p: Price) -> Decimal {
        p.get() + self.phi(p)
    }

    /// v(b) = b − φ(b): proceeds of selling one share at b (L8).
    pub fn sell_proceeds(&self, b: Price) -> Decimal {
        b.get() - self.phi(b)
    }

    /// Unrounded fee for qty shares at p (for math checks).
    pub fn fee_exact(&self, p: Price, qty: Decimal) -> Decimal {
        self.phi(p) * qty
    }

    /// The docs' rule: rounded to 5 dp, anything below 0.00001 becomes 0 (rounding mode unverified).
    pub fn fee_venue(&self, p: Price, qty: Decimal) -> Decimal {
        self.fee_exact(p, qty)
            .round_dp_with_strategy(5, RoundingStrategy::MidpointAwayFromZero)
    }

    /// What Π books: always round up to 5 dp (never 0 for a positive fee).
    pub fn fee_conservative(&self, p: Price, qty: Decimal) -> Decimal {
        self.fee_exact(p, qty).round_dp_with_strategy(5, RoundingStrategy::AwayFromZero)
    }
}
```

```rust
//! L2 book for one YES token, with the NO side derived by the mirror (L1).
use crate::money::{Price, Shares};
use rust_decimal::Decimal;
use std::collections::BTreeMap;

#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub enum Side {
    Bid,
    Ask,
}

#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub struct Top {
    pub best_bid: Option<(Price, Shares)>,
    pub best_ask: Option<(Price, Shares)>,
}

#[derive(Debug, Clone, Default)]
pub struct Book {
    bids: BTreeMap<Price, Shares>,
    asks: BTreeMap<Price, Shares>,
    server_ts_ms: i64,
}

impl Book {
    pub fn apply_snapshot(&mut self, bids: &[(Price, Shares)], asks: &[(Price, Shares)], server_ts_ms: i64) {
        self.bids.clear();
        self.asks.clear();
        for &(p, s) in bids {
            if s.get() > Decimal::ZERO {
                self.bids.insert(p, s);
            }
        }
        for &(p, s) in asks {
            if s.get() > Decimal::ZERO {
                self.asks.insert(p, s);
            }
        }
        self.server_ts_ms = server_ts_ms;
    }

    /// `new_size` is the new aggregate size at `price` (0 removes the level). Returns true if the top changed.
    pub fn apply_delta(&mut self, side: Side, price: Price, new_size: Shares, server_ts_ms: i64) -> bool {
        let before = self.top();
        let map = match side {
            Side::Bid => &mut self.bids,
            Side::Ask => &mut self.asks,
        };
        if new_size.get() == Decimal::ZERO {
            map.remove(&price);
        } else {
            map.insert(price, new_size);
        }
        self.server_ts_ms = server_ts_ms;
        self.top() != before
    }

    pub fn top(&self) -> Top {
        Top {
            best_bid: self.bids.iter().next_back().map(|(p, s)| (*p, *s)),
            best_ask: self.asks.iter().next().map(|(p, s)| (*p, *s)),
        }
    }

    pub fn server_ts_ms(&self) -> i64 {
        self.server_ts_ms
    }

    /// L2: a single condition can only show arbitrage if the book is crossed (bid > ask).
    pub fn is_crossed(&self) -> bool {
        match (self.top().best_bid, self.top().best_ask) {
            (Some((b, _)), Some((a, _))) => b > a,
            _ => false,
        }
    }

    pub fn asks_best_first(&self) -> Vec<(Price, Shares)> {
        self.asks.iter().map(|(p, s)| (*p, *s)).collect()
    }

    pub fn bids_best_first(&self) -> Vec<(Price, Shares)> {
        self.bids.iter().rev().map(|(p, s)| (*p, *s)).collect()
    }

    /// L1: NO asks = 1 − YES bids, same sizes, best (lowest) first.
    pub fn no_asks_best_first(&self) -> Vec<(Price, Shares)> {
        self.bids_best_first().into_iter().map(|(p, s)| (p.complement(), s)).collect()
    }

    /// L1: NO bids = 1 − YES asks, same sizes, best (highest) first.
    pub fn no_bids_best_first(&self) -> Vec<(Price, Shares)> {
        self.asks_best_first().into_iter().map(|(p, s)| (p.complement(), s)).collect()
    }
}
```

```rust
/// L9 reference: unit-by-unit, stop at the first unit whose exact marginal is ≤ 0.
fn brute_all(legs: &[BuyLeg]) -> Decimal {
    let depth = legs.iter().map(|l| l.levels.len()).min().unwrap_or(0);
    let mut total = Decimal::ZERO;
    for k in 0..depth {
        let m = Decimal::ONE - legs.iter().map(|l| l.fee.buy_cost(l.levels[k].0)).sum::<Decimal>();
        if m <= Decimal::ZERO {
            break;
        }
        total += m;
    }
    total
}

/// L11 reference: exhaustive search over every collection of NO baskets.
fn brute_nested(legs: &[BuyLeg], used: Vec<usize>, memo: &mut HashMap<Vec<usize>, Decimal>) -> Decimal {
    if let Some(v) = memo.get(&used) {
        return *v;
    }
    let avail: Vec<usize> = (0..legs.len()).filter(|&i| used[i] < legs[i].levels.len()).collect();
    let mut best = Decimal::ZERO;
    for mask in 1u32..(1 << avail.len()) {
        let s: Vec<usize> = avail.iter().enumerate().filter(|(j, _)| mask & (1 << j) != 0).map(|(_, &i)| i).collect();
        let payoff = Decimal::from(s.len() as u64) - Decimal::ONE;
        let cost: Decimal = s.iter().map(|&i| legs[i].fee.buy_cost(legs[i].levels[used[i]].0)).sum();
        let mut next = used.clone();
        for &i in &s {
            next[i] += 1;
        }
        let v = payoff - cost + brute_nested(legs, next, memo);
        if v > best {
            best = v;
        }
    }
    memo.insert(used, best);
    best
}
```

```rust
//! Depth-aware basket walking (spec §5.4; lemmas L8, L9, L11).
//! Every basket leg is a BUY; NO legs are bought on the mirrored NO asks (L1).
use crate::fee::FeeSchedule;
use crate::money::{Price, Shares};
use rust_decimal::{Decimal, RoundingStrategy};

/// A leg we buy; `levels` best-first (ascending price).
#[derive(Debug, Clone)]
pub struct BuyLeg {
    pub levels: Vec<(Price, Shares)>,
    pub fee: FeeSchedule,
}

#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub enum BasketRule {
    /// Every leg in every basket (D2a, D3); stop when any leg runs out.
    AllLegs { payoff: Decimal },
    /// NO baskets (D2b): each basket holds every leg that still has depth and pays (legs − 1). L4, L11.
    NestedNo,
}

#[derive(Debug, Clone, Default, PartialEq, Eq)]
pub struct LegFill {
    pub filled: Decimal,
    pub notional: Decimal,
    pub levels_used: usize,
}

#[derive(Debug, Clone, Default, PartialEq, Eq)]
pub struct BasketQuote {
    pub q_max: Decimal,
    pub cost: Decimal,
    pub payout: Decimal,
    /// Conservative fees, rounded up to 5 dp per level fill (what Π books).
    pub fees: Decimal,
    /// Unrounded fees (for math checks).
    pub fees_exact: Decimal,
    pub pnl: Decimal,
    pub pnl_exact: Decimal,
    pub pnl_gross: Decimal,
    /// First-segment marginal edge with exact fees (may be ≤ 0).
    pub top_edge: Decimal,
    pub top_edge_gross: Decimal,
    pub legs: Vec<LegFill>,
}

/// Walk the merged level breakpoints of all legs while the marginal edge is > 0 (L9).
/// `budget` caps total cost (for the $100 figure); the capped take is rounded down to 6 dp.
pub fn walk(legs: &[BuyLeg], rule: BasketRule, budget: Option<Decimal>) -> BasketQuote {
    let n = legs.len();
    let mut q = BasketQuote { legs: vec![LegFill::default(); n], ..Default::default() };
    let mut idx = vec![0usize; n];
    let mut rem: Vec<Decimal> = legs
        .iter()
        .map(|l| l.levels.first().map_or(Decimal::ZERO, |x| x.1.get()))
        .collect();
    let mut first = true;

    loop {
        let active: Vec<usize> = (0..n).filter(|&i| idx[i] < legs[i].levels.len()).collect();
        let payoff = match rule {
            BasketRule::AllLegs { payoff } => {
                if n == 0 || active.len() < n {
                    break;
                }
                payoff
            }
            BasketRule::NestedNo => {
                if active.len() < 2 {
                    break;
                }
                Decimal::from(active.len() as u64) - Decimal::ONE
            }
        };
        let prices: Vec<Price> = active.iter().map(|&i| legs[i].levels[idx[i]].0).collect();
        let sum_px: Decimal = prices.iter().map(|p| p.get()).sum();
        let sum_phi: Decimal = active.iter().zip(&prices).map(|(&i, &p)| legs[i].fee.phi(p)).sum();
        let m_gross = payoff - sum_px;
        let m = m_gross - sum_phi;
        if first {
            q.top_edge = m;
            q.top_edge_gross = m_gross;
            first = false;
        }
        if m <= Decimal::ZERO {
            break;
        }

        let seg = active.iter().map(|&i| rem[i]).min().unwrap_or(Decimal::ZERO);
        let mut take = seg;
        let mut capped = false;
        if let Some(cap) = budget {
            if sum_px > Decimal::ZERO {
                let room = ((cap - q.cost) / sum_px).round_dp_with_strategy(6, RoundingStrategy::ToZero);
                if room <= Decimal::ZERO {
                    break;
                }
                if room < take {
                    take = room;
                    capped = true;
                }
            }
        }

        let fees_seg: Decimal = active
            .iter()
            .zip(&prices)
            .map(|(&i, &p)| legs[i].fee.fee_conservative(p, take))
            .sum();
        q.fees += fees_seg;
        q.fees_exact += sum_phi * take;
        q.cost += sum_px * take;
        q.payout += payoff * take;
        q.q_max += take;

        for (&i, &p) in active.iter().zip(&prices) {
            let lf = &mut q.legs[i];
            lf.filled += take;
            lf.notional += p.get() * take;
            rem[i] -= take;
            if rem[i] == Decimal::ZERO {
                idx[i] += 1;
                lf.levels_used = idx[i];
                rem[i] = legs[i].levels.get(idx[i]).map_or(Decimal::ZERO, |x| x.1.get());
            } else {
                lf.levels_used = idx[i] + 1;
            }
        }
        if capped {
            break;
        }
    }

    q.pnl_gross = q.payout - q.cost;
    q.pnl = q.pnl_gross - q.fees;
    q.pnl_exact = q.pnl_gross - q.fees_exact;
    q
}
```

```rust
use crate::book::Book;
use crate::fee::FeeSchedule;
use crate::fill::{walk, BasketQuote, BasketRule, BuyLeg};
use rust_decimal::Decimal;

#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub enum LegStatus {
    Live,
    Placeholder,
    Other,
    ClosedNo,
    ClosedYes,
    Halted,
}

#[derive(Debug, Clone)]
pub struct GroupLeg {
    pub status: LegStatus,
    pub book: Book,
    pub fee: FeeSchedule,
}

/// One NegRisk event: every outcome, tradeable or not.
#[derive(Debug, Clone)]
pub struct Group {
    pub legs: Vec<GroupLeg>,
    pub augmented: bool,
}

#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub enum Kind {
    YesBasket,
    YesBasketIncomplete,
    NoBasket,
    Implication,
}

#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub enum Realization {
    Settlement,
    Converter,
    NotArbitrage,
}

#[derive(Debug, Clone)]
pub struct Signal {
    pub kind: Kind,
    pub realization: Realization,
    /// Walk with each leg's real fee schedule.
    pub quote: BasketQuote,
    /// Walk with zero fees (for gross-only episodes and paper comparisons).
    pub gross: BasketQuote,
    /// Indices into the group's legs (or [0, 1] for an implication pair).
    pub legs_used: Vec<usize>,
}

impl Signal {
    pub fn net_positive(&self) -> bool {
        self.quote.pnl > Decimal::ZERO
    }
}

/// D1 (L2): true means our local state is wrong, never an opportunity.
pub fn canary(book: &Book) -> bool {
    book.is_crossed()
}

fn run(legs: Vec<BuyLeg>, rule: BasketRule) -> (BasketQuote, BasketQuote) {
    let gross_legs: Vec<BuyLeg> = legs
        .iter()
        .map(|l| BuyLeg { levels: l.levels.clone(), fee: FeeSchedule::ZERO })
        .collect();
    (walk(&legs, rule, None), walk(&gross_legs, rule, None))
}

fn decided(g: &Group) -> bool {
    g.legs.iter().any(|l| l.status == LegStatus::ClosedYes)
}

/// D2a (L3): buy one YES of every live leg. Arbitrage only if the set is complete.
pub fn detect_yes_basket(g: &Group) -> Option<Signal> {
    if decided(g) {
        return None;
    }
    let live: Vec<usize> = (0..g.legs.len()).filter(|&i| g.legs[i].status == LegStatus::Live).collect();
    if live.is_empty() {
        return None;
    }
    let legs: Vec<BuyLeg> = live
        .iter()
        .map(|&i| BuyLeg { levels: g.legs[i].book.asks_best_first(), fee: g.legs[i].fee })
        .collect();
    if legs.iter().any(|l| l.levels.is_empty()) {
        return None;
    }
    let (quote, gross) = run(legs, BasketRule::AllLegs { payoff: Decimal::ONE });
    if gross.pnl_gross <= Decimal::ZERO {
        return None;
    }
    let complete = !g.augmented
        && g.legs.iter().all(|l| matches!(l.status, LegStatus::Live | LegStatus::ClosedNo));
    let (kind, realization) = if complete {
        (Kind::YesBasket, Realization::Settlement)
    } else {
        (Kind::YesBasketIncomplete, Realization::NotArbitrage)
    };
    Some(Signal { kind, realization, quote, gross, legs_used: live })
}

/// D2b (L4, L5, L11): buy NO on every live leg that has a YES bid; legs exit as they exhaust.
pub fn detect_no_basket(g: &Group) -> Option<Signal> {
    if decided(g) {
        return None;
    }
    let used: Vec<usize> = (0..g.legs.len())
        .filter(|&i| g.legs[i].status == LegStatus::Live && g.legs[i].book.top().best_bid.is_some())
        .collect();
    if used.len() < 2 {
        return None;
    }
    let legs: Vec<BuyLeg> = used
        .iter()
        .map(|&i| BuyLeg { levels: g.legs[i].book.no_asks_best_first(), fee: g.legs[i].fee })
        .collect();
    let (quote, gross) = run(legs, BasketRule::NestedNo);
    if gross.pnl_gross <= Decimal::ZERO {
        return None;
    }
    Some(Signal { kind: Kind::NoBasket, realization: Realization::Converter, quote, gross, legs_used: used })
}

/// D3 (L10): for a curated pair where A ⇒ B, buy NO_A + YES_B.
pub fn detect_implication(a: &GroupLeg, b: &GroupLeg) -> Option<Signal> {
    let legs = vec![
        BuyLeg { levels: a.book.no_asks_best_first(), fee: a.fee },
        BuyLeg { levels: b.book.asks_best_first(), fee: b.fee },
    ];
    if legs.iter().any(|l| l.levels.is_empty()) {
        return None;
    }
    let (quote, gross) = run(legs, BasketRule::AllLegs { payoff: Decimal::ONE });
    if gross.pnl_gross <= Decimal::ZERO {
        return None;
    }
    Some(Signal { kind: Kind::Implication, realization: Realization::Settlement, quote, gross, legs_used: vec![0, 1] })
}
```

```rust
//! Episodes (spec §5.5): a maximal run of net-positive states per group, in server time.
use rust_decimal::Decimal;
use std::collections::{HashMap, HashSet};

#[derive(Debug, Clone, Copy, Default, PartialEq, Eq)]
pub struct Censor {
    pub left: bool,
    pub right: bool,
    pub gap: bool,
}

#[derive(Debug, Clone, PartialEq, Eq)]
pub enum EpisodeEvent {
    Open { id: u64, key: String, ts_ms: i64, pnl: Decimal },
    Peak { id: u64, ts_ms: i64, pnl: Decimal },
    Close { id: u64, ts_ms: i64, duration_ms: i64, peak_pnl: Decimal, censor: Censor },
}

#[derive(Debug, Clone)]
struct Open {
    id: u64,
    opened_ms: i64,
    last_ms: i64,
    peak: Decimal,
    censor: Censor,
}

#[derive(Debug)]
pub struct EpisodeTracker {
    gap_ms: i64,
    next_id: u64,
    open: HashMap<String, Open>,
    seen: HashSet<String>,
}

impl EpisodeTracker {
    pub fn new(gap_ms: i64) -> Self {
        Self { gap_ms, next_id: 1, open: HashMap::new(), seen: HashSet::new() }
    }

    /// Feed one evaluated state. `net_pnl` is Some only when the signal is net-positive.
    pub fn on_state(&mut self, key: &str, ts_ms: i64, net_pnl: Option<Decimal>) -> Vec<EpisodeEvent> {
        let first_sight = self.seen.insert(key.to_string());
        let gap_ms = self.gap_ms;
        let mut out = Vec::new();
        match (self.open.contains_key(key), net_pnl) {
            (true, Some(pnl)) => {
                if let Some(ep) = self.open.get_mut(key) {
                    if ts_ms - ep.last_ms > gap_ms {
                        ep.censor.gap = true;
                    }
                    ep.last_ms = ts_ms;
                    if pnl > ep.peak {
                        ep.peak = pnl;
                        out.push(EpisodeEvent::Peak { id: ep.id, ts_ms, pnl });
                    }
                }
            }
            (true, None) => {
                if let Some(mut ep) = self.open.remove(key) {
                    if ts_ms - ep.last_ms > gap_ms {
                        ep.censor.gap = true;
                    }
                    out.push(close(ep, ts_ms));
                }
            }
            (false, Some(pnl)) => {
                let id = self.next_id;
                self.next_id += 1;
                let censor = Censor { left: first_sight, ..Censor::default() };
                self.open.insert(key.to_string(), Open { id, opened_ms: ts_ms, last_ms: ts_ms, peak: pnl, censor });
                out.push(EpisodeEvent::Open { id, key: key.to_string(), ts_ms, pnl });
            }
            (false, None) => {}
        }
        out
    }

    /// The group's feed dropped: right-censor any open episode, and treat the next state as a first sight.
    pub fn on_disconnect(&mut self, key: &str, ts_ms: i64) -> Vec<EpisodeEvent> {
        self.seen.remove(key);
        match self.open.remove(key) {
            Some(mut ep) => {
                ep.censor.right = true;
                vec![close(ep, ts_ms)]
            }
            None => Vec::new(),
        }
    }
}

fn close(ep: Open, ts_ms: i64) -> EpisodeEvent {
    EpisodeEvent::Close {
        id: ep.id,
        ts_ms,
        duration_ms: ts_ms - ep.opened_ms,
        peak_pnl: ep.peak,
        censor: ep.censor,
    }
}
```

```rust
//! Duration statistics (spec §5.5). Left- and gap-censored episodes are excluded by the caller.
use rust_decimal::Decimal;

/// Kaplan–Meier with right-censoring. `obs` = (duration_ms, observed).
pub fn kaplan_meier(obs: &[(i64, bool)]) -> Vec<(i64, Decimal)> {
    let mut sorted = obs.to_vec();
    sorted.sort_by_key(|&(d, _)| d);
    let mut at_risk = sorted.len() as u64;
    let mut surv = Decimal::ONE;
    let mut out = Vec::new();
    let mut i = 0;
    while i < sorted.len() {
        let t = sorted[i].0;
        let mut events = 0u64;
        let mut leaving = 0u64;
        while i < sorted.len() && sorted[i].0 == t {
            if sorted[i].1 {
                events += 1;
            }
            leaving += 1;
            i += 1;
        }
        if events > 0 && at_risk > 0 {
            surv *= Decimal::from(at_risk - events) / Decimal::from(at_risk);
            out.push((t, surv));
        }
        at_risk -= leaving;
    }
    out
}

/// Gebele's empirical survival over uncensored durations: share with D > tau.
pub fn empirical_survival(uncensored: &[i64], tau: i64) -> Decimal {
    if uncensored.is_empty() {
        return Decimal::ZERO;
    }
    let above = uncensored.iter().filter(|&&d| d > tau).count() as u64;
    Decimal::from(above) / Decimal::from(uncensored.len() as u64)
}
```
